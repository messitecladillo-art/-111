# 提示词组织

先冻结需要出现的确切文字（赛事届次全称、主标题、副标题、盲审队名），再根据所选模式（**形式一直出图文** 或 **形式二参照分层组装**）组织连续的画面描述。下面是可组合的段落骨架，不必机械填满每一项。

## 形式一骨架：完整图文一体封面（`direct_illustrated`）

```text
用途与画幅：一张完整的[研究主题]报告封面海报，A4 竖版 210:297，全出血平面完整画面（无书本样机、无桌面展示、无多方案拼图）。

确切文字（逐字精确，零错字，零多余自述词）：
赛事名称（置顶小字眉栏）：[如：“益普索杯”第十七届全国大学生市场调查与分析大赛；非竞赛可省]
主标题（艺术字）：[逐字输入，含标点与建议横/竖/阶梯分行]
副标题（低干扰区清晰可读）：[逐字输入，保持完整]
队伍署名（底部盲审合规栏）：[如：参赛团队：xxx调研队；绝不含校名/人名]

视觉概念：[一句话说明主题核心张力与画面隐喻关系]
组织方式与媒介：[完全按当前题材自由决定视觉媒介与艺术风格——不锁死在任何固定预设流派，只要求高完成度与强辨识度]
核心素材：[前/中/远三景叙事元素：主体实体、环境/城市或空间纵深线索、流动连接媒介与前景细部，避免“单个孤立物件悬在空白底上”的寡淡感，避开廉价扁平卡通人物]
构图：[视觉重心、视线路径、尺度对比、前后穿插层次、整页饱满度与专门为文字雕刻的安静阅读口袋]
标题字形：[与题材匹配的艺术字气质——非板正电脑正体；说明横/竖排、核心字高亮或笔画延伸方式，保持每字结构严谨可辨]
配色与反差：[项目色板或本题候选色板，明确明底深墨或暗底亮金反差]
辅助素材：[为什么相关、放在哪一层，不堆砌]
副标题与署名区：[安静低干扰背景、细线/胶囊/竖条导引与舒适字距]
不应出现：[明确禁止“市场调查与统计分析报告”等自述文种词、禁止“模拟/测试/AI”免责字样、禁止学校名/校徽/个人姓名/多余英文乱码/水印]
```

## 形式二骨架：纯净无字背景底图（`layered_assembly` → Step 2 `clean_backdrop`）

在形式二中，先以形式一生成或选定一张**参照图**锁定版式与重心，再对照参照图撰写以下**严格零文字**底图提示词：

```text
用途与画幅：一张对照既定版式参照图的[研究主题]纯净无字封面背景底图（Clean Textless Backdrop），A4 竖版 210:297，全出血平面完整画面。

严格零文字红线（CRITICAL ZERO-TEXT）：
画面中绝对禁止出现任何汉字、英文字母、数字（包括表盘/屏幕数字）、印章文字、Logo、标牌、胶囊框、水印或伪文字笔画。

呼吸负空间预留（严格对齐参照图四区锚点）：
- 上部/右侧文字负空间：[横排留出上部约 42%–46%，竖排留出右侧及上部约 55%–60% 的纯净均匀留白区；明底留浅暖白/冷银负空间，暗底留深邃沉静暗调负空间，供后续透明矢量艺术字叠层]
- 底部署名负空间：[底部约 8%–10% 保持干净无杂物，承托后续盲审队名栏]

主体视觉区（安放于余下视觉重心区）：
[严格复刻参照图的视觉主体、材质质感、光影方向与配色世界，确保主体边缘与文字负空间过渡自然、无生硬裁切线]
```

## 局部迭代原则

- 原始成功提示词参考 `crayfish-original-prompt.txt`；其中具体标题、主体、配色与地域线索仅属于该作品，新题材必须按当前主题重新构思视觉隐喻。
- 同一封面的局部修改：向内置生图工具传入已认可的现有图，用简短明确的指令说明只改哪一处、保留哪些部分，始终保留原版。
- 形式二改字（换届次、换队名、改副标题或换书法流派）无需重画底图，直接更新透明矢量艺术字层并重新对照组装即可。
