# 构图、素材与文字

## 开放式组织方向（启发坐标，而非封闭清单）

以下方向来自对真实优秀报告封面的观察，**仅作启发起点，绝不限制在表内六项**；你可以自由组合或探索任何更契合当前选题的视觉媒介（如版画、蓝晒、胶片纪实、超现实意象融合、纯字形构成、工业微距等）。为新主题提供多套候选时，重点是在媒介、色系与构图上真正拉开差距，杜绝同质化换壳。

| 方向 | 组织机制 | 适用判断 |
|---|---|---|
| 主题插画 | 主体、环境与动作组成一个完整场景 | 题材有可辨识的对象、生活场景或地域意象 |
| 器物微距静物 / 素材拼贴 | 真实质感器物棚拍、光学折射、撕纸/3D剪纸景深、蒙版与遮挡把核心符号凝练成焦点 | 追求零卡通高定质感，或需将抽象调研对象具象为有温度的实体静物 |
| 书卷式排版 | 竖排书法、篆印、留白气韵与水墨/工笔边角关系营造装帧感 | 题材适合文化、传统、在地叙事或沉静厚重的阅读气质 |
| 摄影主导 | 高质感 35mm 纪实/人文自然光照片主体与画面留白共同承担叙事与文字空间 | 需要强烈的人文温度与杂志大刊质感；概念摄影不冒充实地走访证明 |
| 几何分区 / 数据蓝图 | 色块、瑞士网格、斜向边界与精密线描构成对比与连接 | 适合科技服务、政策评估、数据建模或双轨对比场景 |
| 概念字形 | 超大主标题本身成为主要图形（错落阶梯、飞白叠影、笔画意象化），素材围绕字形组织 | 短主标题有强记忆点核心词，适合让字形本身承载第一眼冲击力 |

新题材完全可以组合或创造其他组织方式。没有必须书法、必须绿底、必须卡通人物或必须居中的统一答案。

## 六个素材层次

1. **文字信息**：赛事届次全称（竞赛适用时）、主标题艺术字、研究副标题、盲审合规队名（竞赛适用时）。
2. **核心视觉**：主题器物静物、真实质感场景、地域主体或概念字形（优先高质感实物隐喻，慎用廉价扁平卡通小人）。
3. **场景辅助**：与主题有关的环境、建筑剪影、自然光影等，不为填空而添加。
4. **背景**：底色、纸纹、胶片颗粒、空间景深或明/暗情绪底面，承托主视觉并决定字色反差（明底深墨 / 暗底亮金）。
5. **组织与过渡**：光弧、丝带、撕纸边界、曲线、蒙版、前后遮挡，让多素材成为一体。
6. **主题装饰**：从题材中生长出来的局部细线、脉搏波纹、印章或纹样。

这些层是分析工具，不是六个必须填满的栏目。颜色、尺度、字形和留白横跨所有层。

## 先设计关系，再摆放素材

- **饱满度校准（拒绝“单物体悬空在空白底上”的寡淡感）**：克制不等于简陋。真正高级的封面应当**远观有大气势与大留白节奏，近看有前/中/远三景纵深、环境线索、质感纹理与细部结构可细赏**。围绕核心主体，应自然编织与其同源的场景纵深（如城市街区/窗景/社区环境/建筑线描/自然地貌）、流动过渡元素（光轨、水流、丝带、等高线、几何制图弧线）以及前景框景细节，让整张 A4 画幅成为一个完整丰盈的世界——只在赛事眉栏、主副标题与底部署名处**刻意雕刻出安静的阅读口袋**，而不是让整张画大面积无意义留空。
- 先选视觉重心：标题、主题物或两者相互呼应。其他内容围绕重心分配重量。
- 选择一条可读的视线路径，例如斜向、S 形弧线、环抱景深或前景到远景。让材质和素材推动这条路径。
- 通过尺度差异和受控的出画形成张力；裁切服务构图，不能误裁标题或破坏主体识别。
- 将复杂细节集中在需要停留的位置，给赛事眉栏、副标题与底部队名留下安静、对比度足够的背景区域。
- 元素之间要有联系：同色呼应、线条延伸、前后穿插或光影反射均可，不一定依靠生硬方框和卡片。
- 内部可以有隐含对齐，整体不必像正文一样死板居中排齐；避免为了“自由”把所有素材随机旋转。

## 字形也是素材（拒绝板正，按题材匹配气质）

标题可以独立绘制（形式一），也可以通过真贝塞尔路径矢量化生成透明艺术字层后与无字底图组装（形式二）。选择字形气质时，必须说明它与题材的关系：

- **国风行楷 / 手写毛笔**（横排或竖排，含飞白、错落基线、核心字放大提亮）：适配在地文化、民生温情、人文消费、传统转型题材；
- **现代雕塑光弧字 / 锐利衬线构成**：适配高端器物、光学/医疗科技、商业品牌与品质生活题材；
- **现代笔刷构成 / 几何大字**：适配青年群体、数据蓝图、城市空间、政策评估与双轨赛事题材；
- **自由手写体 + 克制人文楷宋副题**：适配 35mm 纪实摄影大刊与深度社会观察题材。

可用操作包括局部放大、字距变化、阶梯错位、笔画延伸、字与图之间的前后穿插、核心关键字异色高亮。一次突出少数关系即可，整套字保持气质一致。

始终逐字核对：结构、偏旁、点画、引号、字序。装饰不能把文字变成另一个字，也不能用不可辨认的字形掩盖生成错误。副标题以阅读为先，优先在低干扰区域按语义自然分行，避免缩到看不清。

## 避免把个案变成公式

小龙虾案例使用了红虾、青绿江湖、金色稻穗和书法字，是因为这些元素在同一题材中相互支持；《源头之后》使用光学镜片与金属细框，是因为它紧扣配镜质量信任；银发监测使用老花镜与心电手表静物，是因为它紧扣老龄与健康监测。换成公共交通、文旅餐饮、工业制造或青年就业时，必须**重新从当前选题提炼实体隐喻、主体、笔触、空间与颜色**，绝不套壳换物。
