# 交付方式与可选矢量路线

## 交付口径

PNG 是栅格资产；它是候选稿还是正式封面，取决于确认的交付用途。按最终页面清晰度与修改需求在以下三条交付口径中选择，不把 PNG 放进 SVG 冒充矢量：

1. **形式一直出整图栅格交付（PNG）**：保留原生高分辨率像素（如 A4 `1000×1414` 至 `2480×3508`），记录最终物理尺寸与有效分辨率，检查正文与附录嵌入后的文字清晰度与裁切。
2. **形式二分层组装交付（纯净无字底图 PNG + 真矢量透明艺术字 SVG + 2× 超采样合成 A4 PNG）**：
   - 透明艺术字层必须是**纯透明背景（零全页不透明 `<rect>`，零嵌入 `<image>`）**的真矢量 SVG（优先使用真实中文字库经贝塞尔路径升阶输出 `<path d="M...C...Z"/>` 轮廓曲线，确保跨操作系统、浏览器与印刷端 100% 零缺字、零错字、无限缩放锐利）；
   - 合成成品按参照图解析的四区锚点（`headerZone`、`titleZone`、`subtitleZone`、`teamPlaqueZone`）与明暗反差模式（`dark_on_light` / `light_on_dark`）执行 2× 超采样抗锯齿合图；
   - 保留独立可编辑的文字元数据、无字底图与透明 `.svg`，支持随时更换赛事届次、队名或副标题并秒级重组，同时明示转曲后的 `.svg` 路径可无限缩放但需通过源参数重生成改字。
3. **整图全矢量路线（仅在用户明确要求整张封面全矢量化时启用）**：
   - **受控图元重建**：适合几何分区、线条、简单主题轮廓及需要逐对象编辑的素材；
   - **自动描摹后清理**：适合已认可的绘制字形与插画；保留整体艺术关系，再修复碎路径、孔洞、杂色和过细文字。

## 历史案例整图描摹参考（小龙虾案例已验证起点）

当需要走路线 3 的整图自动描摹时，小龙虾案例曾使用 VTracer 0.6.15 生成彩色曲线路径并用 resvg-py 0.5.0 独立渲染，以下参数仅作起点参考：

```json
{
  "colormode": "color",
  "hierarchical": "stacked",
  "mode": "spline",
  "filter_speckle": 8,
  "color_precision": 5,
  "layer_difference": 24,
  "corner_threshold": 60,
  "length_threshold": 4.5,
  "max_iterations": 10,
  "splice_threshold": 45,
  "path_precision": 3
}
```

小字副标题若在彩色描摹中出现杂色，应单独做单色轮廓提取并替换碎路径，不用背景矩形掩盖问题；新封面须重新定位文字区域，不复用旧图裁剪坐标。

## 校验

1. **结构**：解析 SVG，确认无 `<image>`、嵌入 PNG/JPEG、外部图片、`foreignObject`、脚本或依赖栅格化的滤镜；若为形式二透明艺术字 SVG，额外校验无全画布不透明背景矩形。
2. **尺寸**：检查物理尺寸和 `viewBox`（A4 比例 `210:297`），等比置入不强拉伸。
3. **真实渲染**：从交付 SVG 或合成管线独立重新渲染并肉眼核验，不把原始 PNG 改名充当渲染预览。
4. **视觉与文字**：逐字复核赛事名称、主副标题与盲审队名；检查明暗反差、笔画清晰度、遮挡、裁切与底图主体无压盖。
5. **文件记录**：保存参照图、无字底图、透明矢量 SVG 与最终组装图的版本与哈希，明确记录已检项与未检项（如印刷 CMYK/ICC 打样）。
