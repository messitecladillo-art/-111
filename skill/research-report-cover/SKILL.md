# 报告封面

将用户认可的封面经验转化为可复用的创作方法：素材、文字、色彩和留白共同构成一幅有阅读顺序的完整海报作品。允许不对称、穿插、遮挡、拼贴和专门设计的艺术字形，保持研究题名与赛事要素清楚完整。

这是有参考实物的创作 Skill。小龙虾等既有案例是已认可的构图与气质范例，**绝不是新主题必须套用的版式公式**。

## 先识别本次工作

- **整理或复用方法**：保存规则、参考和出处，不重做已认可作品。
- **同一作品的衍生或局部修改**：以现有认可版本为锚点，只改用户指定部分，另存版本。
- **新主题封面**：继承“素材与文字共同构图”的原则，重新决定视觉主体、字体气质、配色和布局。不要只把小龙虾（或任何旧案例主体）替换成另一物体；默认给出多套跨媒介、跨色系、反同质化的候选供用户选择。

对新主题，历史参考图仅用于理解视觉质量、留白节奏与构图关系；只有用户明确要求同款时，才保留其具体构图、配色和笔触。

## 内容与视觉简报

从用户已有信息开始：确切主副标题、研究对象与地域、赛事/盲审要求、视觉偏好、尺寸、已有项目配色、参考材料和交付用途。仅给主题时可先用 `$research-report-title` 命名；若该技能不可用，采用“有记忆点的主标题＋范围准确的副标题”形成拟定题目，不擅自写入未核实的调查结果。

保存所有要出现的确切文字，区分完整题目与排版换行。通常用 A4 竖版（`210:297`）作为报告封面起点，用户尺寸或适用格式另有规定时跟随该要求。题材配色与全文图表相互呼应（封面定稿后可提取同源 `FigurePalette`）；用户没有既有配色时，从主题制定差异化候选色板。

### 竞赛封面必备文字要素与净版红线

当交付对象为学科竞赛报告（如全国大学生市场调查与分析大赛）时，封面必须完整且仅包含以下三类核心文字要素：

1. **赛事名称（细化到具体届数与官方冠名）**：如第十七届须使用官方现行冠名 **`“益普索杯”第十七届全国大学生市场调查与分析大赛`**（不再写作“正大杯”第十七届；其他届次或赛事按当届正式通知覆盖）。
2. **选题主副标题（非板正艺术字，横排、竖排或错落阶梯均可）**：主标题以艺术字形态呈现，副标题完整交代研究范围与问题、置于低干扰区域。
3. **队伍名称（盲审合规）**：如 `参赛团队：xxx调研队`（仅限团队代号，严禁出现学校名称、院系、指导教师或成员真实姓名；正式提交前须核验已脱敏）。

**净版禁令**：
- 严禁出现 `市场调查与统计分析报告`、`调研报告` 等自述文种身份的多余标牌（就像不需要告诉别人“你是你”）。
- 严禁出现任何 `模拟 / 测试 / 演练 / AI生成 / 仅作演示 / 不作为实际结论` 等元解释文字。
- 非竞赛的中性委托研究，仅保留用户指定的文字要素，不强加赛事名称或未提供的队名。

## 艺术构图与反板正字形

读 [构图与文字](references/composition-and-lettering.md) 选择适合本题的组织方式。先决定一个明确的视觉重心与视线路径，再安排素材。丰富感来自前后层次、大小对比、疏密、真实材质/光影或图形呼应，而不是把所有相关符号堆满，更不是机械堆砌廉价卡通小人。

- **风格不设上限、绝不定死**：不要把创作锁死在某几套固定预设或固定流派清单里。无论是摄影、微距静物、水墨工笔、版画/孔版印刷、剪纸拼贴、建筑几何、超现实意象隐喻、极简纯字海报还是混合媒介，只要贴合当前选题气质并具备高完成度，均可自由探索与混搭。
- **字体尽量不要板正**：标题是视觉主体之一，应按题材气质自由创造字形——可以是手写书法、飞白行草、雕塑感现代字、几何构成字、手绘粗笔刷、复古铅字或自由变形的意象字形，善用局部放大、字重对比、节奏错位、笔画延伸、横竖混排及字图前后穿插。**无需把系统字体库或固定流派列表作为上限，也无需每个选题都采用同一种字形**。
- **副标题以完整和易读为先**：可在安静留白区、细线导引、色带或竖列中按语义自然分行，不与主视觉争抢。
- **不把正文版心套到封面**：封面是全出血杂志/海报级构图，但有艺术变化并不等于把所有元素随意倾斜或塞满空白。

## 双轨制作流程（两种形式按需选用）

封面生产支持**两种标准形式**，按用户对“图文融合张力”与“文字零错字/随时可改”的权重自由切换或组合：

### 形式一：直出图文多选（`direct_illustrated`）

1. **多方向反同质化出图（不限定死流派）**：新主题默认并行产出多套（建议 3–6 套）在**媒介语言、色彩情绪、构图重心、字形方向（含横排/竖排/错落）**上真正拉开差距的完整图文候选供用户挑选。[构图与文字](references/composition-and-lettering.md) 中的组织方式只是启发坐标而非封闭菜单，严禁把同一配色或同一画风换壳微调充当多套方案。
2. **提示词写法**：将简报写成连续画面描述（参见 [提示词组织](references/prompt-structure.md)），允许内置生图能力直接绘制中文艺术字并让文字与主体建立前后穿插、光影折射等高度融合关系；生成后逐字核对每一笔偏旁。
3. **局部精修**：用户选定某一方向后，以该图作为编辑参考做局部修正，保留已认可的构图与气质。

### 形式二：参照图驱动分层组装（`layered_assembly`）

当用户要求**100% 零汉字错字、可随时修改赛事届数/副标题/队名而无需重画底图，或需要独立可缩放的透明矢量艺术字**时，按以下四步闭环执行：

1. **① 生成或选定完整图文作为参照图**：先用形式一产出完整图文封面作为视觉参照，锁定主视觉重心、文字留白区、排布方向（横排/竖排/不对称错落均可）与明暗反差（`dark_on_light` 明底深字 / `light_on_dark` 暗底亮字）。
2. **② 生成纯净无字背景底图（`clean_backdrop`）**：对照参照图构图，生成 **100% 零文字、零字母、零数字、零印章、零标牌** 的纯背景艺术图；风格与明暗完全跟随参照图（明底留浅色负空间，暗底留深色沉静负空间，不硬性限定浅底或固定画风）。
3. **③ 生成矢量化无背景艺术字体图层（`vectorTypographySvg`）**：独立生成**纯透明背景（无任何不透明底框）的真矢量艺术字 SVG**（优先将艺术字形转为三次贝塞尔 `<path>` 轮廓），字形风格、配色、横竖排与局部点缀完全跟随参照图气质动态匹配，不限定于固定几套模板，并支持组装前实时微调四项文字。
4. **④ 系统对照参照图精准组装**：按参照图解析出的布局锚点与比例，将“无字背景底图”与“透明矢量艺术字图层”2× 超采样抗锯齿合成为高清 A4 封面成品（同时保留独立无字底图与纯透明 `.svg` 艺术字供二次编辑或矢量交付）。

按 [交付方式与可选矢量路线](references/vector-delivery.md) 决定最终交付格式（PNG、纯矢量艺术字 SVG 或整图矢量描摹），绝不把 PNG 塞进 SVG 冒充矢量。

## 参考与权威

- [已认可案例与来源](references/approved-example.md) 记录小龙虾等已认可范例的标题、素材关系与哈希；原始样本只读保留，新题材只借鉴其构图与图文共生逻辑。
- 历届优秀获奖作品封面用于研究全出血海报构图、字形节奏与盲审要素演化，不照搬他人画面或将他人整图打包为公开素材。
- 竞赛提交封面采用中性研究视觉，不添加工具品牌标识（如 EVI-X Logo）、校徽、校名、奖项承诺或未提供的身份信息。
- 用户批准的是本次设计方向，不代表后续所有选题、版式、赛事规则或印刷输出均已自动批准。

## 交付与检查

交付完整题目、已选模式（形式一或形式二）的封面成品及实际页面预览；若走形式二，同步交付或可导出**参照图、无字背景底图、纯透明矢量艺术字 SVG 与对照组装成品**，并保存提示词、输入参考与版本记录。

验收重点：
- **远观与近看（兼顾气势与饱满度）**：缩略图一眼能辨主题与重心；近看具备**前/中/远三景层次、环境叙事与丰富材质细部**（绝非单个孤立物件悬在空荡单色背景上），同时字形、边缘、材质不破碎、无锯齿。
- **文字零瑕疵**：赛事届次全称、主副标题、盲审队名逐字正确；艺术化不损害可辨度，重要文字不被裁切，零多余自述词或模拟免责词。
- **反同质化**：多候选之间必须在媒介质感、色系、字形气质或构图路径上形成实质区分，而非同款微调。
- **形式二专项检查**：无字底图 100% 零残字/伪字笔画；矢量艺术字 SVG 零不透明背景矩形、零嵌入位图；组装后文字与底图主体零生硬压盖、明暗对比充足。
- **文件边界**：原始参考、已认可作品与产品文件保持不变，衍生物另存；只需正文页框时使用 `$research-report-frame`。

## 全篇衔接与独立审查

本次任务涉及跨部分变化或定稿时，沿用项目当前已确认的题名、研究范围、事实/结果版本、格式与配色依据，将受影响位置和版本交给 `$research-report-consistency` 的独立审查 agent（若不可用则如实说明自查范围）。只做局部任务时按变化影响核对，不扩大为全篇重写，不因审查自动发布或推进赛事状态。
