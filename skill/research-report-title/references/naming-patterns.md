# 命名参考

从表达方式吸收结构，不复制其他报告的词句、对象、方法或地域。命名形式本身不证明研究价值或获奖原因。

| 形式 | 可以承担的任务 | 检查点 |
|---|---|---|
| 对象意象与生活表达组成短主标题 | 建立记忆点，让研究对象自然进入语言 | 意象与对象有关，去掉谐音后仍能理解 |
| 短主标题加研究副标题 | 将主题气质与研究范围分开表达 | 副标题只写已知或明确拟定的对象、地域和问题 |
| 直接研究题名 | 在范围已清楚时简洁表达 | 不为装饰强加诗句、双关或多余维度 |
| 地域意象加案例范围 | 在地理差异与研究问题有关时提供情境 | 不能从意象推断行业排名、地方事实或已完成调查 |

对象相关的借字应保留自然节奏，不要求每个主题都谐音。副标题可以只呈现一个核心问题，也可以呈现互相关联的研究重点，不能机械套成三个维度。保存文字与封面文字一致；换行只改变显示，不改变字序和语义。

本参考由个人标题 Skill 的原创命名方法整理，仅保留可迁移的方法说明；私人报告、用户原始案例与本地来源路径不进入产品文本包。
