# 产品 Agent 运行边界

技能提供命名方法；真实可用能力以宿主配置为准，不授予网络、文件读取、生图或外部发布权限。产品文本包只携带原创方法与工作模式，不包含私人报告、完整案例、原图或本地绝对路径。不能声称读取了未提供的材料。

实际选题 Agent 的有界模型调用将命名规范装入提示词，继续沿用既有 `text`、`questions` 和 `items` 响应结构：题名放入 `items[].title`，取舍和范围说明使用现有文字字段。模型没有工具调用权限，不额外输出封面或宣称完成独立审稿。

本地确定性推荐没有调用模型，不能把装载的版本信息称为命名执行成功。准备规范、形成候选、用户确认题名、文件导出与赛事 Gate 是不同状态。已保存记录按原始版本展示；版本变化后需新会话，不能悄悄重解释旧回执。
