## 一、双段式标题配方与禁忌矩阵

### 1.1 标准结构与副标题四元槽位

$$\text{正式总标题} = \text{主钩子（8–18 字）} + \text{“——”} + \text{描述性副标题（时空范围 + 核心客体 + 构念/变量 + 研究后缀）}$$

- **分隔符规范**：统一采用标准中文全角双破折号 `——`；副标题已含区域限定时，严禁再套“——以某市为例”将标题切碎为三段。
- **副标题四元必选槽位**：`[政策/行业语境（可选）] + [精确地理/群体边界] + [核心客体与变量] + [方法/目标后缀]`。
  - **实证合规例**：`“三孩政策”背景下`（语境）+ `合肥市`（地理）+ `双职工家庭托育意愿样态`（客体与变量）+ `分析与市场激活策略研究`（后缀）（`149`）。

## 二、书眉与扉页对偶标语工程规范

1. **扉页对偶（视觉主区）**：置于宋体三号加粗正式总标题下方或扉页留白处，采用 **`5+5`、`5+7` 或 `7+7`** 严密对仗，凝练时代纵深或供需对撞，**不得替代正式总标题**。
2. **正文书眉（Running Header）**：置于 A4 上边距 `2.54 cm` 内，由**细双横线 + `8–14` 字单行凝练口号 + 角落极简矢量行业小徽标**组成；遵循中性深墨（`#333333` / `#595959`）配 1 种行业强调色（如生态 `#12a152`、科技 `#0070c0`、文旅 `#000080`）。**绝对零校名、队名与导师信息泄露**。

| 标语类型 | 格律规格 | 实证范式 / `[示范模板]` | 对应书眉（`8–14` 字单行） |
| :--- | :--- | :--- | :--- |
| **时空今昔偶** | `7+7` 平仄错落，对照历史与当下 | `前月浮梁买茶去，今朝一品江南茗`（`178`） | `浮梁新茗：千年茶脉的当代破局`（`13` 字） |
| **技术人文偶** | `5+7` 或 `7+7`，前句立条件，后句落体验 | `[示范模板]` `算力向善护隐私，服务温度暖银龄` | `[示范模板]` `适老数字服务体验与信任边界调查` |

## 三、三拍决策张力开篇法（1.1 节写作工程）

第 1.1 节压缩在 1.5 页内，依 **“宏观大盘硬锚 → 结构性反差痛点 → 可测量子问题”** 三拍推进，凝练贯穿全篇的唯一**母洞察（Mother Insight）**。

### 3.1 第一拍与第二拍：宏观锚定与六大反差痛点原型

- **第一拍（100–180 字）**：引用统计年鉴、七普或行业白皮书硬数据，严禁“随着经济发展……”空话铺陈。
- **第二拍（120–200 字）**：用“然而 / 穿透表象”切出结构性裂谷。下列 6 类原型全量源自国奖实证：

| 痛点原型 | 张力构造公式 | 国奖真实量化反差锚点 |
| :--- | :--- | :--- |
| **1. 漏斗断层型** | 高认知 / 高尝鲜 $\longleftrightarrow$ 低转化 / 低复购 | `192` 鸡肉丸认知度 `85.5%` vs 转化率 `72.4%`（落后大希地 `81.7%`）；`151` 无糖尝鲜 `94.92%` vs 月复购 `< 1.2` 次；`031` 黄梅戏认同 `85.65%` vs 高意愿 `16.34%`；`148` 超七成云博访问止步图文检索 |
| **2. 政策摩擦型** | 顶层强力推进 $\longleftrightarrow$ 基层滞后 / 隐性负外部性 | `187` 学科截断倒逼私域教育隐性增负；`167` 绿色食品破五千亿 vs 超八成未消费者受困溢价与盲区；`094` 沈阳 60 岁+超 `27%`、全国 `4,200` 万失能老人 vs `30` 万护理员 |
| **3. 信任坍塌型** | 赛道资本狂飙 $\longleftrightarrow$ 舆论丑闻引爆信用危机 | `176` 郑州 `220` 亿预制菜遭遇“3·15 槽头肉”事件（“预制容易预知难”）；`054` `4,000` 亿鸡蛋市场品牌蛋仅占 `5%`；`089` 全球年损 `13` 亿吨食物下临期食品高意愿仅 `6.06%` |
| **4. 场外冻结型** | 潜在增量庞大 $\longleftrightarrow$ 风险或价格门槛锁死尝试 | `164` 海岛游未访者 `57.54%` 想去却因费用风评止步；`078/082` 自律 APP 意愿 `77.6%` 但拒付 `50%`；`174` 轻食 `51.6%` 因饱腹感与营养疑虑裹足不前 |
| **5. 供给错配型** | 资源技术丰裕 $\longleftrightarrow$ 心智错位与核心诉求落空 | `060` 蜀绣 SEM 广告（`0.591`）与服务（`0.371`）远超面料（`0.097`）；`178` 千年浮梁茶名声显赫 vs 近七成“从未喝过”；`191` 正大农牧心智固化阻滞咖啡心智 |
| **6. 反常识破壁型** | 经验直觉预设 $\longleftrightarrow$ 控制协变量后实证反转 | `158` 打破“独居最爱速食”预设，合住群体购买发生比达独居 `5.300` 倍（`p < 0.001`）；`149` 证实感知风险负向抑制压倒价格；`027` 广告（`> 0.7`）驱动首发却未决定复购 |

### 3.2 第三拍：可测量子问题与后章模型强绑定契约

| 子问题编码 | 核心追问结构（须含可测量指标） | 绑定指标与检验参数 | 承接章节与建模工具 |

### 3.3 `[示范模板]` 三拍开篇范式（短长交错 + 因果克制）

> `[示范模板]`（面向“AI 客服与数字适老化”，短句 `14` 字至长复句 `96` 字交错）：
>
> 截至“十四五”中期，国内头部城市 60 岁及以上常住人口比例已跨越 27% 阈值，伴随智慧政务与线上零售全面渗透，银发群体高频触达数字终端已成常态。**然而，技术覆盖并未等比例兑现为获得感。** 预探索万余条线上差评与基层走访指向同一重撕裂：平台依托自动化应答实现全天候接入，而高龄用户受困于方言识别失准、多层菜单迷失与隐私扣费担忧，长期滞留于“被迫接入却深度失语”的边缘状态，高投入与低留存构成了亟待破解的治理悖论。
>
> 围绕这一母洞察，本文设立四项可测量子问题：其一，银发群体交互流失断点如何按龄层及代际支持分化（第 4 章列联与 `K-Modes`）；其二，界面易用、制度信任与感知风险中，何者位居“高重要—低满意”阻滞区（第 5 章 `IPA` 与改进 `UTAUT-SEM`）；其三，人工转接响应率对持续使用意愿的边际预测是否存在非线性拐点（第 5 章 `XGBoost-SHAP` 与受控情境实验）；其四，供给端在降本考核与适老容错间如何协同（第 6–7 章三方博弈与策略校准）。
