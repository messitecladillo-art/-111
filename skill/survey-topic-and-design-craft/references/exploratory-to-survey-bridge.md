# 大数据预探索与质性访谈向问卷构念转化的“前哨战”指南

> **总纲铁律**：第 2 章“前哨战”的唯一合法职能，是为第 3 章抽样框划界与 `Deff` 定量设计提供依据、为附录问卷锻造操作化题项、为第 4–6 章假设（$H_1 \sim H_n$）提供实证先验。**凡未进入《痛点→维度→构念→题项》映射表、且未在后文触发统计检验的词云、情感图与访谈摘录，一律判定为“装饰性 NLP 孤岛”。**

---

## 一、“数—理—事”三元定位与双轨职能

2023–2025 届国奖样本中，文本挖掘（`text_nlp`）命中率已达 **96.7%（58/60）**，但评审扣分高频集中在“第 2 章展示词云、第 3 章问卷另起炉灶”的割裂断层。高阶工程链路应遵循`发现→测度→细分→归因→决策`（`01_a`）、`大数据破冰→问卷实证→模型归因→实验求真`（`04_b`）及“数—理—事”三角互证（`ocr_01`）。

| 预探索轨线 | 核心数据载体 | 解决的核心盲区 | 向第 3–6 章交付的刚性接口 |
| :--- | :--- | :--- | :--- |
| **线上公域大数据轨** | 电商/OTA/社媒评论、弹幕、搜索指数、迁徙/POI 数据 | 解决“共性痛点是什么、空间热度在哪里、竞品声量差多少” | ① 省/区抽样框与 `PPS` 辅助规模变量（MOS）；② 高频抱怨点转化为量表观测题项；③ 行为阈值对撞问卷自陈偏差 |
| **线下质性田野轨** | 利益相关方深访、焦点小组、自然观察编码、扎根三阶编码 | 解决“未发声群体怎么想、隐性动机与本土口语是什么” | ① 填补标准量表“削足适履”盲区；② 提炼本土口语替代问卷学术黑话；③ 锁定特殊群体配额（如 `003` 自然观察定 `1:4` 男女配额） |

### 2.2 四阶正则清洗漏斗与词库配置

爬取原始语料后，必须在正文交代清洗口径与留存率账本（对标 `Doc 194 表15`：`93,205` 条清洗留存 `80,108` 条）：

1. **去重与防刷单过滤**：按 `用户 ID + 文本 + 短时间窗口` 剔除同一账号机械刷屏、复制粘贴与纯广告帖（`068`, `011`）。
2. **规则正则裁切**：剔除“系统默认好评”、`字符长度 < 2` 无语义短句、纯字母/数字/符号串及无意义表情符（`068`, `01_b`, `02_a`）。
3. **分词与三件套词表**：选用 `jieba`、`jiebaR`（R 语言字典树 `DAG + HMM Viterbi`，`ocr_03`/`ocr_05`）或 `NLPIR`（`022`/`063`），合并加载 **哈工大停用词表 + 领域专有停用词表（剔除品牌名等无区分高频词） + 领域自定义专名库**（`068`, `071`, `ocr_08`）。
4. **结构化落盘**：生成纯净文档-词项矩阵（`DTM`），严禁将含默认好评的粗语料直接喂入主题模型。

## 三、五大前哨挖掘引擎的统计报告契约

**契约原则**：前哨算法不允许只贴图充数，必须按下列契约披露选参依据与向后文传递的特征维度。

| 挖掘引擎 | 核心算法/工具栈 | 最小统计报告契约（必报参数） | 合规视觉与禁区 |
| :--- | :--- | :--- | :--- |
| **关键词与降维** | `TF-IDF`、`Word2vec` + `t-SNE/PCA + DBSCAN`（`03_a`） | 披露停用词裁剪口径、Top-15/20 `TF-IDF` 权重数值及词频对照；`048` 示范：提取“生动程度/信息详细度”联合图像信任度进入树模型 | **禁区**：大篇幅贴低信息量词云而不列表格权重；暴露 `VAR0001` 类原始字段 |
| **语义共现网络** | **`ForceAtlas2`** 语义共现网络（`ocr_01`, `017`, `036`, `120`）、社会语义网络拓扑（`05_a`） | 必报**共现阈值、节点数、边数、模块化社区簇数**及核心枢纽词（度中心性/中介中心性），写明每簇映射哪一问卷构面 | **禁区**：直贴带 `VOSviewer`/`CiteSpace` 右下角水印截图；须导出矢量图并重绘中文标签 |
| **`LDA` 主题发现** | `LDA` 主题模型；可配 `VSM + LSA` 交叉验证（`ocr_07`, `078/082`） | **严禁主观拍定 `K`**！必附 **困惑度（Perplexity）下降曲线与一致性（Coherence）拐点**定 `K` 依据（`01_a`, `ocr_01`）；提倡对**好/差评分别建池跑 `LDA`**（`011`） | **禁区**：只罗列碎词无主题命名；好差评混池导致痛点被正向礼貌词稀释 |
| **情感极性拆解** | `SnowNLP`（`[0, 1]` 区间，`070/073`, `ocr_07`, `080`）、`BosonNLP/HowNet`、`SO-PMI`、`双层堆叠 Bi-LSTM`（`ocr_08`, `093`） | 通用电商训练的 `SnowNLP` 易在非电商域漂移，必附**领域词典微调或随机抽检 ≥200 条人工校验准确率**；区分正负比（`063` 正 `65%`/负 `35%`）与细粒度情绪（`132/133` “恶”超 `70%`） | **禁区**：不经行业校准直接跑文旅/医疗/政务语料；同批正负占比先列三线表再重贴饼图 |
| **宏观搜索与空间** | 百度/微信/巨量指数、百度迁徙、高德 POI | 写明检索词、时间跨度（`ocr_09` 1 年）、区域 Top-N 排序，明示其如何界定第 3 章分层 `PPS` 抽样框或结合 `Deff` 确定样本量（`176` `deff=2.235`、`055` `deff=1.5`、`088` `deff=1.35`） | **禁区**：单贴折线图感叹“关注度上升”，后文仍按校内/周边便利发放问卷 |

## 四、质性预调研与扎根理论三阶编码规程

网评存在年轻化、情绪极化与沉默偏差（`194`, `200`, `162`, `110`, `011`）。非标新领域（`119` 特色水产险）、禁忌议题（`066` 生态葬）或 B/G/C 多边系统，正式定稿问卷前必须执行田野质性预研。

### 4.1 多端采样、田野辅助与饱和度判定

1. **利益相关方配比**：消费端通常深访 **10–20 人**（`087` 10 人、`157` 12 人、`110` 14 位斜杠青年 `S1–S14`），或采用 `KOL 深访 + 焦点小组`（`053` 访 5 位跑团团长各 90 分钟 + 3 地 12 组共 96 人座谈得 **13 万字**逐字稿、提炼 **27 项**痛点）；供给/管理端须纳入店长（`07_a`）、院团专家（`ocr_09`）、五方代表（`060`）或三方联动（`09_a`）。
2. **田野辅助技术**：线下卖场配合自然观察量化编码定配额（`003`）或无提示品牌认知实验（`071`）；敏感议题须先做半结构访谈转特征辞典再部署 `PPS`（`066`）。
3. **理论饱和度门槛**：转录双人校对后按序编码，连续 **2–3 份**新增访谈不再析出新概念与新范畴关系时宣布饱和并停止扩样。

### 4.2 扎根三级编码流水线与三线表规范

依托 `NVivo` 或双人背对背编码（分歧由第三人仲裁）推进三阶抽象：
- **开放式编码**：贴近原生语句贴标签提炼概念与“故事线”（实证参考：`ocr_04` `43` 概念、`119` `109` 概念），**沉淀本土口语词库**（`087`, `088`）消除问卷翻译腔。
- **主轴式编码**：按“因果—现象—脉络—中介—策略—结果”归并主范畴（实证参考：`ocr_04` `6` 主范畴、`119` `10` 主范畴、`179` `5` 主范畴）。
- **选择性编码**：凝练核心范畴（Mother Insight 原型），嫁接经典骨架：`S-O-R`（`ocr_04`, `120`）、`UTAUT/TPB/TAM`（`094`, `180`, `093`）、`SSO`（`183`）、`AISAS` / `SICAS+S-N-G` / `Hooked+FBM`（`086`, `104`, `111`）、`PRICE`（`050`）、`CCSI/SERVPERF/5GAP`（`127`, `168`, `190`）。

## 五、核心焊缝：痛点→维度→构念→题项→模型全链路转换

### 5.1 四步焊接准则（对接 `survey-questionnaire-architect`）

1. **多源证据合并去重**：整合 `LDA` 负向主题、`ForceAtlas2` 枢纽节点、`SnowNLP` 高负向原文及扎根主轴范畴，按“频次 × 负向情绪强度”排定核心痛点清单，确保有词必有题、有题必有据。
2. **本土构念增补**：拒绝“削足适履”（`119`），将文献未覆盖痛点增设为潜变量或调节项——如 `094` 在 `UTAUT` 嵌入感知风险、感知信任与创新性；`132` 纳入本土特色、产品创新、服务独特性作 `PLS-SEM` 调节变量；`104` 验证“多变酬赏”的关键中介路径。
3. **口语转译、可识别约束与双轨路由**：
   - 每个潜变量**配置 `>= 3–4` 道观测题项**，保障后文 `CFA`/`SEM` 模型可识别并满足 `RMSEA`、`AVE`、`CR` 检验要求；
   - **题干零学术黑话**：严禁出现 `PU/PEOU/主观规范` 等术语，全部转译为原生访谈口语；
   - **单题单归因**：严禁“价格和包装满意度如何”类双管齐下设问；
   - **物理双轨分流**：按“已购存量 vs 未购/流失增量”部署跳转路由（`074`, `105`, `175`, `107`），分别测度粘性断点与认知门槛，杜绝均值掩盖矛盾。
4. **预调查双重净化与修正对照**：前哨题池经 `N = 100–200` 预调查（`022` `N=237`）后，执行高低 `27%` 极端组 CR `t` 检验（`127`, `158`, `177`）、`CITC` 与 `α/KMO` 净化，删改脱节题项（如 `029` 删除“月消费/职业”题、`030` 开放题分词后重构二次调查、`133` 由 `60` 题池筛敛），并附《修正题项对照表》（`129 表13`, `105 表1`）。

## 六、择优隔离清单：国奖可学机制 vs 红队一票否决陷阱

即便是国奖原文，亦常混杂截面伪因果、样本冒充与可视化硬伤。编写第 2–3 章时必须执行以下刚性切割：

| 审查维度 | 必须借鉴的高阶结构机制（Learn） | 必须封杀的红队致命陷阱（Quarantine） |
| :--- | :--- | :--- |
| **1. 链路整合度** | 建立表 2-2 级映射表，让第 2 章输出成为第 3 章题池唯一合法来源，第 7 章 `QFD` 质量屋再回扣痛点（`190`） | **装饰性 NLP 孤岛**：第 2 章堆砌词云、共现图与情绪饼图，第 3 章问卷却另抄他人量表，通篇无接口 |
| **2. 网络偏差处理** | **线上锚定 + 线下概率互证**：借鉴 `078/082` 声明网评偏差后转向线下 `PPS`；`201/202` 用迁徙或综合指数赋权；`080` 用弹幕对撞自陈 | **网评替代总体推断**：仅凭社媒评论占比断言“全国用户最痛恨 X”，或把便利线上链接套用 `SRS` 精度公式 |
| **3. 量表开发逻辑** | **扎根内生构念**：借鉴 `119` 拒套大宗标准量表，田野编码 `109` 概念→`10` 主范畴，并注入受访者原生口语 | **量表削足适履与黑话直译**：生搬硬套无关领域量表；将“感知有用性/主观规范”直接印入问卷题干 |
| **4. 异常信号处置** | **异常信号专题升格**：借鉴 `088` 发现受访者普遍把网红“泸溪河”误认百年老字号后，未当噪声丢弃而是升格为竞品专题 | **机械删异与强行洗地**：遇到反常识高频误答，不溯源访谈动因直接删除，或将超阈值拟合硬说成良好 |

## 七、可复制实战工具箱：过渡桥句型、Agent 提示词与出关门禁

### 7.1 无缝衔接章间过渡桥句型（严格去 AI 八股）

1. **网络预研 → 线下概率抽样纠偏**（`[示范模板]`，参照 `078/082`、`011/046` 逻辑精修）：
   > “依托 `46.81` 万条电商评论的 `LDA` 主题聚类与 `SnowNLP` 情绪拆解，本研究初步锁定了连接故障与售后推诿等高频摩擦点。然而，公开网评天然带有极化表达与年龄倾斜等自选择偏差，无法反映全谱系目标客群的概率分布。为此，第 3 章基于百度搜索热度划定区域抽样框，启动多阶段分层 `PPS` 实地调研以剥离上述偏误。”
2. **质性扎根编码 → 量表构造与预调查净化**（`[示范模板]`）：
   > “尽管既有文献提供了 `UTAUT` 等成熟框架，但 `14` 份深度访谈的扎根编码显示，‘换壳加价反感’与‘同伴实测触发’构成了既有量表未能覆盖的本土决策边界（主轴范畴 `A2–A3`）。本章据此将 `6` 个主轴范畴操作化为 `24` 道日常口语题项，并在 `N=160` 预调查后经极端 `27%` 区分度检验剔除冗余指标，完成向正式问卷的收敛。”
3. **问卷自陈局限 → 平台行为大数据/情境实验对撞**（`[示范模板]`，参照 `080`、`184` 逻辑）：
   > “问卷数据印证了受访者主观上对商业化植入的普遍抵触，但事后自陈易受回忆漂移与社会赞许性误差干扰，难以测定微观容忍极限。后续章节将引入目标社区真实弹幕情绪序列（或受控情境 AB 实验），在行为层面对问卷统计结论实施交叉校准。”

### 7.2 AI Agent 协同操作提示词（可直接复制）

#### Prompt A：文本清洗与 `LDA` / `SnowNLP` 契约审查
```text
作为市场调研文本挖掘工程师，请处理附件原始评论语料并严守下列报告契约：
1. 执行四步清洗漏斗：按账号+文本去重、剔除系统默认好评、剔除长度<2字符短句、剔除纯字母数字符号及机械刷屏，输出【清洗前条数→各步剔除数→留存DTM条数及留存率】表。
2. 分词合并加载哈工大停用词表与本行业专有停用词/自定义词典（列出新增的20个专名与停用词供人工核验）。
3. 将语料按好/差评分池后分别训练 LDA 模型，先计算并输出 K=2..12 的 Perplexity 与 Coherence 拐点数据论证最优 K，严禁主观拍定 K。
```
