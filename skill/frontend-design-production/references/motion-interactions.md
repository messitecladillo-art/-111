# 动效、滚动与指针交互

## 先定义行为

用 `对象 → 输入/触发 → 有效范围 → 过程 → 终态 → 取消/恢复` 表达效果。补充触屏、键盘和减少动态时的操作方式。参数由内容和验证决定，演示时长、强度和粒子数量不是默认要求。

| 需求 | 可以先评估的方式 | 额外条件 |
|---|---|---|
| 简单状态过渡 | CSS/已有过渡 | 属性变化、减少动态、焦点与终态 |
| 多元素先后与重叠 | 现有动画工具或时间轴 | 取消、反向、同步、重新挂载 |
| 进入视口揭示 | 已有观察器或滚动工具 | 不隐藏必要内容、加载后布局变化 |
| 滚动固定与叙事 | 合适的滚动编排工具 | 测量、区间、逆向与退出 |
| 局部跟随/追光 | Pointer Events 与局部坐标 | 范围、取消、命中测试、触屏 |
| 排序/转移 | 现有拖拽能力或适当实现 | 占位、目标、提交、替代入口 |

只为需要的能力新增依赖；已有能力足够时不重复接入另一套系统。

## GSAP / ScrollTrigger

采用时核对安装版本的官方 API。定义 start/end、固定区间、阶段顺序和退出表现；scrub 绑定滚动进度，tween 时长体现时间轴的相对区间，不等同于自动播放的实际秒数。

- 固定容器与被动画内容分开；动画内部元素，避免破坏 pin 的布局测量。
- update 更新当前滚动位置；字体、图片或尺寸改变布局后，需要重新测量时使用合适的 refresh 路径。不要每帧重测。
- 框架生命周期中绑定作用域并撤销本次实例；不清理其他组件的全部动画。context 中稍后事件新建的动画需要进入相应收集范围，自定义资源另行清理。
- 同时采用平滑滚动工具时核对集成机制，避免重复循环、监听和相互竞争。
- 正反、快速滚动与尺寸变化之后内容仍可读。减少动态保留完整内容，不只把时长缩短。

## 指针跟随与悬停

按元素边界计算局部坐标；布局或页面滚动改变边界时更新测量。装饰层不截获点击。装饰环可以缓动，定位、准星、点击目标和操作反馈保持及时。

在适当的指针能力下启用 hover 装饰。触屏保留正常操作，键盘保留焦点和必要内容；真实功能不能只靠 hover 暴露。自定义光标有可靠回退，避免脚本未加载时隐藏系统指针。

pointer capture 重定向后续事件，不会把指针锁在区域内；捕获期间的离开事件不能作为唯一取消依据。处理 pointerup、pointercancel、lostpointercapture，提交与清理幂等。只给实际需要的区域设置 touch-action，并在手势开始前确定；不能在手势中才改变它来接管滚动。

## 拖拽与手势

分别定义排序、落区、占位、跨列表转移、边缘滚动、回弹或合并。合并说明业务结果；视觉贴近不代表业务条件成立。

状态覆盖等待、激活、有效/无效目标预览、提交或回弹、完成/失败。阈值按设备误触与滚动冲突验证。拖动中不先删除真实对象；异步提交失败保留或恢复数据，允许重试/撤销。

提供无需拖动的点击/轻触等价入口，例如选择后指定目标、上移/下移按钮、选择文件。键盘也能完成操作，但键盘支持不能代替无需拖动的单指针入口。原型的两帧智能动画只表达状态转场，网页仍需连续跟随、目标判断和数据提交。

## 验收重点

验证离开边界、取消、丢失捕获、快速重复输入、目标失效、提交失败和重新挂载。按功能检查滚动冲突、替代操作、内容完整性、减少动态。记录条件和步骤；未执行的设备测试不计为通过。
