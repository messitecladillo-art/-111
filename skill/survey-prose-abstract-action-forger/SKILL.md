# 学术修辞、摘要与对策锻造师（Prose, Abstract & Action Forger）

基于全量 205 篇国奖正文的统计语言学指纹（2023–2025 届句长均值 `67.9` 字、标准差 `38.3` 字；全库因果词 1,083 次 vs 克制关联词仅 114 次的高危对比），专门消除调研报告中的**AI 公文八股味、截面伪因果、摘要溢出散架、以及“政企民万能对策”**四大软肋。

## 一、摘要严格控页与五步高密架构

实测对比（A4 `宋体小四 12pt + 1.25x 行距` 单页约容纳 **900–1,050** 中文字符）：2023–2025 文本中位摘要长达 `1,574` 字导致普遍跨页。务必择一锁定：
- **A 方案（单页紧缩黄金版，900–1,020 字）**：严锁单页、零溢出，适合篇幅紧张的 65 页总限项目；
- **B 方案（双页高密执行摘要，1,500–1,850 字）**：明确规划 2 个整版，**严禁**出现如部分获奖作“第 1 页塞满 + 第 2 页悬空溢出 4–10 行”的尴尬排版。

统一按 **5 步节奏**推进，并用主题色/加粗标定 **8–12 个核心实体与模型关键词锚点**（10 秒扫视定位）：
1. **宏观背景与结构性张力**（100–140 字）：大盘事实迅速转折出具体市场痛点与核心研究问题；
2. **多源探索与抽样质控规格**（150–200 字）：交代爬虫语料量 + 抽样方法 + 有效 `N` 及有效率 + 信效度阈值；
3. **阶梯式实证核心发现**（350–450 字）：按“现状→分群→机理/预测→访谈”嵌死具体百分比、`OR`/路径系数/排名第一特征；
4. **模型推导的分层对策矩阵**（160–220 字）：显式关联工具（STP / 4P / IPA / QFD）给出靶向建议；
5. **实证价值与收敛**（60 字以内）：**禁止**结尾强行押韵喊“借时代春风绘就壮美蓝图”口号。详见 [五步控页摘要蓝图](references/abstract-five-step-blueprint.md)。

## 二、去 AI 行文三大铁律

1. **句长爆发度（Burstiness）调律**：把 AI 最爱的均长 40–55 字四平八稳句，刻意拆打成 **“12–25 字冷峻定性短句 + 80–120 字高密统计分析复句”** 的交错波形（对齐国奖真实方差基准 `std ~38.3`）。
2. **套话词黑名单清零**：全篇实测高频重灾词必须清零或替换为统计推理转承句（详见 [去AI词汇表与统计嵌入句型](references/deai-academic-prose-lexicon.md)）：
   - **封杀榜**：`综上所述 / 总而言之 / 由此可见 / 值得注意的是 / 与此同时 / 赋能（23-25年激增至 53/66 次）/ 闭环 / 抓手 / 全方位 / 具有重要意义 / 不言而喻 / 双刃剑 / 毫无疑问`。
   - **高级替代**：`交叉卡方检验揭示…… / 控制人口学协变量后，边际效应表明…… / 与整体正态基线形成反差，该群体在……上呈现……`。
3. **截面数据严守“因果克制文法”**：单时点问卷无工具变量（IV）、双重差分（DID）或随机实验支撑时，一律把 `导致 / 促使 / 决定了 / 显著提升了` 降级为 `显著正向关联 / 统计显著预测 / 边际贡献位列首位 / 潜在传导路径显示`。

## 三、四要素商业/工程对策闭环

绝不输出“政府加强监管、企业提升质量、居民提高认知”的空心八股。每条核心建议必须逐项填实 **4 要素**，详见 [四要素可考核对策模式库](references/actionable-recommendations-patterns.md)：
`[① 前文实证断点（图/表序号+具体指标差值）] → [② 精准执行主体] → [③ 依托 PEST/SWOT/STP/4P/QFD 的具体工艺、渠道、算法或机制抓手] → [④ 可考核量化 KPI / 时限与成本/ROI 约束]`。
