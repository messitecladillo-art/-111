## 一、视觉排版底层基准与篇幅硬边界

国家级市场调查与分析报告的视觉系统并非装饰工程，而是统计学严谨性与商业咨询交付力在版面维度的直接投影。对 2023–2025 年 205 篇国奖报告及 2024 年国一逐页渲染 PNG 样本的底层字符解析表明，顶尖报告在字体解耦、字号层级与篇幅分布上高度收敛于科研智库范式。

### 1.2 中英数公式四轨解耦与版面呼吸律

1. **正斜体统计学铁律**：变量具体观测取值与常规缩写用正体（如 `OR = 1.775`、`VIF < 2.1`），统计学检验量与模型参数严格使用 `Times New Roman` 斜体（*$p, t, F, z, R^2, \chi^2, \beta, df, \text{KMO}, \text{RMSEA}$*）。**严禁**出现全角英文数字或宋体直立字母混排回归系数。
2. **页面几何与密度基准**：标准 A4 版心（上下边距 `2.5–2.54 cm`、左右 `2.8–3.18 cm`）；正文固定行距 `18–22 pt`（或 `1.25–1.5` 倍），段前段后 `0.25–0.5` 行（或零空行），首行缩进 `2` 字符，两端对齐，单页版面填充率维持 `82%–85%`（约 `750–900` 字），严禁章末出现大块无效留白。
3. **句长韵律控制（Burstiness）**：国奖全集正文平均句长收敛于 `55–69` 字，标准差 `33–40` 字——以 `70–90` 字高密度复句交代抽样约束与统计边界，紧接 `15–25` 字短断言句敲定实证结论，拒绝 AI 生成式均质短句与窒息长句。

## 二、1+1 中性克制色板体系与行业语义色谱

国奖报告彻底封杀商业 PPT 式高饱和三原色、荧光渐变及 Excel 默认彩虹调色盘，严格执行 **“1 个中性灰黑基底 + 1 个行业语义主色（外加 ≤ 10% 微量警示点缀）”** 的 **`50 / 40 / 10` 克制配比**：中性无彩色系承接 `50%` 以上的文本、表线与背景框；行业语义单色占 `≤ 40%` 用于主数据柱、流程图节点与标题角标；纯红等高饱和警戒色占 `≤ 10%`（如全篇 172 页仅出现 `40` 次 `#ff0000`，或 `136` 全文仅出现 `10` 次），且仅限标注显著性断点、负向风险路径与 IPA 急需改进区。

## 三、跑眉主题口号、极简矢量角标与双细分隔线规范

### 3.2 跑眉、角标与摘要单页装配四准则

1. **跑眉口号（Running Header Slogan）**：长度严格控制 **8–16 个汉字**，提炼自调研地文化意象或核心商业命题；正文页可设“奇数页印全篇口号、偶数页印当前一级章名”，字号 `9.0pt` 宋体或楷体，颜色 `#595959`（或主题色）。
2. **极简矢量角标（Topic-Semantic Mini-Emblem）与盲审红线**：角标尺寸锁定 **`8 mm × 8 mm` 至 `12 mm × 12 mm`**，线宽 `0.75–1.0 pt`，纯矢量 SVG 单色（或双色）绘制，内容**仅限行业符号或研究对象抽象图标**（如茶芽、餐碗、铁锚、电路节点）。**绝对红线**：严禁出现校徽、院徽、竞赛团队 Logo、指导教师姓氏暗记或高校建筑剪影。
3. **双细分隔线（Double Thin Rule）**：采用“**主线 `1.25–1.5 pt` + 副线 `0.5 pt`，线间距 `1.5–2.0 pt`**”的双细平行线（主色调 `#12a152` / `#0070c0` / `#000080`），通栏置于页眉文字底缘下方 `3–4 pt` 处，切忌使用 Word 默认加粗黑线或花边艺术边框。
4. **摘要版面完整收口与语义着色**：摘要既可紧缩收口于单页（约 `750–1,000` 字），也可规划为高密整两页（约 `1,500–1,850` 字）；唯一要避免的是“第 1 页塞满 + 次页悬空溢出 3–10 行”的断尾排版。借鉴 `178_p2` 视觉语法：可适度对**核心方法与关键发现词**施加“加粗 + 唯一主题主色”，零空洞口号填充。

## 三之二、代码统计图 × 生图模型视觉协同边界（不写死章节，只守真伪线）

在报告制作中，不必把“哪里能用生图、哪章只能用折线”写成教条；真正需要守住的是**“数值真伪权归代码，美学隐喻与氛围权归生图”**的双轨分工：

1. **代码实现层（承载数据、比例、地理与检验关系）**：涵盖 EVI-X 原生矢量图与 Python/R/SVG 导出图（分布图/雨云图/发散李克特/森林图/IPA/SHAP/SEM/桑基/Van Westendorp 等），按**数据结构和对比需要**自由出现在样本描述、建模推理或对策落地各节，背景保持纯白并允许使用极淡水平参考线（`#e5e7eb`）辅助读数。
2. **生图模型层（承载封面、可选页框、概念机制与视觉元素）**：
   - **封面底图与页框**：可依托抽象肌理、行业意象光影或极简角标确立第一印象；须保证文字叠放区足够素净、正文边距和字号不受装饰挤压，且零校徽/队名泄漏。
   - **概念机制图与场景示意**：可用于绪论张力导入、问卷结构隐喻或对策协同模式示意，**但严禁图内出现模型凭空生成的伪坐标与假统计值**，且须在图注标明“概念示意”。
   - **混合复合信息图**：生图只贡献图标或版式灵感底稿；一旦涉及样本量 `n`、占比条带、维度均值或分母切换，必须回归代码/确定性 SVG 合成。

### 3.3 Word/LaTeX 跑眉与摘要视觉装配指令 `[示范模板]`


### 4.3 高阶模型制图视觉规范与标准三线表契约

#### 1. 高阶计量与机器学习必备矢量图型
* **回归效应可视化——森林图（Forest Plot）**：禁止用繁冗文字报出十几个哑变量优势比。横向绘制效应点估计与 **`95% CI` 误差棒**，垂直虚线锚定零效应线（线性/Logit 系数图锚定 `0`，优势比图锚定 `OR = 1.0`），左右分列显著正向因子与跨线不显著因子（标杆：`197` 图25、`148` 图15）。
* **黑箱模型可解释性——SHAP 与特征重要性**：机器学习（XGBoost/LightGBM/Random Forest）必须脱离单纯精度对比表，叠加特征重要性水平条形图与 **SHAP 蜂窝图 / 瀑布图 / 依赖散点图**（标杆：`180` 第7章、`170`）。
* **惩罚回归与降维证明**：LASSO 须并置 **10 折 CV 误差曲线（标注 `lambda.min` 与 `lambda.1se` 垂直虚线）+ 系数解路径图**（`139` 图7-1/7-2）；高维聚类须附 **手肘法/轮廓系数拐点图** 及 **t-SNE 二维流形散点边界图**（`118` 图9、`172` 图27），回击“聚类簇数主观拍脑袋”质疑。
* **矢量 SEM 结构方程路径图**：严格遵循 **椭圆（潜变量）+ 矩形（观测题项）+ 圆圈残差（$e_1\sim e_n$）** 制式；每条箭头标注标准化路径系数 $\beta$ 与显著性星号（`***`），**不显著路径改用虚线**（`160/162`），M.I. 残差修正必须绘出双向弯曲协方差弧线（`e8↔e9`，`082` 图6-6），图底统一附注全套适配度指标（$\chi^2/df, \text{RMSEA}, \text{CFI}, \text{GFI}$）。

#### 2. Booktabs 标准三线表硬性物理契约
* **线宽与去网**：顶线与底线粗 **`1.5 pt`**（可容忍 `1.0–1.5 pt`），栏目分隔线粗 **`0.5–0.75 pt`**；**零竖线、零斜线、零高饱和彩色单元格填充**（超长表可设极淡微灰斑马纹 `#f2f4f7` 辅助视距跟踪）。
* **对齐与续表**：数值列严格按**小数点或个位数垂直对齐**（计量系数通用保留 3 位小数），显著性星号居右悬挂；缺项统一用 `-` 占位；**跨页表格必须在次页左上角标注 `续表 X-X` 并完整重现表头**。
* **标题与表注**：表题居中置于**表上方**（五号黑体或小四宋体加粗），图题居中置于**图下方**；表/图底缘紧贴小五号（`9.0pt`）宋体注明 `数据来源：课题组实地调查测算 / 第七次全国人口普查` 及 `注：*p<0.05, **p<0.01, ***p<0.001`。

| 强制用表场景 | 最低统计学汇报字段契约（缺一即红队扣分） |
| :--- | :--- |
| **多阶段 `PPS` 抽样表** | `层/区名 \| 规模度量 MOS (Mi) \| 占比(%) \| 累计区间 [1, M0] \| 计算机随机数命中值 \| 入样标识 \| 理论与修正配额` |
| **量表净化与区分效度表** | `构念/题项 \| CITC \| 项删除后 α \| 总 α \| KMO & Bartlett χ²(df, p) \| 因子载荷 λ \| AVE \| CR`（区分效度矩阵对角线放 $\sqrt{\text{AVE}}$） |
| **Logistic / 分层回归表** | `变量(参照组) \| B \| SE \| 标准化 β \| Wald/t/z \| p \| Exp(B)/OR (95% CI) \| VIF`；底栏报 `-2LL`, `伪 R²`, `平行线检验` / `H-L 检验` |
| **SEM 路径与适配度表** | 适配度表列 `CMIN/DF, RMSEA, GFI, CFI, TLI, IFI` 的参考阈值 vs 实测值；路径表列 `路径方向 \| 标准化 β \| SE \| CR \| p \| 假说裁决` |

### 4.4 制图文本与标签清洗四重防线

视觉审计实测暴露，高分报告极易在制图末期因软件默认输出直接粘贴而爆发四类低级文字污染，生成阶段必须强制拦截：

1. **防线一：清零原始软件聚类与代码标识**
   * **反例**：可视化与表格中直接保留 `聚类类别_1`、`Cluster_2`、`Scene1~5`、`Q7R3` 裸标签。
   * **规则**：所有图表坐标轴、图例与表格首列必须映射为**中文业务命名**（如 `理性功能型`、`轻食新锐群`），仅允许在“问卷变量编码字典表”中以括号附注原始字段代号。
2. **防线二：隔离未汉化英文字段名**
   * **反例**：回归系数表或特征重要性图纵轴残留 `gender`、`age`、`Satisfaction`、`IncNodePurity`、`Mean Decrease Accuracy` 等 R/Python/Stata 变量名。
   * **规则**：图形标签一律全中文规范命名；统计缩写保留英文仅限于公认计量符号（如 `Odds Ratio`, `RMSEA`, `SHAP`, `AVE`）。
3. **防线三：阻断路径图与图例自指错字**
   * **实测高危反例**：`170_p48` 模型路径图出现 **`行为意向->行为意向`** 逻辑自指死循环错字；`170_p65` 图表标签将 **“分享”误作“分析”**；`170_p2` 摘要出现 **`“旅游旅游客源”`** 叠词。
   * **规则**：所有 SEM/DAG 路径图导出前必须逐一校验 `起点变量 ≠ 终点变量`，并执行高混淆双音节词（`分析/分享`、`意向/意愿`、`满意/建议`）专项拼写扫描。
4. **防线四：统一标点与编号空格规范**
   * **实测反例**：`174_p77` 出现 `1.轻食餐饮...`（句点后缺空格）与 `2. 女性消费者...`（句点后多空格）混排。
   * **规则**：全篇统一中文编号格式（如 `1.` 后统一无空格或统一半角 `1` 空格），严禁同一层级混用。

```python
# [示范模板] 森林图 (Forest Plot, OR & 95% CI) —— 替代枯燥回归长段文字与 Excel 丑图
import matplotlib.pyplot as plt
import numpy as np

# 1. 严禁裸露英文字段名，全部映射规范中文业务标签
labels = ["信息清晰易懂", "育有未成年子女", "中等收入(8k-12k)", "60岁以上群体", "仅提供伪个性化"]
ors = [1.775, 1.850, 1.434, 0.230, 1.120]
ci_low = [1.024, 1.210, 1.005, 0.140, 0.785]
ci_high = [3.076, 2.828, 2.046, 0.378, 1.598]
p_sigs = [True, True, True, True, False]  # False 跨 OR=1 虚线

y_pos = np.arange(len(labels))
fig, ax = plt.subplots(figsize=(6.8, 3.6))

# 2. OR = 1.0 基准垂直虚线
ax.axvline(1.0, color="#595959", linestyle="--", linewidth=1.0, zorder=1)

# 3. 1+1 克制配色：显著项主色 #0070c0，不显著项退为中性灰 #808080
for i, (y, or_v, lo, hi, sig) in enumerate(zip(y_pos, ors, ci_low, ci_high, p_sigs)):
    color = "#0070c0" if sig else "#808080"
    ax.errorbar(or_v, y, xerr=[[or_v - lo], [hi - or_v]], fmt="o", color=color,
                ecolor=color, elinewidth=1.6, capsize=3.5, markersize=6, zorder=3)
    ax.text(hi + 0.08, y, f"OR={or_v:.3f} [{lo:.2f}, {hi:.2f}]",
            va="center", fontsize=9, color="#212529" if sig else "#595959")

ax.set_yticks(y_pos)
ax.set_yticklabels(labels, fontsize=10, color="#212529")
ax.invert_yaxis()
ax.set_xlabel("优势比 Odds Ratio (95% 置信区间)", fontsize=10, color="#333333")
ax.set_xlim(0, 4.1)
ax.grid(axis="x", color="#e5e7eb", linestyle=":", linewidth=0.6)
plt.tight_layout()
fig.savefig("forest_logit_clean.svg", format="svg", bbox_inches="tight")
fig.savefig("forest_logit_clean.png", dpi=300, bbox_inches="tight")
```
