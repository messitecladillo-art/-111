# 图表双轨选型全谱系与上下文逻辑指南（代码图 vs 生图模型）

本手册确立**“真伪从严、选型从活”**的视觉表达总则：凡承载真实样本数值、比例、统计量、置信区间与地理边界的图件，**100% 必须由代码从冻结数据确定性绘制**；凡承担视觉隐喻、版式底纹或无数字概念示意的图件，方可由生图模型生成或通过“生图纹理+代码数据”混合合成。表中所列“常见出现区域”均为经验参考落点，可随报告母型（M1–M6）与叙事节奏自由调序或合并，**切忌机械套死章节**。

## 一、底层分工原则：表 vs 代码图 vs 生图模型

| 维度 | Booktabs 三线表（审计真伪） | 第一轨：代码实现图（量化推理） | 第二轨：生图模型 / 混合图（叙事与美学） |
| :--- | :--- | :--- | :--- |
| **核心职责** | 保留精密参数、显著性星号、标准误、`CI`、样本分母与多算法客观 PK，供评委核验可复现性。 | 依靠真实坐标、比例长度、面积或力导向布局，把分布、极差、象限优先序与非线性拐点直观拉出来。 | 建立课题视觉气质、解释抽象机制流程、组织复合摘要概览或提升封面/章首辨识度。 |
| **硬性底线（不可破）** | 顶底粗线 `1.0–1.5pt`，栏目线 `0.5–0.75pt`，无竖线/斜线；表题**居上**；小数点对齐；跨页标`续表`并重申表头。 | 所有数据绑定已确认结果或原始数据计算；绝不用含 `VOSviewer` 等软件水印的截图、Excel 3D 畸变图或原始变量名（`聚类类别_1`）。 | **绝不由生图模型捏造真实数字、伪坐标刻度或冒充实地照片**；参赛盲审版本中零校徽、零团队名、零 EVI-X 品牌水印。 |
| **弹性空间（可活配）** | 字段列随模型精简增删；人口学一般压入一张紧凑总表，无需每个单题单独占页。 | 同一分析意图往往有 2–4 种等效好图（如分布既可看**雨云图**、也可看**分组小提琴**或**点带图**），按样本量与群组数灵活择优。 | 复合信息图建议走“生图提供概念元素/排版草图 + 代码精确绑定冻结数值”的混合路径；概念图可标明示意性质后按需放在绪论、章首或案例节。 |

### 2.2 样本分布、量表质量与分群比较类

| 分析意图与数据结构 | 候选好图谱与渲染来源 | 常见出现位置与上下文咬合逻辑 | 选图提示与避坑 |
| :--- | :--- | :--- | :--- |
| **单题/多题李克特态度分布** | **李克特发散堆叠条形图** `[EVI-X 原生 likertPlot]`；**题项均值比较点图** `[EVI-X 原生 item_mean]` | **常现于**：描述性分析核心节，一次性总览全量表感知水位。<br>**上下文**：从“总体均值看不出高低极化”切入 → 以中性分值为中轴左右发散展示赞同/反对比例 → 点出首末反差题项，引出后文差异或归因检验。 | 比逐题贴柱图/饼图省掉大量篇幅，且直观暴露“中间派占比过高”或“两极撕裂”。 |
| **连续变量分布、偏态与多群对比** | **分组雨云图** `[EVI-X 原生 raincloud/group_raincloud]`；**小提琴/箱线/点带图** `[EVI-X 原生]`；**组均值哑铃点图** `[EVI-X 原生 dotPlot]`；**棒棒糖图** `[EVI-X 原生]` | **常现于**：样本描述、方差/非参数差异检验与多维度群体对比节。<br>**上下文**：用假设检验确认组间差异有统计学意义后 → 雨云图同时给核密度轮廓、四分位和散点，哑铃点图高亮同维度不同群组跨度 → 说明“某组不仅均值低，尾部离散度更大”。 | 样本极小（`n<15`）时不硬画平滑密度小提琴，改点带图/箱线图更诚实。 |
| **结构构成与双维交叉关联** | **双向百分比堆叠图 / 马赛克图** `[EVI-X 原生]`；**双层嵌套环形图 / 旭日图** `[Python/R]`；**样本华夫格图** `[EVI-X 原生 waffle]`；**NPS 三段堆叠对比图** `[Python/R]` | **常现于**：样本代表性核验、列联 `χ²` 分异或口碑诊断节。<br>**上下文**：单变量人口表放进紧凑三线表即可；当要看“代际×渠道/高活跃×低活跃”双维关联或结构占比落差时再配百分比堆叠或马赛克图，高亮反差最鲜明的格子。 | 多选题不画满圆饼图（改水平条形图并写明分母口径）；类别 `>5` 且长尾多优先降序水平条。 |
| **量表信效度与聚类降维** | **删项 `α` 与校正题总相关图** `[EVI-X 原生]`；**因子陡坡碎石图** `[EVI-X 原生 screePlot]`；**标准化聚类中心对比图** `[EVI-X 原生 clusterProfilePlot]`；**多维分组雷达图** `[Python/R]`；**t-SNE 流形边界散点** `[Python/R]` | **常现于**：质量检验（前测净化/EFA）与客群画像节。<br>**上下文**：文字交代删题前后的指标提升与选 `K` 准则 → 雷达图（维度 `≥5` 且簇 `≤4`）叠绘各群短板轮廓 → 给出精准业务人群命名，并用未参与聚类的外生变量校验有效度。 | 禁用仅带 `Cluster_1` 等代码标签；雷达图层过多相互遮挡时改用哑铃点图/小倍图。 |

## 三、第二轨：生图模型驱动与混合视觉资产（适用边界与上下文）

生图模型擅长**建立主题美学质感、具象呈现调查场景和辅助复合构图探索**，但其底层机制决定它无法承担精确统计学测量。在竞赛/科研工作流中的合理用法分为四类（可参照 `research-descriptive-infographics` 与 `research-report-frame`）：

| 视觉类型 | 生图模型职责 vs 代码职责 | 典型落点与上下文功能 | 真实性与合规注意 |
| :--- | :--- | :--- | :--- |
| **1. 主题封面底图**<br>（如 `report_cover`） | 生图生成低干扰抽象肌理、行业意象光影或几何等高线背景，留出顶部浅色负空间；标题文字由排版引擎叠放。 | 独立封面页；奠定“1+1”色调基准与高级智库第一印象，免去廉价矢量素材拼接感。 | 严禁模型生成随机乱码英文/中文；严禁携带学校名称、导师暗示或赛事官方标徽（匿名盲审零泄露）。 |
| **2. 极简学术页框与角标**<br>（如 `report_frame`） | 可选用生图探索极简角标纹样或边缘微细肌理，但正文页心（约 `75%+` 中央区域）须纯白防遮挡；正文几何边距保持不变。 | 页眉角落微徽标或章首页过渡框（若当届通知明确禁用任何装饰页框则跳过不加）。 | 不为塞饰纹而缩小正文字号、挤占表格跨页或撑破合并 `≤65` 页篇幅总控。 |
| **3. 无数字概念与场景插画**<br>（如 `section_illustration`） | 生成宏观研究背景情景、多主体协同关系（B/G/C 互动）、服务体验痛点情景分镜等**纯定性概念视觉**。 | 绪论开篇破题、章首导言、对策模式示意图或典型情境展示。 | **绝不出现伪造数字、坐标刻度或统计曲线**；需在图注如实标明“概念机制示意”，不可把生成人物/场所当成实地访谈照片。 |
| **4. 复合描述信息图**<br>（混合流水线 `AI + 代码`） | **职责切片**：生图仅可承担**主题小图标、版式灵感草图或装饰性氛围块**；所有样本量、百分比条带、均值刻度、对比面板与单位标签**必须由代码从同源结果快照合成**。 | 摘要视觉速览页、人口/行为概览总图，或把多条相关描述发现收束为一张高密 BENTO 编辑图。 | 确保不同面板若源自多选题或条件子样本，各自保留真实分母标注；不同真实性级别（如模拟 vs 实证）不得混拼在同一面板内。 |

## 四、上下文织造心法（保持叙事弹性，拒绝另一套八股）

1. **原理从严，句法从活**：图表配套文字不必死板照搬固定四段开场白，只需确保**读前知道“为什么看”、读中能定位到具体编号与关键反差、读后能推进观点或触发下一阶检验**。有时“短句先抛反常识极值，再紧跟括号检验量与图号”比机械四步更有爆发力。
2. **一图一任务，不唯“多”论英雄**：实证强弱不靠图种数量堆砌；样本简单时，**发散李克特图 + 森林图 + 一张交叉重点表**就足够打穿论证，不必为了凑高阶而硬插意义薄弱的复杂网络图。
3. **跨章呼应而非各自为政**：每一幅关键图表尽可能在后文至少被消费一次（前哨气泡映射进第 3 章构念、第 4 章聚类雷达喂给第 7 章分层触达对策），让全篇图谱串在同一条“母洞察”主线上。
