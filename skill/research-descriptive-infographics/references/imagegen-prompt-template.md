# 可变的图像生成提示词

用于主题素材或构图探索。先由真实结果决定信息关系；本模板不让 imagegen 计算、摆放真实统计值或生成地图边界。它不规定人口属性、横向条带、色系、面板数或人物数量。

## 填写变量

| 变量 | 如何确定 |
|---|---|
| `{主题与读者任务}` | 实际研究主题与核心问题；可包含同等重要的并列问题 |
| `{实际字段与关系}` | 来自冻结结果的维度身份、顺序/循环/比较关系；不给可识别个体数据 |
| `{构图几何及理由}` | 按设计决策选主从、矩阵、卡片、径向、条带或混合布局；解释阅读顺序 |
| `{画幅与最终尺寸}` | 报告版心、PPT或屏幕实际比例；不是所有任务都用竖长图 |
| `{视觉密度与层级}` | 清晰入口、主从或并列面板关系、需要的留白；随问题优先级和显示场景设定 |
| `{项目色板与语义}` | 具体色值或经确认的主题方向；每种颜色服务的对象 |
| `{插画语言}` | 中性物件、场景、少量人物或无插画；以主题和授权为依据 |
| `{保留区}` | 哪些区域由后续工具加入标题、图表、数值、图例；不要绘制伪图表当真实编码 |
| `{输出用途与禁止项}` | 素材/概念；避免Logo、官方背书、肖像仿真、私人内容和无意义微字 |

## 构图概念稿

```text
为“{主题与读者任务}”创作原创描述性统计复合信息图的视觉构图概念。
实际信息关系是：{实际字段与关系}。不添加不存在的维度，不套用固定人口画像。
画幅与使用场景：{画幅与最终尺寸}。
采用{构图几何及理由}，建立清晰入口、与问题优先级匹配的主从或并列层级和连续阅读路径。
密度：{视觉密度与层级}。色彩：{项目色板与语义}。
主题素材使用{插画语言}，与数据呈现区协调，不抢占量化比较空间。
为{保留区}保留干净的排版空间；真实图形、精确中文与数字将由后续工具合成。
图像本体不加“概念稿”“示例数据”等标签，不加免责声明条、脚注微字或水印。
不生成真实统计数字、伪数据图、数据地图、赛事/机构Logo或可识别受访者。
避免照描参考图布局和图标，输出适合{输出用途与禁止项}的原创视觉方向。
```

如果需要验证完整视觉节奏，可用无数值的图形占位表示面板位置；这些只作概念，不进入最终统计图层。真实比例/位置由确定性工具重建，不能保留生成式占位再贴数字。

## 独立插画/素材

```text
创作一组服务于“{主题与读者任务}”的原创{插画语言}素材。
对象仅为：{批准的主题对象}。配色：{项目色板与语义}。
在{画幅与最终尺寸}下保持统一视角、描边、光线与细节密度，留出适当裁切空间。
背景与透明需求：{背景或transparent_background选择}。
素材只帮助识别主题/类别，不承担数量、比例、地图、趋势或真实人物证据。
不加文本、数字、Logo、水印、解释条或无意义微字；不复制参考图图标和人物。
```

调用内置工具时按请求选择 `transparent_background`；编辑已批准图时提供正确参考，不反复凭文字重生母版。仅在授权需要时用参考图片；风格归纳通常不需上传原始截图。

## 生成后

检查物体结构、人物刻板暗示、意外文字、图标一致性、裁切和最终尺寸清晰度。保存实际提示词、生成日期、工具、输入引用、输出路径与哈希、人工取舍及权利记录。再用冻结结果叠加真实图表与精确文字并核对几何。概念稿本身不证明最终数据图正确；图面之外的成果详情注明概念/模拟/实际身份。
