# 三张参考图的可迁移观察

本文件是对用户提供的三张图片的设计归纳。原件仅在本地私有研究位置读取，定位、尺寸和 SHA-256 记录在本次任务的私有 source manifest；技能源不复制原图、聊天界面或私人路径。原作者、授权和完整数据来源未核实，不能据此公开转载素材、复用数字或证明统计正确性、奖项与来源身份。

## R1：同一构成的配色变体

可观察结构：图片用并列的冷色与暖色方案展示同一组人口背景信息。变量在左侧定位，各类标签、图标与百分数整合进横向容器；共同的形状语言有助于连续扫描。

可迁移原则：统一图标尺度、对齐、标签位置与语义颜色，可让多个构成变量成为整体；同一内容换色属于风格变体，不是新的分析方法。

边界与修正：画面中小类别空间紧、白字对浅底的对比有限；容器的可见长度与比例关系不能未经复核直接采信。新作先决定“比例编码”或“信息卡”，再按各自约束制作。不要固定沿用它的字段、行数、类别、人物或配色。

## R2：食品价格主题的编辑式多视角信息图

可观察结构：多块相连的食品价格主题画面，用一个较大的环绕/径向构图形成入口，并辅以时间、地点、品类与细节微图；食品图像、相近色系、线与圆形元素形成主题连续性。图片包含地图、气泡、时间/排名与小图的视觉形态，另有界面或其他覆盖内容，部分细字无法读取。

可迁移原则：同一主题可以由不同尺度、不同类型的证据面板共同回答；该案例以主图提供入口、辅助图负责比较与核查，新作也可为同等重要的问题设置并列主面板。主题插画可连接各分区，构图不必限制为横向条带或人口卡片。密度与结构应由信息关系和载体决定。

边界与修正：不能从截图核准具体变量定义、气泡面积映射、环形尺度、连线含义或地图数据。所有复杂编码在新作中必须单独说明并从冻结结果重建；装饰连线不冒充数量流动，地图不由图像生成替代。不要复制其食品素材或把高密度本身当成质量标准。

## R3：图标与数值的类别矩阵

可观察结构：多个类别组按行组织，每个类别容器内整合物件/人物图标、短标签和百分数，暖色明暗变化产生行内节奏。类别容器宽度有变化，但截图不提供完整编码说明。

可迁移原则：当读者主要任务是辨认类别与读取数值时，卡片矩阵能压缩图例距离并形成整体感；图标是类别入口，直接数值承担精确读取。

边界与修正：不得把参考容器的宽度或面积默认为准确占比。若容器只是排版，采用稳定尺度；若长度要代表比例，按真实值重建并处理小项外标。人物造型不能被当作真实群体肖像或性格证据；新主题可完全不出现人物。

## 共同归纳

可保留的是：同一主题下的视觉统一，图文就近，明确阅读入口，局部细节与整体节奏配合。

不可固化的是：人口属性清单、横向行结构、卡片数量、冷/暖/绿色板、径向中心、插画风格与信息密度。新任务应从实际字段和比较关系重新选择。
