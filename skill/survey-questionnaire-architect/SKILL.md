# 调研问卷工程架构师（Questionnaire Architect）

立足 172 份国奖报告附录（含 79 份甄别设计、124 份多维量表、14 份 KANO 双问、12 份注意力检验、5 份联合分析）与 122 份净化工商/社科实战问卷，将抽象研究构念落成**零歧义、低跳出、高信效度、可直接导入问卷平台**的标准调查工具。

## 问卷构建标准流水线

1. **匿名合规卷首语（30–40 秒速读上限）**
   - 必含 4 要素：中立/脱敏团队身份（**盲审竞赛严禁在问卷中暴露具体高校/学院名称，统一用 `XX 大学调研团队` 替代**）、调查研究目的（不泄露研究假设以免诱导）、核心术语一句话界定（如“什么是云博物馆/生成式AI”）、严格匿名与学术用途承诺 + 预计耗时（`3~5 分钟`）。
2. **硬核甄别前置与跳答路由（Screening & Skip Logic）**
   - 把目标客群过滤（如“近半年是否消费过……”“是否为家庭核心购买决策者”）与行业排他校验放到开头，不合格直接优雅终结或分流至“非使用人群认知与阻碍模块”，绝不允许无使用经验者硬填满意度量表。
3. **人口统计学口径对齐原则**
   - 年龄、受教育程度、月可支配收入/生活费划分**必须组距互斥穷尽**（如 `18岁及以下 / 19~25 / 26~35...`，严禁出现 `20-30` 与 `30-40` 边界重叠或像废卷般选项字母跳档），并与研究城市《统计年鉴》或核心模型分组口径保持一致。
4. **核心构念多题项操作化（每潜变量 ≥ 3~4 题）**
   - 遵循“单一动作/态度归因”，绝不出现并列兼问（例：反面典型“您对价格和包装的满意度如何？”必须拆成独立题项）。
   - 具体行业潜变量矩阵（餐饮/快消/康养/文旅/新能源汽车/AI SaaS/育儿教育/金融/基层治理）直接查 [17 大行业构念题项矩阵](references/domain-construct-matrix.md)。
5. **高阶决策题型与防偏差防线**
   - **区分复购与推荐**：未来复购意愿用 5/7 级李克特量表，推荐意愿优先采用 `0–10` NPS 量表。
   - **KANO 需求分类题**：严格成对部署“如果具备（正向）”与“如果不具备（负向）”双问，采用标准 5 档语义（`我很喜欢 / 理应如此 / 无所谓 / 可以忍受 / 我很不喜欢`）。
   - **联合分析（Conjoint）**：基于正交实验设计生成低相关性属性水平组合卡片（单人评估不超过 8–10 张以免作答疲劳）。
   - **质控防线**：在量表中段随机插入 1–2 道**注意力检测（测谎题）**（如 `“本题为注意力检测，请直接选择‘2’”`，且选项数字乱序排列 `3/1/4/2/5`），并在多选题写清上限（`最多选 3 项`）。

## 严禁出现的废卷病灶

- 严禁向普通匿名受访者索要真实姓名、手机号、门牌号等强敏感隐私（特殊社区/机构定点台账除外）。
- 严禁在问卷题干中堆砌学术缩写（如直接问“您的感知有用性 PU 如何”）；须转译为受访者日常口语（“使用该功能能帮我更快完成购票”）。
- 更多高级题型标准源码模板与正反对比用例见 [特殊题型、跳答与防偏差规范](references/item-types-and-anti-bias-guards.md)。
