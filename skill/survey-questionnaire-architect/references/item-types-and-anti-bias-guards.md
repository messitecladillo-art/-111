### 2.2 三大自动跳答路由拓扑 `[示范模板]`

在线平台必须启用逻辑分支（Skip Logic），纸质问卷须在跳转选项与分支终点**双向显式标注题号**（借鉴 `154` 武汉露营闭环范式）：

1. **三段式漏斗与潜客留存路由**（融合 `169` 微短剧 + `社区团购` Q7）：
   - `Q1 是否使用/购买过【目标产品】？`
     - `A. 是` → **跳至 Q4**（进入使用频次、客单价 `AOV`、满意度、核心驱动量表）→ 顺答共性人口学模块；
     - `B. 否` → **顺答 Q2**（未使用的阻碍因素多选）+ **Q3**（未来了解或尝试意愿，回收**潜客转化率 KPI**）→ **答完 Q3 强制跳至人口学模块**，严禁无体验者流入满意度与复购题。

3. **“未体验免答”与条件归因追问**：
   - 总体满意度设置 `不好说（从未体验该服务）`（源自 `147` 养老社区，修正其错印为“好说”的缺陷），选中即跳过明细子矩阵；高/低分归因追问采用单选项触发显示（`170` Q12、`名企` Q3–Q5、`家庭教育` Q8 选“未参加辅导”跳过 Q9 辅导科目）。

### 2.3 跳答逻辑红队隔离区（国奖实测反例）

- **跳转闭环致死题**：`153` 冷冻速食（国一）Q7 选“不愿意购买”跳 Q10（常购产品），Q8 愿意原因跳 Q11，导致 **Q9“不愿意购买原因”成为无人可达的死题**，且不买的人被迫填常购品牌。
- **单向跳转有去无回**：`173` Q3 学生跳 Q5（生活费），但 Q4（在职月收入）答完无跳转指令，导致在职者被迫再填一遍学生生活费。
- **多选题挂载冲突跳转**：`175` Q18 多选题为选项 A、B 分别配置不同“跳转到第 X 题”，多选时路径死锁。多选题严禁使用选项级跳转，只能用**条件显示（Display Logic）**按选中项逐个展开子题。
- **经历后置与因果倒置**：`170` 先以“如果你去”问 9 题出行规划，到 Q20 才问是否去过；`151` Q14 先问“是否购买创新后饮料”，Q15/17/19 才问喜欢哪类创新。经历甄别必须最前置，方案呈现必须在意愿测量之前。

## 3. 人口学区间互斥穷尽（MECE）与统计年鉴对齐协议

### 3.1 四项口径铁律

1. **边界严格互斥穷尽（MECE）**：严禁闭区间端点重复（如 `20–30` 接 `30–40`，该类边界重叠在 `146`/`148`/`151`/`152`/`154`/`167`/`169`/`173`/`175` 等十余份实测报告中高频出现），推荐**左闭右开、相邻整数不重不漏**或括号明注（正面模范：`153` Q3 `3千元以下（不包含3千）`）。严禁区间包含打架（如 `170` Q5 `4001~8000元` 接 `4000元及以上`、`名企` `3个月以下` 接 `1年以下`）与区间断档（`151` 价格缺 `4–5元`、`求职者` 薪资缺 `4000–5000元`、`152` 同行人数缺 `4人` 及 `10人+`、`170` 停留时间缺 `1–2天`）。
2. **学历与人群全谱系覆盖**：严禁如反例 `调查问卷的要求` 仅列“中专/本科/硕士”，必须覆盖 `小学及以下` 至 `硕士及以上（或博士）` 全谱系，且互斥划分在读与最高已获学历。
3. **学生/非学生财务口径分流**：参照 `146` Q4 与 `173` 逻辑，按职业将 `月可支配收入（在职/自由职业）` 与 `月生活费（全日制学生）` 分轨采集或于题干加注口径，避免学生误选极低收入档污染支付能力模型。
4. **对齐《统计年鉴》与 `PPS`/`Deff` 校准协议**：年龄分段、性别、常住地城乡/行政区划、受教育程度与家庭人均收入切分点，**必须在问卷定稿前对齐研究区域最新《统计年鉴》或人口普查公报分组口径**。唯有口径一致，抽样阶段才可将辅助变量映射至 `PPS` 抽样框，回收后方可运行卡方拟合优度检验（$\chi^2$ Goodness-of-Fit）评估代表性、估算设计效应 `Deff` 并实施事后分层加权（Post-stratification）。涉衍生生理指标（如 `151` BMI），严禁让受访者心算选档，须采集原始身高/体重由后端按 `<18.5 / 18.5–23.9 / 24.0–27.9 / ≥28.0` 自动分箱。

## 4. 五大高级题型标准结构与统计报告契约

### 4.1 5/7 级李克特量表（Likert Scale）与衍生矩阵

- **标准正向递增 5 级语义库**（`1→5` 递增，严禁反转；实证源自 `quest_01`）：
  - **认同度**（`154`/`父亲版`）：`1=非常不符合 / 2=不太符合 / 3=一般 / 4=符合 / 5=非常符合`
  - **频度**（`人力资源指数`）：`1=从来没有 / 2=不经常 / 3=有时 / 4=经常 / 5=总是`
  - **严重度**（`150` Q6）：`1=不发生 / 2=轻微 / 3=一般 / 4=较严重 / 5=非常严重`
  - **了解度**（`150` Q7）：`1=完全不了解 / 2=了解较少 / 3=一般了解 / 4=较了解 / 5=很了解`
  - **满意度**（`147`/`148`）：`1=非常不满意 / 2=不满意 / 3=一般 / 4=满意 / 5=非常满意`
- **7 级李克特量表 `[示范模板]`**（高区分度感知质量、SEM 潜变量防天花板效应）：
  `1=非常不同意 / 2=不同意 / 3=比较不同意 / 4=一般（中立） / 5=比较同意 / 6=同意 / 7=非常同意`；每个潜变量须配置 **$\ge 3$–$4$ 个**单维平行陈述项。
- **实测组合变体**：(1) **10–1 分整体评价**（`147`：横向 `10..1` 辅以 5 段语义锚 + `不好说` 分流）；(2) **IPA 双维配对**：`保险公司` 双栏并行（同项并列期望与满意度）或 `正大优鲜` 前后同序分块（先评 8 品类重要度，再同序评满意度）。
- **统计契约与隔离红线**：
  - 严禁极性反转（`167` 表头“完全符合--完全不符合”配 `1–5`、`保险公司` `1非常满意→5非常不满意` 且样表预填 `3,3,2,1,2...`）、语义倒错（`环境污染` Q16 “较满意”排“满意”前且缺中立）、锚点偏斜（`茶文化` 3 级无负向、`员工关系` 1 正 1 中 3 负）、擅改计分（`BDI` 将 `0–3` 改为 `1–4` 未说明换算致总分虚高 13 分）。
  - **禁止对李克特缺失值做均值填补**：序数刻度缺失须用完整案例删除或 EM/多重插补；SEM/CFA 必须汇报载荷、Cronbach's $\alpha$、组合信度 `CR`、`AVE` 与拟合度（如 `RMSEA`、`CFI`），不得把方便样本的李克特均分直接包装成总体参数估计。

### 4.2 0–10 NPS（净推荐值）

- **实证核验边界**：`quest_01` 语料未见标准 `0–10` NPS 原题，常见以 `147` 10–1 分整体满意度或 `174` 5 级口碑推荐（且将“推荐给他人”与“网络好评”兼问）替代，存在测度混叠缺陷。
- **标准结构 `[示范模板]`**：
  - **题干**（将“自身复购意愿”用 5/7 级李克特单独测量，NPS 专注他向推荐）：`基于您的真实体验，您有多大可能性向身边的朋友、同事或家人推荐【产品/服务】？[0–10 单选]`
  - **刻度**：横向 `0`（`完全不可能`）至 `10`（`极有可能`）共 11 档整数，每档仅标端锚或辅 `5=中立`。
  - **统计计算契约**：按 `0–6` 为贬损者（Detractors）、`7–8` 为被动者（Passives）、`9–10` 为推荐者（Promoters）切分：
    $$\text{NPS} = \left(\frac{n_{9\text{–}10}}{N} - \frac{n_{0\text{–}6}}{N}\right) \times 100 \in [-100, +100]$$
    报告时必须同时列明总有效基数 $N$ 及三类人群占比，严禁仅报总分或直接算 0–10 算术均值充当 NPS。

### 4.3 KANO 正反双向配对模型

- **核心结构与实测锚点**（源自 `quest_02` 国奖防疫原型）：对每一项待测功能属性，必须成对部署正向（具备该功能）与负向（不具备该功能）两问，统一采用标准 5 档语义：`① 很满意（或我很喜欢） ② 理应如此 ③ 无所谓 ④ 可以忍受 ⑤ 很不满意（或我很不喜欢）`。
- **正反双问 `[示范模板]`**：
  > **K1a（正向）**：如果【某生鲜平台/文旅景区】**提供**【“冷链全程温控实时溯源”功能】，您的感受是？
  > `○ 很满意   ○ 理应如此   ○ 无所谓   ○ 可以忍受   ○ 很不满意`
  > **K1b（负向）**：如果【某生鲜平台/文旅景区】**不提供**【“冷链全程温控实时溯源”功能】，您的感受是？
  > `○ 很满意   ○ 理应如此   ○ 无所谓   ○ 可以忍受   ○ 很不满意`
- **25 格交叉评价矩阵与 Better-Worse 契约**（源自 `quest_02`）：

| 正向（具备） \ 负向（不具备） | 1. 很满意 | 2. 理应如此 | 3. 无所谓 | 4. 可以忍受 | 5. 很不满意 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **1. 很满意** | `Q` (疑问) | `A` (魅力) | `A` (魅力) | `A` (魅力) | `O` (一维/期望) |
| **2. 理应如此** | `R` (反向) | `I` (无差异) | `I` (无差异) | `I` (无差异) | `M` (必备) |
| **3. 无所谓** | `R` (反向) | `I` (无差异) | `I` (无差异) | `I` (无差异) | `M` (必备) |
| **4. 可以忍受** | `R` (反向) | `I` (无差异) | `I` (无差异) | `I` (无差异) | `M` (必备) |
| **5. 很不满意** | `R` (反向) | `R` (反向) | `R` (反向) | `R` (反向) | `Q` (疑问) |

- **计算与质控契约**：
  $$\text{Better（增加后满意系数）} = \frac{A + O}{A + O + M + I}, \qquad \text{Worse（不提供后不满意系数）} = -1 \times \frac{O + M}{A + O + M + I}$$
  每项 KANO 属性占用 2 题，单卷建议控制在 **6–10 项核心功能**以内以防作答疲劳；若某功能 `Q`（疑问）比例异常偏高，须立即审计正反题干是否存在双重否定或歧义。

### 4.4 联合分析正交卡（Conjoint / Discrete Choice Experiment）

- **实证溯源与疲劳隔离**：`101`（2021 国三）采用联合分析与正交实验生成 25 种基金产品；`103` 综述提及离散选择实验（DCE）。**红队铁律**：直接让单个受访者连续评估 25 张卡片会彻底击穿注意力（对比 `135` 控题在一张 A4 正反面防疲劳）。正交设计若生成 16–25 张卡片，必须拆分为 **2–3 个区组（Block）随机分配**，保证**单人评估卡片数 $\le 8\text{–}10$ 张**，并额外置入 1–2 张 Holdout 校验卡。
- **两类标准呈现结构 `[示范模板]`**：
  - **结构 A：全轮廓评分卡（Rating-based Conjoint）**——展示同一正交组合（如：`年化收益预期 4%~6% | 风险等级 中低 | 申购费率 0.15% | 封闭期 30天`），要求受访者评估购买意愿（`1=绝对不买 ~ 7=绝对会买`）。
  - **结构 B：离散选择实验配对卡（Choice-based Conjoint / DCE）**——并排呈现 2 个属性正交配置方案与 1 个基准退出项：

| 属性维度 | 方案 A | 方案 B | 方案 C（基线退出） |
| :--- | :--- | :--- | :--- |
| **价格/费率** | 29 元/月 | 49 元/月 | **以上方案均不选择**（维持现状/不购买） |
| **核心功能** | 基础 AI 问答 | AI 问答 + 专业报告生成 | |
| **响应 SLA** | 5 分钟内 | 实时（< 10 秒） | |
| **您的选择** | `○ 选择方案 A` | `○ 选择方案 B` | `○ 均不选择` |

- **统计报告契约**：传统评分联合分析必须汇报**属性相对重要性权重**、各水平**分值效用（Part-worth Utility）**及 Holdout 卡拟合指标（Pearson's $r$ 与 Kendall's $\tau$）；DCE 模型必须汇报多项/混合 Logit 参数 $\beta$、优势比 **`Odds Ratio`**、伪 $R^2$ 及边际支付意愿（`WTP = -\beta_{\text{attr}} / \beta_{\text{price}}`）。严禁省略 `Opt-out` 基线选项而高估市场渗透率。

### 4.5 多选、限选与排序题

- **规范结构与实测范式**：
  1. **常规多选加排他锁**：选项末端“以上均无 / 均不认可”必须开启**平台互斥锁**，禁止如 `148` Q9（限选 4 项混入`很少关注`）、`153` Q12（含`无`）、`地摊经济` Q19（必选 3 项却含`以上您都不认可`）导致矛盾勾选。
  2. **上限约束多选**：明确写清上限（`148` Q8 限 3 / Q9 限 4 / Q18 限 5；`176` Q26 限 2 / Q27-28 限 3；`社区团购` 限 3）。
  3. **Top-N 限选排序 `[示范模板]`**（源自 `正大优鲜` A3 / `文旅产业` Q7/8/11）：`“请从下列特征中选出对您最重要的 3 项，并按第一重要、第二重要、第三重要顺序排列”`。
- **统计报告契约**：多选题建表必须区分**响应百分比（% of Responses，分母为总勾选次数，合计 100%）**与**普及率/个案百分比（% of Cases，分母为作答人数 $n$，合计 > 100%）**；Top-3 排序须汇报明确加权分值公式（如第一/二/三位分别赋 `3/2/1` 分算综合均值）。**严禁将普及率合计超过 100% 的多选题绘制成饼图。**

## 5. 防同源偏差（CMB）、注意力检测与废题黑名单

### 5.1 防同源偏差（Common Method Bias）全流程防线

- **事前程序隔离机制（Procedural Controls）**：
  1. **题型与量表断点混排**：避免连续数十道同向“非常同意”Matrix 题引发直线作答（Straightlining），穿插客单/频次客观题、排序题与 7 级/5 级隔离；
  2. **分支物理隔离与随机化**：对量表题项开启随机轮播（Randomization，保留量表锚点顺序与固定“其他”项），在独立分支内各自布防质控点（借鉴 `124` 购买/未购买群分别设测谎题）；
  3. **反向题平衡与重编码**：如 `EPQ` 嵌入适度反向陈述，代码本必须在信效度与建模脚本首行强制完成反向重编码（`6 - X` 或 `8 - X`）；
  4. **消除引导与时长边界**：封杀 `150` Q7 / `瑞安原生钛` Q17 单向科普；参考 `135` 物理篇幅约束（A4 正反面）与 `124`/`201` 时长窗（`< 1 分钟` 或 `< 2 分钟` 极速盲填、`> 15 分钟` 挂机剔除）。
- **事后统计审计契约**：
  - 采集期后对人口学基线做**游程检验（Runs Test）**校验样本随机性（参照 `124` 报告 $p > 0.05$）；
  - 建模前执行 **Harman 单因子检验**（未旋转探索性因子分析第一公因子方差解释率诊断），多潜变量 SEM 建议叠加未测潜在方法因子控制（ULMC）或检查构念间全共线性 `VIF`（排查方法变异膨胀）。
