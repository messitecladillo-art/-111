## 1. 品牌身份

| 项目 | 定稿 |
|---|---|
| 中文主品牌 | 证见 |
| 英文工作名 | EVI-X |
| IP 角色 | 獬见 |
| 品类描述 | 正大杯全流程循证竞赛智能体 |
| 主口号 | 让每个问题，都循证抵达行动。 |
| 短口号 | 问有据，见有策。 |
| 品牌承诺 | 把真实问题连接到可复核证据、可靠洞察和可执行行动。 |

`EVI-X` 是工作名，不代表已取得商标、字号、域名或社交账号使用权。对外商业化、注册、发布站点或批量制作衍生物前，必须分别检索“证见”“獬见”“EVI-X”及近似名称的商标、域名、应用商店和主要社交平台占用情况，并保存检索日期与结果。

品牌人格是“循证策略官＋友善守证灵兽”：冷静、锐利、诚实、克制，不迎合、不虚构、不以复杂模型炫技，同时始终给出清晰的下一步。

## 2. 使用边界

只使用以下三个 canonical 模式代码，不创建同义别名：

| 模式代码 | 场景 | 品牌默认状态 | 声明要求 |
|---|---|---|---|
| `agent_ui` | 智能体界面、能力页、内部工作台 | 开启 | 在简介、关于页或同屏信息中声明独立、非官方身份 |
| `public_promo` | 官网、社交媒体、公开路演、衍生物与媒体展示 | 开启 | 必须显示本节规定的完整非官方声明 |
| `competition_submission` | 报告、附录、问卷、数据、代码输出、答辩 PPT 与讲稿 | **关闭** | 仅在规则要求时披露 AI 使用，不用品牌替代披露 |

### `competition_submission`：默认关闭品牌

市场调查报告、附录、问卷、数据表、分析代码输出、答辩 PPT、讲稿和其他可能提交给赛事评审的材料，默认不出现“证见”“EVI-X”“獬见”、角色图形、品牌角标或品牌水印。只有同时满足以下条件才可启用：

1. 当届、组别、赛区和阶段的适用规则已经核实；
2. 规则明确允许或不禁止该类标识；
3. 团队负责人明确要求使用；
4. 不影响匿名、AI 披露、页数、版式与其他硬性合规要求。

品牌不得被用来掩盖 AI 参与，也不得替代适用的 AI 使用说明。

### `public_promo`：必须声明非官方

官网、社交媒体、宣传海报、公开演示、衍生商品、案例展示和媒体稿等公开物料，必须在可见位置或紧邻说明区域加入：

> 证见 EVI-X 为独立研究辅助工具，非“正大杯”赛事官方产品，与赛事主办方、承办方及冠名单位无隶属、授权或合作关系。

头像等无法容纳声明的极小载体，应在账号名称、简介、落地页或同屏说明中提供声明。不得使用赛事官方标志、冠名方标志、官方吉祥物、奖杯、桂冠、官方证书、赛事主视觉或足以造成来源混淆的近似构图。不得宣称“官方”“指定”“授权”“保奖”“冠军保证”或暗示已获官方背书。

### `agent_ui`：品牌可见但交付物隔离

智能体头像、欢迎页、能力导航和内部状态界面可以显示证见品牌。进入项目交付导出流程时，必须显式读取目标模式；若为 `competition_submission`，导出的报告、PPT、图表和附件不得继承界面水印、角色角标或品牌页眉。

## 3. 证据链超级符号

所有核心视觉与叙事围绕同一条不可倒置的链路：

```text
Q 问题 Question → D 数据 Data → I 洞察 Insight → A 行动 Action
```

| 节点 | 视觉语义 | 内容要求 |
|---|---|---|
| Q | 问号、开放圆环、观察入口 | 明确真实问题、决策主体和证据缺口 |
| D | 点阵、样本网络、结构化网格 | 表示有来源、可审计的数据，不表示“越多越真” |
| I | 折射棱镜、聚焦光束 | 区分事实、解释、推断和限制 |
| A | 单向箭头、可衡量路径 | 指向责任主体、动作、优先级与 KPI |

四节点必须按 `Q → D → I → A` 左到右、下到上或角根到角尖排列，不得缺项、重复、倒序，也不得把相关性视觉化为确定因果。

## 4. 獬见角色不变量

完整角色、全身姿态、主视觉与实物衍生必须保留以下四个主不变量；缺少任一项即判定身份失败：

1. **四节点 Q-D-I-A 证据角**：头部正中只有一根向上略前倾的金色独角；角上必须清楚可数地出现且只出现四个相连发光节点，从角根到角尖依次映射 Q、D、I、A。生成图不强制在节点内写字，字母应优先在后期排版中添加。
2. **胸口棱镜**：胸前只有一枚纵向菱形切割棱镜，青色核心、琥珀金折射面、金属包边；它象征把数据折射为洞察，不得替换成勋章、徽章、盾牌或宝石项链。
3. **箭头尾**：一条长而柔韧的深蓝缎带状尾巴，末端只有一个清晰的青金双色三角箭头；尾巴表达从洞察走向行动，不得变成普通兽尾、多尾或武器。
4. **引号耳**：一对大而直立的深蓝耳朵，左右内耳各有一个镜像金色引号／逗号形纹样，组合后表达“倾听真实用户声音”；不得改成星星、爱心或赛事标志。

唯一的尺寸例外是经清单批准的紧凑头像／微型图标：可以因圆形裁切省略身体与尾部，但在 32 px 及以上时，四节点独角、双耳引号、琥珀眼和胸口棱镜仍必须可辨；画面若出现尾巴，仍必须是唯一的箭头尾。16 px 栅格回退图标允许节点因像素采样发生光学合并，但必须由批准头像确定性缩放，不得手工改成错误节点数；需要节点精确可数时改用 SVG 标志或 32 px 以上图标。例外必须写入 `brand-manifest.json`，不得由生成者临时口头放宽。当前批准的紧凑锚点为 `evi-x-avatar-v1`；完整角色生产锚点为 `evi-x-character-anchor-v2`。

辅助不变量：

- 物种为现代化、友善的幼年獬豸，四足、短吻、紧凑而敏捷；不是独角兽、鹿、龙、猫或犬。
- 眼睛为温暖琥珀色，神态聪明、克制、自信，不凶狠、不卖萌过度。
- 身体以墨蓝哑光陶瓷／树脂质感为主，配细窄金属金纹和少量青色能量线；避免写实长毛、塑料廉价感和厚重铠甲。
- 头部仅一根角；无翅膀、皇冠、披风、衣服、武器、奖牌或奖杯。
- 全身可带少量圆形证据节点纹，但不得再造第二条四节点主链，避免主次冲突。

## 5. 视觉语言

### 色彩

| 角色 | 色值 | 用途 |
|---|---|---|
| 证见墨蓝 | `#0A1F33` | canonical 主品牌色、角色身体、标题与深色底 |
| 证据青 | `#00B3A4` | 数据节点、能量轨迹、交互状态 |
| 深证据青 | `#00796F` | 深色交互态、印刷备用与层次 |
| 行动金 | `#F4B942` | 证据角、关键结论、行动箭头 |
| 暖象牙 | `#F7F4ED` | 角色设定稿、报告与社交物料浅底 |
| 雾灰 | `#E7EEF3` | 浅层分隔、表格底与非数据背景 |
| 石板灰 | `#536677` | 辅助文字、网格与中性状态 |

不要复制赛事、主办方、承办方或冠名方的官方色彩组合。公开物料不得以官方红、奖项金、奖杯轮廓组成近似官方徽章。

### 形态与版式

- 使用四节点轨迹、折射棱镜、箭头路径、数据点阵和克制的研究网格作为辅助形态。
- 主视觉采用大留白、低噪声信息层级和单一焦点；角色服务于证据叙事，不遮挡图表与方法说明。
- 中文排版优先使用思源黑体／Noto Sans CJK SC，拉丁文优先使用 Inter；字体须由后期排版工具完成，不把关键文字交给生图模型。
- “证见 EVI-X”字标与角色图像分离管理。生成图默认不内嵌字标、水印、口号或免责声明。

## 6. 文案人格

表达顺序固定为“结论 → 证据状态 → 限制 → 下一步”。使用明确、可验证的措辞：

- 推荐：“这项结论由样本数据支持，但外推仅限于……下一步应……”
- 推荐：“缺失即未知；先补证据，再下判断。”
- 禁止：“一定获奖”“模型越高级越好”“AI 已替你完成真实调研”。

獬见可以友善，但不幼稚；可以锐利，但不审判参赛者。它质疑证据而不是攻击个人。

## 7. 资产生产流程

1. 先读取 `assets/brand/prompts/character-master.md`，并以清单中 `review_status=production_anchor` 的最新完整角色作为身份参考。当前使用 `evi-x-character-anchor-v2`；多视图 `evi-x-character-master-v1` 仅供造型探索，禁止作为生产母版。
2. 使用内置 `image_gen` 作为默认生成路径。每一种资产单独调用，避免用同一提示词一次生成多个不同用途。
3. 在提示词中逐字重复四个主不变量。变体只改变姿势、构图、场景或媒介，不改变身份。
4. 生成图不承担中文、英文品牌名、Q-D-I-A 字母、口号或免责声明的正确排版；这些内容在后期确定性排版中添加。
5. 检查输出后，每轮只修改一个主要问题，再重新验收。不得用“整体更高级”之类不可验证的返修指令。
6. 项目资产使用稳定命名：`evi-x-<asset>-v<integer>.<ext>`；禁止覆盖已批准版本。
7. 每个最终资产记录提示词 ID、提示词版本、生成工具、输入参考图、生成日期、输出路径、审核人和验收结果。

标准提示词：

- `assets/brand/prompts/character-master.md`
- `assets/brand/prompts/hero-evidence-chain.md`
- `assets/brand/prompts/sticker-pack.md`
- `assets/brand/prompts/avatar.md`
- `assets/brand/prompts/merchandise-concept.md`

## 8. 验收与审计

### 一票否决

- 证据角节点不是恰好四个，或顺序无法对应 Q-D-I-A；
- 完整角色缺失胸口棱镜、箭头尾或引号耳；紧凑头像违反已登记的裁切例外；
- 角色出现第二根角、翅膀、皇冠、奖杯、奖牌或赛事／冠名方标志；
- 公开物料没有非官方声明，或提交物在未授权情况下出现品牌；
- 资产暗示官方背书、保证获奖或虚构调研、数据和评价。

### 质量检查

- 32 px 以上头像仍能识别独角、四节点、引号耳和胸口棱镜；16 px 回退图标按清单例外检查剪影与来源；完整角色还必须识别箭头尾；
- 角色比例、眼色、材质、主配色与批准母版一致；
- Q-D-I-A 视觉顺序明确，行动箭头不回流到问题端；
- 文字均由后期排版完成，拼写、字号和安全边距可读；
- 文件名、版本、提示词、参考图、生成日期和审核结论均可追溯。
