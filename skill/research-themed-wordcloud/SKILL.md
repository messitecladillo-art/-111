# 主题意象联想词云技能（Research Themed Word Cloud）

拒绝千篇一律的椭圆、爱心或购物袋轮廓。一幅高水准的调研报告词云，必须让人在 **0.5 秒内仅凭剪影轮廓就认出这份报告的调研对象与核心产品**。

## 一、双轴意象联想机制（Dual-Axis Semantic Association）

收到任意研究课题 `{topic, population, artifact, corpus}` 时，强制沿两条实体视觉轴完成意象联想，输出结构化联想方案（`AssociationPlan`）：

1. **A 轴 · 核心受众人物形象（Subject / Persona Silhouette）**
   - 从目标群体提炼极具辨识度的温润人物侧面/半身剪影（非写实照片，而是轮廓清晰的纯黑图形掩膜）。
   - 例：`银发智能健康监测` → **银发长者侧面半身剪影（发髻/眼镜/温和侧颜）**；`县域即时零售骑手` → **配送骑手与电摩剪影**；`高校 AI 辅助学习` → **学士帽青年侧影**；`母婴消费` → **怀抱婴儿的亲子剪影**。
2. **B 轴 · 核心产品或场景载体轮廓（Artifact / Carrier Silhouette）**
   - 从被测产品、服务载体或关键场景提炼辨识度最高的实体轮廓。
   - 例：`银发智能健康监测` → **智能健康监测手表/腕表轮廓（表盘 + 表带 + 侧冠）**；`县域闪电仓` → **包裹快递箱 / 冷链配送车剪影**；`社区长者食堂` → **热气碗筷餐盘剪影**；`新能源汽车充电` → **充电桩与电车轮廓**。

完整行业联想映射表见 [双轴意象联想矩阵](references/silhouette-association-matrix.md)。

## 二、单词云 vs 双词云决策规则

- **单词云模式**：当开放题或二手语料维度单一、有效词条较少（`< 35` 个高区分度词元）时，优先选择与该节叙事最贴合的一轴（人群诉求节选 **A 轴人物剪影**；产品改进建议节选 **B 轴器物剪影**）。
- **双词云并列 / 分章联动模式（推荐）**：当研究同时覆盖“受众心理诉求与场景痛点”和“产品硬件与流程改进建言”两类语义簇时，**生成两幅互补轮廓的主题词云**：
  - **词云 1（A 轴受众轮廓，如银发长者形象）**：聚焦**受众人群特征、心理顾虑、代际支持与社区服务诉求**语料；
  - **词云 2（B 轴器物轮廓，如智能监测手表轮廓）**：聚焦**设备硬件交互、读数辨识、续航同步与具体功能改进建言**（如 `Q32` 开放题语料）。

## 三、掩膜生成与 `wordcloud + jieba` 渲染契约

1. **掩膜获取优先级**：
   - 优先命中本地主题剪影掩膜库（`skill/research-themed-wordcloud/assets/masks/*.png` 及 `apps/backend` 内置掩膜库）；
   - 新选题无现成剪影时，调用**内置生图能力**生成一张 `4:3`、**纯黑 `#000000` 实心剪影 + 纯白 `#FFFFFF` 背景（零渐变、零阴影、零文字、内部填充面积占比 60%–72%）** 的掩膜 PNG 并入库复用。
2. **高密度排布与纯白极简美学（对接 `fuqiuai/wordCloud` + `flingjie/words_image`）**：
   - 使用 `jieba` 中文分词（加载停用词表，彻底过滤虚词与元标签词）或接入已核算词频字典；
   - 通过 `POST /api/reports/wordcloud` 调用 Python `wordcloud.WordCloud(mask=mask_array, max_words=220, min_font_size=7, background_color='white', prefer_horizontal=0.88, contour_width=0, repeat=True, collocations=False)`，按报告主题主色（深墨 + 林青 + 暖金 + 陶土）着色；
   - **视觉红线**：画面必须是**纯白/透明背景 + 纯粹词元自然构成的剪影**，**严禁绘制可见掩膜外轮廓描边线（强制 `contour_width=0`）**，严禁添加外层卡片框、顶部标题栏、四角徽章或底部 `注：...` 解释文字（图题统一由正文排版的标准图题承担）。

## 四、主题剪影词云与高频词条形图并排双联版式（跨行业普适）

当需要在一幅展板内同时呈现质性语料的主题轮廓意象与精确词频梯度时，可启用领域无关的双联模式（`pairedBar: true`）：

- **纯白无外框双联构图（`1400×680`）**：画布底色固定为纯白 `#FFFFFF`，零外层圆角卡片框、零顶部装饰栏；左栏 `56%` 放置主题剪影词云本体，右栏 `44%` 放置清爽的 **Top-12 高频词横向渐变条形图**。
- **100% 中文词签与精确频数标注**：右侧条形图按频次由高到低排列，左侧对齐纯中文高频词元（严禁出现英文分词代码或停用词），条形末端直接标注精确频次整数，配色与左侧剪影词云共用课题主辅色系，适用于任意行业与开放题语料。
