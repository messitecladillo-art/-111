## 接续基线

主分支 `codex/initial-evix` 的基线为 `aef8eae4`（PR #1）。本轮从其后续分支 `fd1bc7f6` 接续，保留已有的交互、Hook 依赖、同名模型服务区分、模拟数据提示样式、长量表配色及硅基样本文档修订。

本轮审查以文件、具体提示和操作状态为单位，不以旧任务中的文件总数作为完成依据。覆盖当前 `components/`、`lib/` 中 88 个含中文的 TS/TSX 文件，以及 `app/`、`data/` 中 23 个产品代码文件；另核对 8 个含中文消息的 Python API 模块。获奖案例、官方通知、赛事日历记录和生成的规则快照不做文案改写。

## 改动范围

精简 41 个产品代码文件及硅基样本文档中的重复说明、实现阶段标签和宣传句。标题直接说明任务，按钮直接说明动作，错误提示保留解决路径。额外修复 3D 舞台的无障碍描述：画像人数变化时同步更新人数，不重建 WebGL 场景。

以下信息继续在相关操作处展示：

- 数据来源、模拟标记、统计分母、缺失与跳题口径，以及检验的适用条件。
- 问卷修改的预览和确认、过期版本处理、撤销、保存失败与恢复范围。
- 项目权限、邮件与模型测试适配器状态、真实密钥输入限制。
- 模型调用额度、取消后已发出请求的计费、结果未知时的核对方式。
- 离线运行结果的导出备份提示、模拟数据不得并入真人样本的限制。

审查中修正了两处容易误解的说法：离线答案是单独展示，不承诺刷新后恢复；画像复现同时依赖相同设定和随机种子。保真度诊断需要真人样本对照，不能将诊断指标直接表述为已验证的人群观点。

三个模块组由不同审查者交叉复核；集成部分单独复核。文案审查没有改变统计算法、数据结构、权限逻辑或来源记录。
