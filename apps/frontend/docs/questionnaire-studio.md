# 问卷设计工作台

2026-09-30 新增模块拼装与批量量表题组，详见 [拼装式研究工作台](composable-research.md)。保留严格 v1 备份与原有逐题编辑。

入口：`/workspace#design`。这是待实施设计工具，不是答卷收集系统、有效量表认证系统或赛事 Gate。

## 已实现

- 研究简介、对象、参照期、招募方案、告知说明与预试记录。
- 单选、多选、量表单题、数值、开放题；编码、构念、来源、研究问题、分析计划与决策用途映射。
- 当前题聚焦预览、整份通读预览及单选条件显示预演。聚焦模式保留原题序，不执行跳题；目录搜索不改变整份预览或路由预演。条件以稳定题目 ID 和选项字符串编码关联，隐藏或未回答的来源不触发后续题。
- 题目目录支持题干、变量、构念、研究问题与题型的字面搜索；空格分隔的关键词同时匹配，不执行正则。可筛选结构问题、用途未映射、显示条件与未应用数值。筛选不修改题序、不丢弃正在编辑的题目；活动题被过滤时明确提示。
- 检查概况可跳转到题目目录或相应问题分类；检查项可定位题目、展开相关设置或定位研究简介。结构问题数量不是量表质量分，也不是赛事 Gate 结果。
- 桌面三栏工作区；窄屏可切换编辑与预览。错误与数值暂存提示始终位于工作区切换之外。
- 增加、复制、重排、移除；有下游引用时阻止破坏性改动；最近 40 次编辑撤销/重做。
- 替换、删除与恢复备份使用站内确认框，默认聚焦取消，支持 Escape 取消与返回原按钮；确认期间版本变化则保留最新编辑，导入确认后再次核对读取批次与编辑版本。
- 下载可恢复 JSON 备份、问卷草稿 TXT、变量与分析字典 JSON。后两者不是恢复备份。
- 严格有界、UTF-8 JSON 恢复；格式错误、超限或读取期间出现新编辑时，保留当前设计。先校验再确认替换。
- 区分结构问题与人工复核。示例为自编教学内容，不是国奖原始问卷或经过验证的成熟量表。

## 容量与边界

最多 80 题、每题 30 选项、格式化备份 300,000 UTF-8 字节。量表单题支持 2–15 个连续整数点；数值绝对值最多十亿。这些是工程边界，不是比赛要求或测量理论标准。缺漏和语义错误可保存为草稿，但会列出结构问题，不自动修复。

数值编辑保留 `-`、`1e` 等尚未完成的临时输入，不把它们写成空值；此时阻止导出并提供定位、恢复上次有效值。切题保留临时输入，撤销/重做会清除临时输入并提示；删除或替换会明确确认放弃。负零在解析时按数值等价规范为零，不改动选项字符串编码。JSON 中重复成员（包括转义后同名字段）会被拒绝，避免静默覆盖。

默认在页面内存编辑，不自动保存或上传。可下载本地备份，或在「问卷项目与版本」连接、检查隐私并明确保存至服务端问卷库；支持历史预览、确认载入和撤销，详见 [问卷版本库](questionnaire-library.md)。刷新会丢失未保存编辑及未应用输入。页面离开提醒只能作为辅助，浏览器不保证一定展示。不得把真实受访者答卷或身份信息填入题目/来源字段。文件可以包含用户自己输入的内容，分享前人工检查。

当前条件仅支持此前单选题的一组编码，不支持多源逻辑、任意表达式、配额、随机题序或问卷发放。路由演练只检查显示路径，不替代目标人群认知访谈、预试、伦理审查或实际填答测试。条件失效时不展示相关下游题。草稿文本保留所有题和显示条件，不能未经核对直接发放。

改变模拟单选后，隐藏题的旧模拟答案会清空，避免再次打开分支时沿用过期选择。文本导出同时标明题序和变量编码，使条件来源可独立定位。

来源字段只是用户陈述，不自动验证文献。映射填写完成也不代表统计方法适配。自动提示无法判断完整覆盖、内容效度、结构效度、测量等值、样本代表性或伦理合规，不给虚构质量分或“可参赛”结论。
