# 拼装式问卷与组合分析

入口：问卷设计 `#design` → 模块拼装；数据分析 `#analysis` → 导入 / 模拟数据 → 组合分析。

## 问卷拼装

- 7 个自编模块：筛选、分层画像、行为投入、体验、障碍需求、意愿、开放补充。选择顺序就是追加顺序，原有题项与路由不改动。
- 逐行建立 2–12 个量表题项，配置构念、5 / 7 点范围、两端锚点与来源。生成普通 v1 题目，不新造备份字段；反向计分须逐题确认。
- 批量生成先经严格解析再一次提交，整批撤销 / 重做；新 ID 唯一，变量编码忽略大小写避让；累计仍最多 80 题。
- 模块状态在问卷内部页签切换时保留。尚未加入问卷的选择与量表输入不是已应用问卷，**不包含在问卷备份里**；刷新后丢失。
- 自编草稿不是国奖原题、成熟量表或可直接发放的成品。不会自动补研究依据、选项穷尽、伦理批准、预试证据或下游显示条件。

## 分析积木

### 问卷与数据逐题对应

在设计页点击“将本版问卷送到数据分析”，到分析页明确接收快照；也可导入问卷设计备份。读取 CSV 后逐题选择对应列，核对单选列存的是编码还是选项文字，最后确认本版对应。同名列只作建议，不自动批准；支持只对应本次需要的题目。

- 关联模式在计算前核验题型、有效选项、数值范围、量表整数计分与构念。不会因为就业状态写成 1 / 2 就将其当作连续变量计算均值或 Pearson；单题量表也不自动视为连续量。
- α 必须使用至少两个同构念、同范围量表题，反向设置与问卷一致。推荐按钮只填入设置，不自动计算或删除题项；未纳入的题目数量明确标示。
- 本页源问卷、列对应、数据解析身份或计分配置变化后，关联结果须重新核对/计算；旧结果不能继续进入报告候选。现版本采用保守整体失效，不是选择性重算。导入备份无法跟踪外部问卷文件的后续变化。
- 对应备份包含问卷文字、选项、列名和文件/解析指纹，不含答卷行。恢复必须使用原始数据与相同解析设置；恢复不会带回确认授权，需重新确认。分析页的数据、问卷快照及对应关系仍是本页内存状态，刷新前须主动下载。设计页另有显式保存的 [服务端问卷版本库](questionnaire-library.md)，不自动保存分析页的数据或对应关系。
- 已关联的频数/α 报告提案保留问卷、解析和映射指纹，以及参与计算的稳定题目 ID。服务端验证选中题项与计算摘要的契约；这些客户端提供的元数据不能证明田野真实或实际施测版本。
- 条件题、多选拆列和开放文本编码暂不支持关联计算，显示明确阻断。条件题在逐行资格规则实现前直接阻断关联计算；当前缺失概览仍是原始单元格检查，尚未区分结构性跳过与应答缺失。未关联时保留手动分析，其测量水平需要用户自行核对。

回归见 `tests/questionnaire-mapping.test.mjs` 与 `tests/research-flow-api.test.mjs`。2026-09-30 的界面检查使用 6 行合成数据，覆盖备份下载/恢复、恢复后重新确认、源问卷变更使旧结果失效、窄屏和深色显示；不代表真实项目已完成调研或通过比赛 Gate。

### 可计算的分析卡

6 种可重复组合的卡片，最多 12 张：频数 / 比例、数值分布、分组描述、交叉表与 Pearson χ² / Cramér V、Pearson 相关、Spearman 秩相关。原有 Cronbach α、反向计分、校正题总相关与删除后 α 在专门页签保留。

每卡独立记录研究问题、变量、分析样本 n、缺失 / 非数值排除、结果和解释限制。可上移 / 下移、移除并撤销最近一次移除。同一方法允许用在多组变量。样本画像、群体比较、关联探索提供二卡起步组合，不预设变量与结论。

- 缺失代码按既有规则；不插补、不自动删重复、不改原文件、不加权。
- 数值解析不等于测量水平适配。各卡显式选择变量，疑似标识列禁止进入计算。
- 分组保留数值全缺失的组（n=0、摘要=null）。每组完整有效数之和等于分析 n。
- 相关在每对完整样本内计算；Spearman 对该样本重排平均秩。常量 / 不足两对返回 null；两对 ±1 有专门提示。平移与尺度处理降低数值上溢 / 下溢风险。
- 交叉表只保留两个分类都非缺失的行；行百分比按行分母。χ² 无连续性校正，V 未偏差校正；任一侧不足两类则未定义。报告稀疏期望频数。不计算 p 值、不宣称显著。
- 频数最多 50 类，分组 / 交叉表每侧最多 20 类；超过则拒绝，不静默合并类别。
- 设置 / 缺失规则变化后旧输出失效。缺失代码非法时保留卡片、禁算与下载。更换数据（包括同一文件再次导入）重置卡片；失败导入不替换原数据。
- 页面内存处理，不发送原始答卷、不写浏览器存储。独立下载组合记录：包含文件 hash、配置、当前结果；不含原始行，分类标签替换为代号；不是可恢复数据备份。变量名、研究问题、小样本汇总仍可能敏感。
- 基础分析记录与组合记录分开下载。切换到量表 / 数据概览不会清空组合卡片。

## 统计证据到报告（P0，本地已实现）

数据分析页新增可恢复的执行记录：当前频数卡片 / 原始 Cronbach α → 隐私确认 → 保存汇总与提案 → 核对具体目标报告与版本 → 确认追加章节。其他统计卡片继续保持既有功能，尚未接入这条报告链路。

- 原始答卷仍只在浏览器内存处理。显式同意后仅将白名单汇总、数据 SHA-256、变量/缺失设置、研究问题保存到 D1；分类标签替换为代号。汇总仍可能敏感，不能把此处理称为匿名化。
- 服务端基于分类计数重算比例、基于共同尺度的方差汇总复算 α；不接收任意结论或验证标签。只验证汇总结构/公式与固定文案，不能证明摘要对应原始文件或田野真实。
- 提案、输入指纹、目标草稿 ID、基线版本固定。改数据/设置/问题会禁用旧提案确认；刷新后仍可查看历史，但需重新导入并按原设置计算匹配，才可批准未完成提案。
- 显式确认执行一个 D1 batch：保留写入前版本、CAS 追加独立报告章节、保留确认后版本、记录结果。PPT 与 Office 二进制不自动修改。每次确认占 2 个命名版本，容量不足整体不写。
- 同一请求重试不重复写，取消为终态；其他页面先修改会返回冲突，不覆盖。身份沿用现有编辑会话和作用域保护；不新增认证旁路，不触碰 agentctl Gate。
- 记录最多 80 条/身份。暂无删除、自动归档或后台 LLM 执行。前三条事件是同次保存的实际阶段，非伪造专家思考；模型调用费用为 0。
- 回归：`tests/research-flow.test.mjs`、`tests/research-flow-api.test.mjs`；独立服务重启使用 `tests/research-flow-restart.mjs seed|verify`，仅允许隔离本地合成测试库。

本轮验收覆盖开发运行环境，未部署阿里云/生产平台。Windows 下直接运行打包 Worker 的错误路径曾触发运行器内部错误，生产部署须另行复现排查；不能以开发环境测试通过替代生产稳定性验收。

### 2026-09-30 运行隔离与来源复核

- 畸形 UTF-8 请求按无效 JSON 返回 400；内部异常仍返回脱敏的 500，不向客户端暴露路径或内部错误。
- 集成测试使用独立 Vite 启动器、端口、缓存目录与 D1 测试库。就绪确认同时校验 IPC 来源、随机 nonce、PID、端口、主机和项目路径，不读取或删除用户的 Vinext 预览锁。
- Windows 清理先记录 PID、父 PID 和创建时间，再检查关闭回执与存活子进程。进程元数据不可读、存在不明子进程或关闭失败时，保留临时数据并停止后续复用；不能把权限不足解释为“没有子进程”。受限环境需要允许只读进程元数据查询。PID 复用可能导致保守地保留临时目录，不因此获得结束其他进程的权限。
- ONLYOFFICE HTTP 回归仍使用合成模拟服务；通过回归不代表实际编辑器、云端访问或生产 Worker 已验收。
- 第十七届总通知与第十六届历史细则分开显示。新届次完整实践赛细则未收录时，适用规则匹配仍为阻断。历史匿名条款保留强制要求，但不再擅自增加来源未明示的“取消资格”后果。

本轮反思：先前仅凭子进程退出消息推断完整进程树已释放，证据不足；独立审查发现后增加只读元数据核验。直接打包 Worker 的请求流错误仍未解决，应单独制作最小复现、定位依赖或应用边界，不降低安全拒绝断言来换取测试通过。

## 方法路线与边界（当前能力）

工作台同时说明数据质量、信度与效度、差异检验、解释与行动各阶段所需条件。KMO / Bartlett、EFA / CFA、t / ANOVA、回归、聚类、SEM、p 值与置信区间**未实现**；路线说明不是可计算能力。α 不是效度、单维性、代表性或比赛质量认证。

方法定义已于 2026-09-30 结合 R / SciPy 官方说明核对。独立 SciPy 1.13.1 与有理数样例位于项目 `.collab/runs/20260930-research-blocks/methods-research/`，为合成测试数据而非田野数据。

回归入口：`npm run test:questionnaire`、`npm run test:analysis`；单元检查包含原有编辑器、案例链与 Office 文件检查。新增后端仅为上文 P0 的汇总、提案与版本事务；ONLYOFFICE 实际引擎与云部署不在本轮验收范围。
