## 文件与运行方式

- `/workspace#cases` 支持关键词、地区和方法筛选；报告内可跳到阅读定位、手动翻页和缩放。按用户的知识产权保护要求，不提供原报告下载入口。
- 点击“导入原报告”可多选文件。按内容指纹匹配，改名不影响识别；内容或页数不匹配会拒绝保存。
- 原 PDF 和封面缓存保存在当前浏览器、当前网站来源的 IndexedDB，不经过服务器。更换浏览器、端口或清理站点数据后需要重新导入。
- 单文件上限 60 MiB，总缓存上限 250 MiB；替换同一报告不重复计算容量。一次只解析一份文件。
- 源图解码上限 32M 像素，显示画布上限 8M 像素；分别控制，避免原报告的高清扫描图被静默移除。
- 目录和详情 API 提供元数据，不提供原 PDF。原报告没有加入 Git 或公开静态资源。本次完成的是本地阅读；跨设备共享原文需另接有权限控制的资料存储。
