# 路演与答辩：资料吸收、成果核对与分段实测

模式：`agent_ui`。这是独立研究辅助功能，不是赛事官方计时器、获奖预测或项目 Gate。

## 来源与取舍

三份私人培训材料共 126 页已重新核对：指南 84 页、回答模板 2 页、路演拆解 40 页。完整文本阅读与关键页面视觉核对分开记录，不声称每页都做了视觉审查。当前 13 个题库主题覆盖了大部分可用经验，本轮没有通过重复出题扩充数量。

指南物理第 4 页关于分段彩排和时间检查点的经验，被独立改写为“开始 → 按段记录 → 暂停/继续 → 结束 → 复盘”。这是 EVI-X 的产品设计推导，不是原资料的软件设计，也不是官方规定的总时长、固定段落比例或预留时长。

回答模板的组织思路可借鉴，但不能用 R²、信效度或工作投入替代方法验证，也不能预设做过试点。路演材料中的表演、角色、IP 均为可选表达，不能证明建议已实施或效果已实现。原件、讲稿、图像、联系方式和案例数字不进入网站。

## 使用

1. 在“路演与答辩”中调整五段练习计划；正式时限仍需核对适用通知。
2. 在“分段实测彩排”输入本轮报告/讲稿版本标签，开始计时。标签由用户填写，系统不会打开或验证该材料。
3. 讲完一段后点“完成本段”。时间到不会自动跳段；暂停时间不计入讲述时长。
4. 切到后台或工作台其他模块时自动暂停。返回后手动继续，中断次数保留。带中断记录不能直接当作连续实战用时。
5. 提前结束保留当前未完成段，未讲段落保持未记录；不会补零或以此宣称达标。
6. 完成五段后比较讲述计划、预留时间与总练习额度。计划变化不会重写历史快照。
7. 结束本轮后单独导出彩排 JSON。最多保留 20 轮，满额不自动删除。清空前明确确认，答辩笔记不受影响。

## 保存与边界

- 彩排只在页面内存中。同页切换模块保留，刷新/关闭会丢失；浏览器离开提示仅是尽力提醒，不能替代导出。
- 彩排 JSON 仅供复盘，当前不支持导入恢复。原有“导入/导出练习笔记”仅处理答辩笔记与时间编排，不包含彩排历史。
- 不录音、不录像、不读取报告、不上传服务器或外部模型；不自动认证口头讲述真实完成、数据正确或证据充分。
- 浏览器单调时钟只用于练习，暂停不计时；设备睡眠/浏览器调度可能影响测量，不替代正式计时。导出不含单调时钟的内部绝对时间。
- 题库来源的年代、组别和获奖说法保留原有边界；不据培训资料新增已核验获奖案例。

## 验收入口

`npm run test:defense` 包含计时模型、冻结快照、暂停/继续、未完成状态、导出限制和原笔记导入兼容检查。独立 UI 挑战和真实浏览器检查记录在本轮 `.collab/runs/20261002-defense-absorption-review/` 中。纯单元测试不等于实际浏览器、真实 ONLYOFFICE、生产环境或赛事提交包验收。

## 建议落地证据卡

这次复核没有重复扩充 13 个训练主题，而是把“发现对应建议、建议对应记录”做成独立可编辑卡片。来源包括指南物理第 3、7、12 页的具体追问、回答模板第 1 页的建议组织，以及路演拆解第 13、28、37 页值得警惕的成果解释。分类和字段是本系统的独立改写与产品推导，不是原件流程或官方要求。

- 一项行动一张卡，默认“尚未声明”；用户可以选择方案、原型、反馈、采纳、实施、观察变化或效果归因。不设进度条，不自动升级，允许记录撤回、负向和未见效的结果。
- 保存支撑发现、对象、责任角色、自报材料版本、有限主张、时间范围、证据位置、指标、对照或识别依据、反证、限制与下一步。
- 根据声明类别提示待补字段。全部填满也只是结构完整，不证明真实性、采纳、实施或因果效果，更不会批准项目 Gate。
- 最多 20 张卡；不自动删除旧卡。成果卡单独导出/导入，不混入原有答辩笔记或彩排包。导入先预览，明确确认后替换同编号卡、追加新卡，其余保留。预览后编辑会取消旧预览。
- 导入上限 384 KiB；不接受未知版本、伪造审批字段、重复键或重复编号、无效编码和超限内容。不截断、不静默纠正未知声明类别。
- 只在页面内存保存，不上传服务器、不调用外部模型、不读取实际证据文件；刷新/关闭会丢失未导出的卡。材料版本是人工标签，不是自动关联或哈希核验。

本功能的模型、导入与容量回归入口为 `tests/action-evidence.test.mjs`，计入 `npm run test:defense`。独立审读、挑战和隔离浏览器验收记录位于 `.collab/runs/20261002-defense-evidence-integration/`；以其最终验收记录为准，不把代码存在或测试夹具存在当作通过。
