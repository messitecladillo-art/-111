# 选择控件使用规则

适用范围：EVI-X 产品界面（`agent_ui`）。这是项目的交互设计规则，不是赛事官方规则；不会改变比赛阶段、Gate 或 Agent 状态。

## 参考与核读边界

1. Will《UIUX / 下拉菜单的专业使用规则》：[小红书视频](https://www.xiaohongshu.com/discovery/item/6aafbd8f0000000027009293)。主协调者于 2026-09-22 实际核读下列关键画面；本文件整理该核读记录，组件作者未另行联网复核。
2. [GOV.UK Design System：Select](https://design-system.service.gov.uk/components/select/)。主协调者于同日核读，作为公开设计系统的补充依据：使用选择列表前，先考虑减少候选项或使用可见单选项；提问时不预选答案。

## 项目规则

- **少量互斥答案，且比较很重要**：优先用带分组题目的原生 radio，平铺可见标签；必要时增加简短说明。
- **大量候选项**：先减少无关选项、分类或分步缩小范围。确需检索时设计可访问的搜索／组合框；不直接把长下拉替换成同样漫长的 radio 列表。
- **年龄、日期等已知值**：按任务选择数值、日期或分段输入，并提供格式说明与校验。出生日期输入不能机械等同于预约日历；本轮没有实现新日期控件。
- **可用性影响选择**：在作出选择前显示状态及原因。不要让用户选完再发现不可用；不以颜色作为唯一状态信号。
- **询问用户事实或意见**：初始 `value` 使用空字符串，让用户主动选择；不能默认勾选第一项来制造答案。已保存的真实回答或明确设置偏好可按其实际值恢复。
- **保留合适的 select**：选项已有固定、熟悉的顺序，或紧凑选择有明确价值时，可以保留原生 select。替换与否取决于任务、可见空间、比较需求和真实可用性测试。

## 可复用组件

`components/ChoiceGroup.tsx` 提供原生 `fieldset`、`legend`、可见 `input[type=radio]` 和整卡可点击的 `label`。

```tsx
import ChoiceGroup from "@/components/ChoiceGroup";

<ChoiceGroup
  legend="目前的材料状态"
  name="materials-state"
  value={materialsState}
  onChange={setMaterialsState}
  required
  options={[
    { value: "not-started", label: "尚未收集", description: "先明确所需材料。" },
    { value: "partial", label: "已有部分", description: "继续补齐证据缺口。" },
    { value: "ready", label: "已经齐备", description: "仍需核查来源与质量。" },
  ]}
/>
```

父组件持有状态；询问新问题时用 `useState("")`，本组件不会自动预选。`tone` 接受 `light`（默认）或 `dark`，只切换视觉，不改变语义或答案。

接入约束：

- 每组的 `name` 在同一表单中唯一；同组候选项的 `value` 唯一且非空，`label` 非空。
- 使用同名原生 radio 保留 Tab、方向键、空格键及表单提交语义，不重写键盘选择逻辑。
- `required` 接入浏览器原生必填校验。若父表单使用 `noValidate`、自定义提交或异步校验，父层仍须提供明确错误反馈与焦点管理。
- 选中态同时保留原生圆点和卡片描边，不只依赖颜色。说明文本与其选项通过 `aria-describedby` 关联。
- 点击区域至少 48px 高；字体不小于 14px，窄容器自动换行。radio 本体使用局部高优先级样式，避免继承全局文本输入框的 100% 宽／48px 高尺寸。
- 本组件不提供搜索、多选、禁用选项或可用性业务逻辑。需要这些能力时须另行定义需求，不用样式假装已经支持。

## 验收清单

静态与类型检查确认原生语义、属性契约及样式可解析；最终接入后还需独立验证：

1. 没有回答时不勾选任何项，必填组不能提交空值。
2. 点击标签和说明区域都能选中对应 radio；一次只选一个选项。
3. Tab、方向键、空格键可操作，焦点清晰可见；没有重复名称或说明朗读。
4. 在实际诊断表单、深色工作台及 320px 窄屏中，控件不溢出、不被全局样式拉伸。
5. 原有表单状态、提交参数及业务逻辑不因替换选择控件而改变。

该清单是验收要求，不表示以上浏览器行为已全部验证。
