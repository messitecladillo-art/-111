# 报告优化体系

目标：任何主题、任何调查设计的报告，都能按同一套流程达到规范、严谨、可读。体系不以任何一篇报告为模板：结构来自研究问题，检查来自通用规范，数字来自已登记的分析结果。

## 原则

1. **问题驱动**：报告的分析章节由研究问题决定。“现状如何”“群体之间有何不同”“哪些因素有关”“人群如何划分”“需要什么、愿付出什么”“哪里做得不好”“先做什么”各对应一个分析模块；没有提出的问题不需要对应的章节、方法或模型。
2. **证据驱动**：报告中的数字只来自已登记的分析结果；图、表、公式由程序按结果绘制和排版；读数段由确定的模板生成，再由作者改写。
3. **规范优先**：统一按通用规范处理格式——图表编号与题注、三线表、资料来源、统计符号斜体与行内公式、负号与千分位、GB/T 7714—2015 文献著录等，不模仿某篇报告的版式习惯。
4. **适配而非堆砌**：方法服从研究问题和变量类型；一个结果默认只配一件最合适的图或表；公式数量随所用方法而定，不追求数量。
5. **可复核**：每个图表都能追溯到登记结果、数据来源与样本量；方法、抽样与清洗规则写清楚，附录可复现。

## 优化闭环

| 步骤 | 做什么 | 在哪里 |
| --- | --- | --- |
| ① 定研究问题与报告类型 | 写出 3–5 个研究问题，选报告类型或逐个选分析模块 | 报告书 → 报告体检 →「按研究类型重建骨架」；写作指引 |
| ② 设计方案与抽样 | 抽样框、各阶段抽样、样本量公式 | 抽样设计 →「写入报告」 |
| ③ 回收与清洗 | 登记剔除规则，核查后登记为报告结果 | 数据分析 → 回收质量控制 |
| ④ 分析并登记结果 | 按研究问题选方法，登记结果（带变量名、统计量与自由度） | 数据分析 → 分析方案 |
| ⑤ 写入报告 | 结果自动落到对应小节：图或表、方法说明与公式（首次出现时）、读数段 | 发现与矢量编排 →「写入报告」 |
| ⑥ 体检与补齐 | 按优先级处理缺口，每项附操作入口 | 报告书 → 报告体检 |
| ⑦ 撰写与改写 | 在模板读数段基础上写出解释、比较与启示；AI 只改写文字，不产生数字 | 报告书 |
| ⑧ 导出与核对 | Word 排版（编号、公式、图表目录），PPT 分镜 | 导出 Word / PPT |

每完成一步回到 ⑥，直到体检没有优先缺口。

## 报告结构：通用框架 + 分析模块

**通用框架**（每份调查报告都有）：摘要；研究项目简介；调查方案设计与实施（目的、对象、内容、方法、抽样、分工、质量控制）；调查数据处理及检验；样本特征与描述性分析；结论与建议；参考文献；附录。

**分析模块**（按研究问题选，均可增删）：

| 研究问题 | 模块 | 典型方法 |
| --- | --- | --- |
| 不同群体之间有没有差异、变量之间是否相关 | 群体差异与关联分析 | 卡方检验、Welch t / F、Pearson / Spearman 相关 |
| 哪些因素与目标行为或态度有关，作用多大 | 影响因素分析 | 线性 / Logistic 回归、结构方程 |
| 人群能否分成需要区别对待的几类 | 人群细分与画像 | 聚类、因子分析 |
| 目标人群需要什么、愿意为什么付出 | 需求与意愿分析 | 偏好排序、联合分析、支付意愿 |
| 哪些环节重要但表现不佳 | 评价与问题诊断 | IPA、综合评价 |
| 资源有限时先做什么、值不值得做 | 方案设计与评估 | 层次分析、成本—效果比较 |
| 公众在讨论什么 | 网络文本与二手资料分析 | 词频、情感、主题模型 |

**报告类型**只是常见的起点组合：现状—问题—对策（默认，适用面最广）、影响因素、满意度与服务评价、需求与意愿。选定后仍可随时插入或删除模块。

## 报告体检的判定方式

- **只查适用项**：没有多题项量表就不查信度、效度；没有建模类问题就不要求模型；还没有图表就不评图文比例。暂无适用项的维度显示“尚不适用”，不计入总分。
- **数量随本报告变化**：公式数对应所用检验与模型的种数；正文篇幅按本报告的分析图表数估计；每个分析小节都应有证据；每个图表都应被正文引用并解读。
- **通用写作规范作阈值**：摘要 500–2,000 字、关键词 3–8 个、参考文献不少于 10 条且均被引用、结果段落多数含数据、段落 50–300 字、核心发现 3–5 条、每个图表约配 200–2,000 字解读。这些是研究报告的一般约定，不是某篇报告的统计。
- 体检只检查结构与证据的呈现，不评判研究结论是否正确；规则可能漏判或误判，结果用于提示。

## 范本的作用

作者提供的优秀报告只用于**校准质量维度**，例如“每个图表后有读数段”“每种方法写出公式”“建议对应发现并写明执行主体与评估指标”。体系不复制其章节、方法组合、图表数量或措辞，范本文件不进入代码库、提示词或示例。
