# 工作台视觉适配 · 2026-09-22

## 范围

用户指定参考 [academic-workbench](https://github.com/wujing855/academic-workbench)。本次按它的侧栏导航、灰米纸面、青绿色强调、轻玻璃卡片和紧凑工作区进行独立适配，不安装其服务、不迁移其数据、不调用其第三方 API。

当前身份仍为证见 EVI-X，`visual.mode=agent_ui`。公开参考项目不是赛事官方规则来源，也不代表双方存在合作。MIT 声明见 `THIRD_PARTY_NOTICES.md`。

## 信息结构

侧栏分为“我的工作台 / 研究与证据 / 项目管理 / 质量保障”。概览、获奖案例、诊断、项目登记和规则解析各有面板。生命周期入口仍指向项目管理内的本地只读视图。

- 原有 URL hash 保留；`#top` 回到概览，`#lifecycle` 打开项目区并定位生命周期卡片。
- 面板切换不会卸载诊断与筛选组件，保留本页输入和结果；页面刷新后不保留临时答案。
- 亮暗主题只存在于当前页面内存，不写入个人设置、密钥或业务数据。
- 移动端侧栏改为折叠导航；切换入口后收起，Esc 可关闭并回到菜单按钮。
- 原有抽屉焦点限制和背景 inert 继续使用；抽屉由 portal 挂在 body，保持浅色阅读面，不受主题祖先作用。

## 保留的功能与真实性边界

获奖案例的来源核验层级、证据成熟度的必答单选、诊断 API、权威控制边界、规则五维匹配均保留。没有添加虚构任务、倒计时、项目进度、比赛成绩或“已联网 AI”状态。弹道仅为教学互动。

## 维护

- `components/WorkbenchShell.tsx`：导航、面板、主题和键盘焦点。
- `app/workbench.css`：附加主题层；不复制上游完整样式表或图片。
- `components/EviXPlatform.tsx`：现有业务组件与面板组合。
- `docs/selection-controls.md`：新学到的选择控件规则。
- `docs/evidence-flight.md`：弹道交互及参考边界。
