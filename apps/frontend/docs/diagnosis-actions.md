# 从诊断到可复核行动

模式：`agent_ui`。本功能是确定性的自报信息辅助流程，不是大模型自动研究、证据认证或赛事 Gate 执行器。

## 已接通的工作流

1. 在 Agent 诊断填写实际状态。输入只在诊断接口处理，不持久化；不提交个人信息或企业机密。
2. 风险行动按高、中、低优先级排序。行动卡列出准备材料、预期产物、复核条件，并打开对应工作区。打开页面不等于任务已完成。
3. 点击“预览问卷简介提案”，进入问卷设计；这一步不修改任何问卷内容。
4. 点击“比较当前设计与提案”，检查当前内容与拟写入内容。默认只选择空白字段，覆盖已有内容必须明确勾选。
5. 显式应用选中字段后，进入现有研究映射与设计检查。仍需逐题设计与人工复核；可用一次撤销恢复应用前版本。

实际可写入字段仅为问卷名称、调查对象、地域和决策目标。决策目标明确组合“决策主体”和“决策问题”，不推测题目、抽样、预试、数据或调查结论。其他字段、已有题目和显示条件逐项保留，分类仍为 `proposed`。

## 版本、容量与控制边界

- 诊断成功时固定本次提交快照；五个文本字段与接口一样去除首尾空白。修改任一输入或重新提交立即清除旧结果和待确认提案。即使恢复原文字，也不会复活旧提案。
- 预览固定目标问卷版本。之后编辑、撤销或重做都会使旧预览失效，必须重新比较。未完成数值输入、导入或确认操作期间不应用提案。
- 诊断允许的部分字段比问卷上限长。超限字段完整展示并单独禁用，不静默截断；用户可以只应用其他合法字段，或精简诊断输入后重做。最终整体问卷仍受 300 KB 等原有校验约束。
- 操作取消、校验失败或过期时保留原设计。应用通过既有问卷撤销历史完成一次事务；应用本身没有服务器写入或自动存储。
- 提案与未保存设计仅在当前页面内存。同页切模块保留；刷新会丢失。应用后可“下载备份”，或在 [问卷版本库](questionnaire-library.md) 明确保存本版设计。这两者都不保存诊断评分、独立来源认证或完整执行日志。
- 字段白名单、允许导航、严格参数校验和冻结映射限制本步可执行行为。未知行动代码不会变成任意链接或命令。

## 评分的诚实边界

既有分数依据文字长度、关键词及自报阶段/证据成熟度计算，只是启发式提示。它未阅读报告、核验来源或审查真实田野，不能表示获奖概率、研究质量或 Gate 通过。自报“已核验”不会赋予问卷已验证身份。

## 本轮反思与修复

- 发现：诊断只输出静态清单，工具链断开。改进：保留稳定行动代码，并接通一个实际、可选择、可撤销的问卷简介写入步骤。
- 发现：修改输入仍显示旧结果；高风险项可能被前五项截断。改进：逐次输入失效保护，严重度排序后截取。
- 独立挑战：异常字段选择数组可扩大授权范围，行动映射内层可被修改。改进：先严格复制普通数据，拒绝访问器和额外成员；逐项冻结行动描述。
- 集成检查：类型收窄和渲染中读取 ref 被校验拒绝。改进：使用已验证字段对象、独立渲染 revision 状态，保留事件处理器中的实时 revision 检查。
