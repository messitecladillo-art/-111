# 词云与选题

入口：工作台 `#diagnose`（Agent 诊断）→「词云与选题」标签。与「准备度诊断」并列，评估出的候选题目可一键带入准备度诊断。

本模块帮助团队先读懂一个研究领域，再用可追溯的证据筛选题目。它借鉴 VOSviewer（关键词共现图谱）、CiteSpace（突现、中介中心性、聚类质量、时间线）与 Connected Papers（文献关系网络）的成熟做法，全部计算在浏览器内完成，文件不上传。

## 立场与边界

- **不估计获奖概率。** 内置获奖案例索引只有 32 项（29 项官方来源核验题名，3 项用户陈述），不是全量榜单，也没有未获奖作品作对照。因此获奖题目只作描述性参照：要素出现比例、题面相似度与公告来源。
- **不生成任何文献或数据。** 所有图表只呈现用户导入文件中的真实记录；缺少的字段（参考文献、被引次数、年份）如实降级并在图上注明，不补全。
- **区分证据类型。** 文献统计为计算结果；题目要素为关键词规则识别（显示触发词，可能漏判）；可行性为自评，未经核验。
- **“少见”不等于“值得做”。** 研究空白检验只说明两个词很少被一起研究；是否值得研究，要靠一个真实的决策问题来论证。

## 数据导入

| 来源 | 格式 | 可用字段 |
| --- | --- | --- |
| Web of Science | 纯文本（Full Record and Cited References）、RIS、BibTeX | 题名、作者、年份、来源、作者关键词、Keywords Plus、摘要、被引次数、DOI、参考文献 |
| 中国知网 | RefWorks、EndNote | 题名、作者、年份、来源、关键词、摘要（不含参考文献与被引次数） |
| Scopus、文献管理软件 | RIS、BibTeX | 视导出内容而定 |

- 可一次导入多个文件，按 DOI、再按“规范化题名 + 年份”去重；单文件上限 20,000 条，合计 80 MB。
- UTF-8 解码出现乱码时自动改用 GB18030（旧版知网导出）。
- 「示例语料」可直接载入内置获奖案例索引的题名，用于体验，结论只描述这 32 个题名本身。

## 词与计数

- **词来源**：作者关键词 / 作者关键词 + 数据库扩展词 / 题名抽词 / 题名与摘要抽词。默认在多数记录带关键词时用作者关键词。
- **抽词**：英文按停用词切分 1–3 词短语；中文先删去“研究、分析、基于、路径、策略”等通用措辞，再用浏览器的 `Intl.Segmenter` 分词，由 1–4 个相邻词组成短语，因此不会产生跨词碎片（如“京市老”）。若一个短语几乎总出现在更长的短语里（≥ 80%），保留更长的那个。
- **规范化**：全半角折叠、大小写折叠、英文末词单复数合并（保护 data、analysis 等词）、复数缩写（EVs → ev）。「合并与排除」支持 `原词 => 统一词` 与单独排除。
- **全计数**：每篇记录中一个词只计一次。

## 七个视图

| 视图 | 借鉴 | 编码与方法 |
| --- | --- | --- |
| 词云 | — | 字号 ∝ √篇数（同字数时面积与篇数成正比）；颜色为聚类或平均年份；版面放不下的词列出数量，并提供完整表格 |
| 共现图谱 · 网络 | VOSviewer | 圆面积随篇数增大；连线为共现，强度另报关联强度 = 共现 × N ÷（篇数A × 篇数B）；Louvain 模块度聚类（固定访问顺序，可复现）；固定种子的力导向布局，坐标轴无含义 |
| 共现图谱 · 时间线 | CiteSpace | 每个聚类一条横道；横轴可选平均发表年份或首次出现年份；连线为 Pathfinder 骨干 |
| 突现 | CiteSpace | Kleinberg 二状态模型（s = 2，γ 可调，最短持续 1–3 年）；强度为突现期内相对基线的对数似然增益；延续到最新年份标“至今”；可对关键词或被引参考文献检测 |
| 文献网络 · 书目耦合 | Connected Papers | 两篇施引文献共同引用的参考文献数，余弦归一化；每篇保留最强 6 条关系。参考文献不足时改用关键词 Jaccard 相似度并明确标注；无被引次数时圆大小改按关系数 |
| 文献网络 · 共被引 | CiteSpace | 被本集合引用最多的 100 篇参考文献，同一施引文献同时引用即连线；侧栏列出“奠基文献” |
| 时间脉络 | “蒲公英”图 | 角度 = 发表年份，离中心距离 = log(被引 + 1)，颜色 = 主要聚类，内圈短柱 = 每年篇数；无被引次数时改为按年向外堆叠 |

结构指标（共现图谱顶部与聚类表）：

- **模块度 Q**（加权）：> 0.3 通常视为聚类结构清晰。
- **轮廓值 S**（1 − 共现向量余弦距离）：> 0.5 合理，> 0.7 高度一致。
- **中介中心性**（Brandes 算法）：在 Pathfinder（r = ∞，q = n − 1，即所有最大生成树的并集）剪枝后的骨干网络上计算，≥ 0.1 标紫圈，表示“枢纽词 / 枢纽文献”。全计数网络几乎两两相连，中心性普遍接近 0，因此先剪枝，与 CiteSpace 的常见做法一致。

这些阈值都是惯例，不是检验。

## 选题工作台

**从文献中找方向**

- **选题篮**：在词云、共现图或突现表中点击词加入，可用于筛选文献网络、突出时间脉络，或直接起草候选题目。
- **研究空白候选**：取篇数 ≥ 5 且不超过半数记录的前 60 个词，两两计算独立预期共现 = 篇数A × 篇数B ÷ N。只检验预期 ≥ 3 篇、且互不包含的词对。每对做单侧 Fisher 精确检验（超几何分布下实际共现不多于观测值的概率），再用 Benjamini–Hochberg 方法把错误发现率控制在 5%，并保留实际不到预期一半的组合。卡片显示实际与预期、q 值、是否跨聚类、两词趋势，以及少数已有的结合研究。
- **前沿信号**：延续到最新年份的突现词，以及近 3 年占比显著上升的词。后者用双比例 z 检验，两段各需 ≥ 20 条记录、该词 ≥ 8 篇，|z| ≥ 1.96。
- **枢纽词**：中介中心性 ≥ 0.1 的词。

**评估候选题目**（证据画像）

输入题目后自动识别其中出现过的语料词：较长的短语优先，同义词表生效，可手动增删。六个维度各自给出“有证据支持 / 仅作参考 / 需要补强 / 无法判断”，**不合成总分**：

| 维度 | 依据 |
| --- | --- |
| 文献基础 | 每个核心词的篇数与占比（< 3 篇需补强）；核心词是否为枢纽词 |
| 新颖度 | 同时含全部核心词的文献数与独立预期；两两共现与单侧 Fisher p 值。≥ max(10, 1% N) 篇视为已较充分，需写清差异；0 篇提示先用决策问题论证组合的必要性 |
| 时效 | 各核心词的近期占比变化与 z 值、突现期 |
| 获奖题目参照 | 相似度 = 0.6 × 题名字符二元组 Jaccard（去掉通用措辞）+ 0.4 × 案例标签命中比例。显示届次、奖项、核验状态与公告链接；Jaccard ≥ 0.35 提示与已获奖题目高度相近 |
| 题目要素 | 主副标题、研究人群、地域或场景、测量对象、行动导向。显示触发词，以及“29 个官方核验获奖题目中有多少含此要素”；另报题目字数与获奖题目字数的中位数和四分位 |
| 可行性（自评） | 决策者、人群触达、一手数据、敏感信息 |

画像以“神经元”式证据树呈现，下方是“下一步可以补强”清单和逐维明细。最多 4 个候选可并列对比（只并列状态，不排序），并可复制为 Markdown（保留来源与边界说明）或带入准备度诊断。

## 导出图表

每张图都有「导出 SVG」按钮，覆盖词云、共现网络、时间线、突现图、书目耦合网络、共被引网络、时间脉络、研究空白候选图和证据画像。导出规则：

- 背景透明，不含网格与选择高亮。
- 计算后的样式内联为属性，文件不依赖页面 CSS。
- 图下附标题、图例、方法说明与数据来源（数据库、条数、年份、词来源与阈值）。
- 画布绘制的时间脉络与 HTML 突现表另行生成矢量版本。
- 配色与当前主题一致：白底文档请在浅色主题下导出。
- 导出内容不含证见标识，可放入匿名提交的报告。
