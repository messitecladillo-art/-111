# 浏览器身份恢复（本地试用）

恢复的是同一服务器上的编辑身份：报告文字草稿、PPT 讲稿、命名版本，以及已保存的 DOCX/PPTX 原文件和版本。[问卷版本库](questionnaire-library.md) 也按同一 owner 隔离，设计上可通过恢复身份读取已存版本；本轮新增问卷的新 Cookie 恢复场景尚未完成独立 HTTP 验收。它不是全文制作引擎，也不是文件备份或账号登录系统。问卷未保存的浏览器本地状态、项目控制台的另一套身份不在恢复范围内。

## 使用

1. 在编辑器的“身份与恢复”中刷新当前状态。
2. 主动生成随机密钥，保存到自己的密码管理器或安全位置。系统不会自动写入剪贴板或浏览器持久化存储。下载操作只启动浏览器下载，不证明文件已落盘。
3. 确认已妥善保存后登记。只有收到匹配的服务器确认才算启用；网络结果不明确时保留同一密钥重试，不要关闭页面后凭记忆假定成功。
4. 清除 Cookie 或换浏览器后，打开同一部署，粘贴密钥并明确确认恢复。当前页面及收到通知的其他标签页会暂停编辑器请求；先导出未保存文字，再手动刷新进入恢复的文件库。
5. 轮换密钥会永久作废旧密钥，但不注销已登录的浏览器会话。曾使用的密钥不允许再注册给任何身份。

持有密钥的人可访问该编辑身份的全部作品。不要把密钥放进论文、答辩 PPT、工单、截图、聊天或公开仓库。服务器不提供查看或找回已登记密钥的接口。未提前登记并保存密钥、且 Cookie 也丢失时，无法仅凭作品名称找回。服务器数据库或文件对象丢失时，身份密钥不能恢复文件本身。

## 安全和实现边界

- 浏览器用 Web Crypto 生成32随机字节；服务端以域分离 SHA-256 保存 verifier，只保存恢复会话 token 的哈希，不保存或返回原始密钥/会话令牌。
- 原有 Cookie 身份的 owner hash 保持不变。恢复后的新 HttpOnly Cookie 通过服务器映射回同一 owner；文件、字节、版本和原归属不搬迁、不覆盖。
- 新端点只允许浏览器匿名编辑身份。平台登录或 `x-client-key` 身份不被转成匿名身份。现有部署的代理可信边界仍是平台自身的前置条件。
- 所有恢复操作要求 HTTPS（本机回环开发例外）、同源、显式保护头和固定当前 scope；身份变化不会自动保存到另一个库。普通接口对过期恢复 Cookie 返回401；只有显式会话初始化会发新匿名 Cookie，随后可以使用密钥恢复。
- 同源 GET 状态在浏览器未发送 Origin 时只接受 `Sec-Fetch-Site: same-origin`；变更端点始终要求精确 Origin。
- 恢复请求与 Cookie 初始化使用同一 Web Locks 锁；不支持 Web Locks 的环境禁用恢复。跨标签页通知只携带身份切换事件，不携带密钥、scope 或内容。通知不可用的旧页面仍会在下一次带旧 scope 的请求收到冲突。
- 每个身份最多20个未过期的恢复会话、1024条终身恢复会话记录和1024条密钥历史记录。历史哈希不删除，以免旧凭据被重新绑定。上限是本地试用保护，不是生产分布式限流；达到上限需维护方案，不通过删除文件绕过。
- 256位随机密钥降低猜测风险，但不代替生产登录体系、强制重新认证、恶意请求限流、CSP/XSS防护、设备撤销与操作审计。未通过生产并发或安全认证。
- 密钥未加密保存在用户选择的下载文件中，因此下载目录、剪贴板、密码管理器及设备安全由用户管理；共享设备不宜下载到公共目录。
- 已发送的旧身份写请求可能仍在服务端完成；页面冻结只能停止后续请求和丢弃过期确认，不虚构撤回已提交事务。

## 维护与验证

备份必须同时保存 D1 元数据与原文件对象。恢复表也在 D1 内；换部署但不迁移数据库不会继承身份。默认本地开发状态位于应用 `.wrangler/editor-state`，不要为了排错清除该目录。

使用隔离测试数据库运行 `npm test`，不向用户库添加测试作品。验收包含密钥轮换 CAS、历史密钥不可转让、身份隔离、文稿/讲稿/版本/两种 Office 文件字节一致及服务器重启。真实浏览器另验收显式操作、冻结和手工刷新，不把模拟测试当作完整浏览器验证。

参考（2026-09-27核验）：[OWASP 恢复凭据安全建议](https://cheatsheetseries.owasp.org/cheatsheets/Forgot_Password_Cheat_Sheet.html)、[MDN Origin 请求头](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Origin)。本功能是可重复使用、可轮换的离线备用身份密钥，不是一次性密码重置链接；不宣称完整满足密码重置流程。
