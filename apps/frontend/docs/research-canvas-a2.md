# A2：研究画布基础操作验收

本批基于已合并的 PR #9（`5926a58f`），只增强 `/workspace#canvas` 的基础交互。托管项目的编辑器宿主仍在独立的 A1 PR；本批不迁入未合并的服务端画布或变更首页。

## 行为

- 新增可点击节点库，也可拖到落点；复制保留选中子图内部连接，重新生成节点与连接 ID，清除人工复核确认。
- 连线可从端口拖动，也可使用选中工具栏的「连接…」。两种方式采用同一套类型、单输入、重复与循环校验；点线仅用于说明。
- 一次拖动、多选移动或一次方向键长按各对应一次撤销。拖动中 Esc、失焦、隐藏页面或切换视图恢复手势开始时的位置。
- 删除立即更新结构；退场副本只负责 160ms 装饰，不接收输入、不参与计算。撤销恢复原 ID、位置和连接，并中止旧退场。
- 选择 180ms，新增／复制／恢复 220ms，连线 180ms，拖动抬起 120ms。React Flow 负责坐标，动画只作用于内部壳；关闭动效直接显示终态，系统减少动态偏好优先。
- 复制采用附近落点的 220ms 展开；本批尚未实现从原卡飞向副本的连续轨迹。
- 自动排布中开始拖动或撤销会取消旧布局动画。快速操作采用即时历史引用；视觉定时器和帧循环在离开或卸载时清理。
- 导入复用节点 ID、但输入／输出端口变化时，刷新端口位置缓存；拖动与选择不额外量测。撤销导入也刷新改变的端口。

## 桌面和压力验收

确定性结构图不包含答卷和虚构的分析结果：

```powershell
node --experimental-strip-types scripts/canvas-interaction-fixtures.mjs --preset daily > daily.canvas.json
node --experimental-strip-types scripts/canvas-interaction-fixtures.mjs --preset stress > stress.canvas.json
```

分别生成 50 节点／80 连线与 200 节点／500 连线。使用画布「更多 → 导入画布结构」导入，在节点列表定位目标后拖动。性能记录需在构建时显式设置 `NEXT_PUBLIC_EVIX_CANVAS_DIAGNOSTICS=true`；正常构建不显示诊断控件。

观察器只记录真实节点指针手势，显示拖动期间的 RAF 帧间隔、输入处理到下一 RAF 回调的等待时间、可用时的 JS 堆和长任务。后一项是回调等待指标，包含不了输入派发排队或 GPU 绘制，不等于端到端交互延迟。压力图交互测试也不替代后台任务或统计计算吞吐测试。

### 实测环境与结果

Windows 桌面，Intel Core i9-14900HX（24 核／32 线程）、16 GiB 内存、Codex 内置 Chromium 浏览器；Node 24.15.0、Next.js 16.3.6、React 19.2.8。生产构建，1440×900，标准动效，定位到 0.9 倍缩放、配置面板展开。每张图执行 10 次实际节点拖动，核验每次位置确实改变；全部节点和连线都已挂载。

| 图 | 实际节点／连线 | 指针移动／帧样本 | RAF 帧间隔中位／P95／最大 | 输入处理→下一 RAF P95 | 长任务 | JS 堆起止 |
|---|---|---|---|---|---|---|
| 日常图 | 50／80 | 80／257 | 4.2／4.4／9.1 ms | 1.0 ms | 0 | 29.4→40.3 MiB |
| 压力图 | 200／500 | 80／456 | 4.2／11.4／17.8 ms | 3.0 ms | 0 | 32.5→55.7 MiB |

这些是本机的有限样本，不能据此确认所有硬件的 60fps 或端到端交互 P95＜100ms。JS 堆为运行时快照，没有强制垃圾回收，不能作为泄漏或长期内存上限判定。

### 真实交互检查

- 节点库点击添加与实际拖入落点均通过；端口实际拖动新增连线、错误数据类型拒绝、撤销连线通过，控制台没有新增错误。
- 选中节点方向键移动、多选拖动对应一次撤销；断开连线后撤销恢复原连接 ID。
- 连续复制→删除→撤销恢复原副本 ID 和位置，关闭动效模式没有删除视觉副本。
- 20 次工作台／画布往返后，节点 ID、位置、中文节点名称与连接数量保持一致。
- 导入日常图→压力图→撤销→恢复，不刷新页面，完成端口量测后分别完整显示 80／500 条连接；压力图的 500 个连接 ID 与输入一致。
- 200 节点上限时复制被明确拒绝，原结构保持；快速操作、节点与关联边删除恢复另有核心测试和浏览器回执。
- 1280×720、1440×900、1920×1080 桌面检查通过；1280 下节点库与配置面板均留在视口内。标准／减少／关闭设置可切换；Esc 关闭面板并恢复节点库触发按钮焦点。

本轮压力测试修复了两项真实缺陷：端口拖动触发 React Flow 更新循环；相同 ID 更换节点端口后沿用旧量测，导致部分数据连线缺失。两者均在最终生产构建复测。

### 验证边界

原生自动化工具以一个不可拆分的动作执行拖动，无法在按住指针的中途插入 Esc。取消手势的恢复、晚到事件隔离和清理已做源码独立复核，核心位置操作有测试；中途 Esc／失焦取消仍需人工验收，未标为浏览器通过。尚未测量输入法组合输入中途切换、方向键长按的系统重复速度及跨硬件性能。
