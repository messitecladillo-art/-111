# Word 报告排印

入口：工作台 `#editor`（「报告与 PPT」）→ 导出 Word 报告正文 / 附录。实时预览与导出使用同一套编号、图、表和公式规则。

## 公式

- **独立公式**：在「发现与矢量编排 → 图文内容块」里给章节加「＋公式」，输入 LaTeX；输入框下方即时排出公式，无法解析时显示原因。导出为 Word 原生公式（OMML，可在 Word 中继续编辑），右侧按章编号，如 (2-1)。
- **行内公式**：正文中写 `$…$`，如 `$n_0$`、`$\chi^2=26.84$`，导出为句中的 Word 公式。`$` 与内容之间不能有空格；写美元符号请用 `\$`。
- 转换过程：KaTeX 解析 TeX → MathML → OMML（`lib/omml.ts`），抽样手册全部公式都在测试中逐一转换并检查结构。

## 编号与引用

- 图、表、独立公式按章编号：图 4-1、表 4-1、(4-1)；附录用附图 1、附表 1。图题在图下，表题在表上，题号与标题之间空两格。
- 正文引用写作 `[[图:块ID]]`、`[[表:块ID]]`、`[[式:块ID]]`，导出时换成“图 4-1”“表 4-1”“式（4-1）”。正文编辑区的「插入引用」下拉框会在光标处插入；内容块上的「复制引用」也可复制该标记。
- 引用的块被删除、类型不符或被复制成两处时，预览中标红，导出会停下并指出所在章节。
- 开启目录时，目录之后自动生成表目录与图目录（在 Word 中更新域即可显示页码）。

## 一键写入报告

「发现与矢量编排 → 研究发现」的已登记结果下方有「写入报告」：

- 默认写到报告蓝图对应的小节（人口统计变量 → 样本特征分析，其他频数与数值描述 → 描述性统计分析，交叉表、分组比较与相关 → 差异检验与相关分析，信度 → 正式调查数据检验，问卷质量筛查 → 正式调查数据处理，抽样框 → 抽样设计）；报告里没有该小节时，连同所在章按蓝图顺序新建。也可在下拉框中改选任一已有章节。
- 每个结果默认只插一件图表：分布与比较用图，题项和规则清单用表，单个相关系数直接写进正文。可勾选“图”“表”调整。
- 同时写入一段**读数段**（`lib/report-templates.ts`）：先写主要规律及数字，再写检验的统计量、自由度、p 值和效应量（如 $\chi^2(4)=26.84$、$p<0.001$、Cramér $V=0.160$），并按 0.05 显著性水平下结论；统计符号一律为行内公式；相关与差异只写“关联”，不写成因果。所有数字取自登记结果，不经过 AI。
- 某种检验第一次出现时，先写一段方法说明及其公式（$\chi^2$ 与 Cramér $V$、Welch $t$ 与自由度、Welch $F$、Pearson $r$、Spearman $\rho$、Cronbach $\alpha$），并附“式中，……”的符号说明；同一报告中再次出现时不再重复。（以报告中是否已有以该统计量开头的公式为准，旧版合写的公式同样识别。）
- 写入后可撤销；生成的段落与普通内容块一样可以继续修改。

## 图

- 由已登记的分析结果直接绘制（ECharts 服务端 SVG，`lib/report-figures.ts`），Word 中为矢量图并附 PNG 兼容图。
- **一个报告一种色相**：所有颜色都是报告主题色的深浅梯度（`accentScale`），不引入其他颜色，灰度打印仍可分辨；有序类别由浅到深。标签在深色块上用白字、浅色块上用黑字。
- 图型随结果而定，种类多样但每个结果只出一张：
  - 频数：两到四类为环形图（中心标注样本量 $n$），更多类别为柱状图，类别名较长或超过七类时横放；无序类别按占比从高到低，“其他”置后。
  - 交叉表：行内占比的百分比堆叠条形图（每组标注 $n$）；列类别超过六个时改为热力图；选择“频数”或“期望频数”列时按所选列画分组柱状图。
  - 分组比较：均值条形图并附 ±1 标准差须线，组名后标注 $n$。
  - 单个数值变量：箱线图（须线到最小值与最大值），标注五数概括与均值。
  - 相关系数：在 −1～1 的刻度上标出系数及其 95% 置信区间，并画出零线（默认只写进正文，需要时可勾选“图”）。抽样框只用表。
  - PPT 原生图表与 LaTeX 导出不画相关系数（否则会把 r、n、p 当作同一组数值），会提示改用表格或文字。
- 图高随内容变化（宽度统一），Word 中按同一比例放到版心宽度。
- 负数用减号“−”，坐标轴刻度不加千位逗号；统计符号（$n$、$r$、$\rho$）为斜体。
- 数据中的类别名、题目名一律按原文写入，其中的 `[[…]]` 或 `$` 不会被当作引用或公式。
- 字体与正文一致（中文宋体、数字 Times New Roman）；评分量表（非常不满意……非常满意、从不……总是）与年龄段等有序类别按自然顺序排列，表格同样如此。

## 表

- 三线表；表内文字五号；长表跨页时重复表头。
- 只保留读者需要的列：频数表为类别、频数、占比与 95% 置信区间并附合计行；交叉表排成矩阵，单元格为“频数（行内占比）”，附行列合计；分组比较为样本量、均值、标准差、中位数。
- 按含义取位：计数取整，百分比一位小数，p 值写作 <0.001，同一张表内的统计量统一两位小数。不识别的结果保留全部列，只做取位。

## 来源与注释

- 每个图表下方一行资料来源（来源、有效样本量、数据类别）；同一结果的图和表只标一次。
- 各结果的方法说明（如“检验不证明因果”“未加权”）在每节末尾合并为一条“注：”，重复的句子只出现一次。

## 版式

- 中文宋体 / 黑体，西文与数字 Times New Roman；封面标题黑体二号；其余版式沿用报告格式设置（A4、页边距、行距、页码）。
- 由报告文字生成的 PPT 页面同样把引用标记换成图表编号。

- `tests/omml.test.mjs`：抽样手册全部公式可转换且结构完整；分式、求和、重音、根式、分段函数、粗体希腊字母、下括号、空白与函数名的映射。
- `tests/report-word-engine.test.mjs`：按章编号与附录编号、引用解析与失效拦截、重复块标识、表格取位与矩阵、图型选择与 SVG 安全、所有着色都属于主题色相、类别自然顺序、行内公式切分、Word 中的公式 / 题注 / 来源 / 注释 / 图表目录、PPT 页面不出现引用标记。
- `tests/report-templates.test.mjs`：变量名随结果登记且不改变旧结果指纹、题注、各方法读数段的数字与检验写法、行内公式均可排版、不出现因果措辞、方法说明与公式只写一次、写入位置与新建章节、内容块上限、写入后导出 Word。
- 本机 Word（COM）打开导出文件无修复提示，公式计数与内容一致。
