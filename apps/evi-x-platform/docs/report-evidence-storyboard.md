# 报告多证据分镜

本批在现有报告分镜中增加“多证据组合”。先选主讲章节与原文，再明确选择来自不同章节的段落、图表和表格；一页最多两幅图表，最多十二个章节来源。更换主讲章节只调整来源顺序，原有选择保留。公式继续在成果编辑器单独编排。

图表复用报告的共享图形 ID、结果 ID、数值列与内容块 ID，不从截图重绘统计值。新对象增加 `sourceSectionId`，把内容块引用限定在所属章节；不同章节的块可以同名。旧对象没有章节所有者时，只有类型、图形、结果与数值列唯一匹配才能显示已覆盖，存在歧义则要求复核。

预览先检查模拟类别、缺失来源、容量和导出适配；大表或过密页面要求分拆，不截断数据、不缩小文字通过检查。确认后通过父编辑器既有撤销入口追加或替换 PPT，报告原文保持。旧单章卡继续走原路径，未强制迁移为新的多来源卡。

预览绑定精确作品内容。生成期间编辑变化、撤权或旧结果晚到时，旧预览不能写入。父层再次校验当前权限票据、身份过渡、版本操作及精确 base；组合页应用时显式升级为 `EditorContent/v3`。正文与编辑器实例沿用原宿主。

新 v3 关联绑定所有已声明来源、内容块、结果、发现和图形/配色，以及页面对象。嵌套对象键采用固定排序以抵抗 JSON 存取的键序变化；v1/v2 历史指纹继续按原语义读取。格式、内容、来源和对象变化分别触发待复核，指纹一致不代表研究判断已获科学或人工批准。

前后端共享 `tests/fixtures/report-storyboard/source-owner.json` 的合成汇总样例，验证新字段精确保存、旧 v2 拒绝新增所有者、旧无所有者内容保持可读，以及缺块、错误对象类型、空白、控制字符和长度越界。API 测试使用真实解码器，不依赖数据库、网络或 TeX 编译器。浏览器焦点、原生中文输入和新文件 Office/WPS 效果需另记实测，不能由合同测试代替。

本批不包含证据附录、项目 AI 日志适配器或 E 的界面与 API；这些继续独立审阅。研究画布和这里的 PPT 编排均不推进赛事 CLI 阶段或 Gate。
