# 抽样设计

入口：工作台 `#sampling`（侧栏「研究与证据 → 抽样设计」）。对应评分中“方案设计”的样本代表性与调查方案、“调查实施”的抽取记录，以及“分析与结论”中按设计计算精度。所有计算在浏览器内完成；输入只保存在本机浏览器。

**所有公式都以 KaTeX 排版的标准数学公式呈现**（`components/math/Tex.tsx`，katex 0.16.29），不使用纯文本或等宽字符串表示公式；每个公式可一键复制 LaTeX 源码，直接粘贴到报告的 LaTeX 版面。

## 推断边界

- 多阶段设计中只要有一个阶段为拦截、配额或方便抽样，整个样本就不是概率样本：方法段落写明这一点，样本量公式给出的精度仅作规模参照。
- 加权只能减少与调整变量有关的偏差；非概率样本加权后仍不是概率样本。
- 复杂样本方差采用“最终群”近似（初级单元视为层内有放回抽取），提供各层初级单元总数时作有限总体校正；只有 1 个初级单元的层须先合并。
- 系统抽样的方差没有无偏估计，给出简单随机近似与相邻差分两种近似；PPS 不放回的方差用放回近似（偏保守）。

## 验证

- `tests/sampling-methods.test.mjs`：与 R `survey` 4.5 / `sampling` 2.11 的结果对照（`tools/build-sampling-reference.R` 生成 `tests/fixtures/sampling-reference.json`）——加权分层整群设计的线性化均值、总量、比例、设计效应、logit 区间、子总体、刀切法、有限总体校正；平衡半样本与 Fay 方法（总量与线性化严格相等）；整群、二阶、分层、比率、GREG；迭代校准与事后分层权数；πPS 入样概率；两组比较样本量。用穷举全部可能样本证明简单随机、分层、Hansen–Hurwitz 估计及其方差估计无偏；用固定种子的蒙特卡洛检验比率、回归、整群、二重抽样、随机化回答的方差公式与各抽取程序的入样概率；规划器（分层样本量、费用最优、普查层、累积平方根、二阶最优、二重抽样条件、无回答追访）与方案段落、抽样框表。
- `tests/sampling-handbook.test.mjs`：手册中全部公式与行内数学、各计算器输出的每一步公式都能被 KaTeX 严格编译。
- `tests/sampling.test.mjs`：样本量（比例 385 / 370 / 278 等经典数值；均值的有限总体校正为 $n_0/(1+n_0/N)$）、分配与方法段落措辞。
