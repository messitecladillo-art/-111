# 回收质量控制

入口：工作台「数据分析 → 数据检查」，读取数据后出现在缺失代码设置下方。对应评分中“调查实施”的质量控制与数据处理：先登记规则，再看标记结果；原始数据不变，剔除只作用于后续分析，并留下可放入附录的剔除台账。

## 规则

| 规则 | 判定 | 默认处理 |
| --- | --- | --- |
| 作答过快 | 用时低于中位用时的指定比例（默认 1/3），或低于固定秒数。读取 `180秒`、`3分10秒`、`1.5分钟`、`00:02:03`、纯秒数等格式；无法读取的行不标记并单独计数 | 剔除 |
| 直线作答 | 所选同一量表的 ≥3 道题全部选同一选项（只检查答全的行）。候选列只列出取值为少量数字的题目 | 仅标记 |
| 注意力题 | 指定题目不等于预设答案，未作答也计为未通过 | 剔除 |
| 同一 IP 重复提交 | 同一 IP 第 2 次及以后的提交，保留首次 | 仅标记 |
| 答案完全重复 | 除编号、平台时间、时长和 IP 列外所有答案相同的第 2 份及以后 | 剔除 |

答卷编号、作答时长和 IP 列按问卷星、腾讯问卷等导出的列名自动识别（序号、所用时间、来自IP、Duration (in seconds) 等），可手动更改；只按完整列名识别，“通勤用时（分钟）”这类题目不会被当成平台字段。XLSX / SAV 导入的数据同时核对原始列标签。

## 流程与记录

1. 选择规则与阈值，点击“登记规则并核查”。登记时间写入台账；规则改动后旧结果失效，须重新核查。
2. 结果表列出每条规则的判定标准、标记数和比例；一行可能同时触发多条规则，剔除数按行计。
3. 每条规则可选“剔除”或“仅标记”。直线作答和同 IP 默认只标记：前者可能是真实一致的态度，后者在校园网、移动网络中常见共用。
4. 下载剔除台账：来源文件名、原文件 SHA-256、登记时间、每条规则的标准与处理方式，以及每个被标记答卷的原表行号、答卷编号、触发规则和“剔除/保留待复核”。
5. “以质控后数据继续分析”用保留的行重新载入分析（仅限 CSV 读取与系统回收的数据；SAV / XLSX 导入带有原始编码与平台解释步骤，请按台账在原平台筛除后重新导出，避免绕过编码确认）：数据名称注明剔除行数，页面显示来源、规则与台账 SHA-256；真实或模拟属性继承原数据，模拟数据质控后仍是模拟数据；系统回收的数据保留发布版本与冻结题目对应。台账哈希按实际下载的文件字节计算。分析记录导出中包含这条来源链。原始数据可随时重新读取。

阈值应在看到分析结果之前确定，不要为了得到显著结果而调整规则。

## 验证

`tests/data-quality.test.mjs` 用一份仿问卷星导出的合成表覆盖：平台列识别（不误识别 `tip`、`zip` 等列名）、各种时长格式、五条规则的标记行与判定标准、剔除与仅标记的区分、台账内容、CSV 往返（引号、逗号、换行）和量表候选列识别。
