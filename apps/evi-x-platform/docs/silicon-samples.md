# 硅基样本实验室

入口：工作台 `#silicon`；在「我的项目」中打开项目后，可在「硅基样本」标签下使用语言模型引擎。

硅基样本（silicon samples）指让语言模型按设定的身份扮演受访者作答问卷。本模块把它限定在**最稳健的用途——预测试**：在真人作答前发现题目表述不清、选项缺失、跳转错误与作答负担，并演练分析流程。

## 使用边界（界面首屏与导出处同时展示）

| 用途 | 本模块立场 |
| --- | --- |
| 预测试、表述打磨、分析演练 | 推荐，主要用途 |
| 模拟难触达人群 | 只作参考；**不得**用模拟回答填补、扩充或替代真实样本，不与真实答卷混合分析 |
| 机制建模（贝叶斯先验、ABM 初始化、压力测试） | 须另行论证假设与局限，本模块不提供结论 |

语言模型对较低学历、农村及少数民族语言或方言人群的模拟通常更不可靠。画像涉及这些特征时，名册与结果页会提示「保真度风险」，但提示不能修正偏差。

## 流程

1. **画像设定**：从模板（在校大学生 / 城市居民 / 银发人群 / 自定义）起步，编辑属性、取值与相对权重；「精确配额」按最大余数法对齐每个属性的边际比例，「独立抽取」按比例随机。权重是研究者的假设，不是人口统计。同一随机种子总得到同一批画像。
2. **问卷与情境**：使用「问卷设计」中的当前草稿或内置教学示例。题干中 `{情境}` 按情境替换（≤4 个），`{变量名}` 引用该受访者此前的回答（答案传递）。「连续作答」带着前序问答作答；「逐题独立」每题单独提问。
3. **运行**：离线演示引擎在浏览器内按种子生成可复现的随机答案，只用于走查跳转、答案传递与界面，不代表任何人；语言模型引擎经服务端调用用户自己的模型服务（BYOK），最多同时比较 3 个模型，运行前显示调用次数并需明确同意。
4. **结果与检验**：
   - 预测试发现：结构阻断项、占位符问题、无人可达题、困惑率 ≥20%、拒答率 ≥15%、未被选择的选项、回答集中 ≥85%、量表无差异、天花板 / 地板效应。
   - 保真度检验（Argyle 等人的四项标准）：社会科学图灵测试（需人工盲评）、反向连续性（属性与回答的最大 Cramér V）、向前连续性（直线作答、正反向题一致、跳转违规）、模式对应性（事先写下的预期关系与 Spearman ρ 对比）；另附重复答卷比例、回答多样性、多模型一致率与高风险画像数。
   - 答案分布：按情境、模型或画像属性分组的 100% 堆叠条形图（量表用 5 级顺序色阶，选项用 8 色分类色板，均经 dataviz 校验器在明暗两种表面上校验），附图例、悬停 / 聚焦提示与表格视图；刻度超过 5 级时以表格呈现。
   - 导出与披露：CSV / JSON 下载、送入数据分析演练、可放入报告方法部分的「AI 使用说明」（最后一段须据实填写真人预调查复核情况，系统不代填）。

## 数据标记与防混用

- 导出的每一行都有 `__origin = silicon_simulated` 列；JSON 记录 `classification: "simulated"` 并附说明。
- 数据分析工作台读到任何含 `__origin` 列的表，都会强制按模拟数据处理（徽标、写作摘要首行、导出记录 `origin` 字段），无论表内其他内容如何。删除该列属于刻意规避，不在本工具的防护范围内。
- 实验室只在浏览器本地保存配置（画像、情境、预期等）；运行结果不在浏览器持久化，语言模型运行记录保存在服务端并按用户隔离（RLS）。

## 3D 舞台

Three.js 实例化渲染：每个身体部件一次绘制调用，120 位人物与 1 位成本相同。人物外观（主色、发色、帽子、配饰、身高）只用于辨认，不发送给模型。舞台可按属性或某题回答分组（光环颜色对应回答），拖动旋转、悬停查看、点击打开设定面板；窄屏改为网格布局并上下堆叠。无 WebGL 或用户选择时显示平面名册，信息完全相同；系统开启“减少动态效果”时停用走位、呼吸与环视动画。
