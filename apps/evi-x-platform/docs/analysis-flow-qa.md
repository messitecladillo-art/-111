## 修复

信度模块有效输入 `1.0` / `5.00` 会规范化为计分范围 `1` / `5`，但之前图表格式签名还包含仅在输入框中存在的 `boundsDraft`。方案文件保存数值参数，不保存临时输入文本，导致同一数据、同一参数重算后无法载入原图表格式。

现在签名只绑定规范化的计算配置、数据与研究问题。实际上下限发生变化时仍拒绝旧格式；空白、无效、倒置或超限的计分输入仍使结果过期并阻止计算。修复前已导出的含临时输入文本的格式文件，需要恢复原参数、重算并重新下载一次。

## 已完成的页面操作

- 导入 CSV、缺失代码、七模块方案预览与确认，逐个计算。
- 手动新增频数模块、配置变量、计算和移除；上下移动已有模块保持结果。
- 信度参数输入 `1.0` / `5.00` 后重算，设置洞见青色系、标题、注释和统计结果表。
- 实际下载 SVG、PNG、方案、计算汇总和格式 JSON；新页面重新读取原 CSV、恢复 `NA`、载入方案、重算七模块、载入格式成功。
- 空白计分上限阻止计算且隐藏旧数值；实际上限改为 6 后有效案例变为 13，旧格式被拒绝。
- 重复列名文件被拒绝，原数据 20 行和现有结果保留；重新选择有效文件后开始新的分析会话。
- 缺失代码与方案不一致时拒绝载入；页面给出恢复原缺失代码的操作提示。
- 三线表页面外线 2px、表头线 1px，对应 1.5 / 0.75 / 1.5pt；各表头与各单元格分别居中。真实 SVG 导出具有两条 2px 外线和一条 1px 表头线，24 个表头/数据文本使用独立列中心。
