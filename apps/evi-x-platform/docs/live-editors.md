# 正大杯系统：报告与 PPT 编辑器

当前入口：研究工作台左栏「报告与 PPT」，地址 `http://127.0.0.1:3180/workspace#editor`。旧 `/#editor` 书签会兼容跳转。

以下编辑器与 D1 保存记录属于原工程迁移基准；当前托管保存范围以 [P0 运行说明](../../../docs/p0-running.md) 为准。

## 使用

- 报告：章节标题、正文、来源说明；增删、复制、排序；连续正文即时预览。
- PPT：封面、正文、正文与旁注三种版式；逐页标题、正文、讲稿、配色；增删、复制、排序。
- 支持撤销 / 重做、停笔 1.2 秒后自动保存、立即保存与另存副本。
- 工作区新增专注写作、编辑与预览、仅预览三种视图；窄屏自动使用单栏编辑并可切换预览，手机仍保留撤销与重做。
- 目录可搜索、收起；选择章节时报告预览跟随到该章节。PPT 提供文字缩略图和演示预览，方向键翻页、Esc 退出、演讲备注按需显示。
- 「草稿与版本」中可保存命名版本（每份草稿 20 个，不自动删除）。版本保存当前确认的正文与幻灯片；打开历史版本会新建独立草稿，不覆盖原稿。自动保存与本次编辑的撤销历史不等同于命名版本。
- Ctrl / ⌘ S 保存（仅在编辑工作区生效）；输入框保留系统原生撤销。Ctrl / ⌘ K 打开全局功能导航。明暗主题记住设备偏好，不存放研究内容。
- 报告分镜：选择章节与原文证据，填写本页任务、内容性质、结论边界和下一步；同章可拆多页，可调整顺序，先预览再确认写入 PPT。默认追加，整套替换需主动选择；总页数仍不超过 40 页。不再静默截取章节开头代替证据。
- 分镜中的原文选段必须存在于当前章节；完整来源说明写入讲稿，不静默截断。内容性质由使用者声明，不代表系统核实了调查真实性；已标记的教学模拟内容不能在分镜中降级为真实材料。
- 已生成页面记录来源章节与内容指纹。报告、来源说明或页面编辑后可见复核提示；导出 PPTX 前汇总全部关联页的变化（含未选中页）并要求确认，检查失败也会提醒，取消不会修改作品。指纹一致不等于事实核验。分镜时长仅用于排练规划，不代表适用届次的比赛时限。导出前检查正文、旁注和讲稿中的匿名及权利信息。
- 未应用的分镜只保留在当前页面：折叠面板、首次自动保存不丢失；刷新、关闭页面、切换或新建作品会丢失，需先确认应用。生成后的页面沿用现有草稿保存、撤销和版本机制。
- 导出真实 DOCX、PPTX（原生文字及讲稿）和可恢复 JSON 备份。默认不加入系统品牌。
- 单人实时编辑 / 预览，不是多人光标协同。不导入原有 Office 文件、图片、任意图表或复杂排版。预览不是 Office 分页引擎，提交前在演示/文字处理软件中检查字体、分页与字号。

## 保存与身份

内容存在 D1 `editor_drafts`，不以浏览器存储或进程内存作为主库。每份作品最多 40 章、40 页、500 KB，每个身份最多 40 份。

登录用户沿用系统账户身份。匿名编辑会话使用 HttpOnly、SameSite=Strict Cookie，HTTPS 下带 Secure；有效期 30 天。清 Cookie 或更换浏览器后匿名库不可自动找回，务必保留 JSON 备份。scope 仅为非凭据的身份一致性标记；实际每次查询/写入仍验证 owner。

全文和讲稿会保存到草稿库。禁止放入原始问卷、个人信息及未授权资料。草稿列表只返回元数据。导出仅在客户端完成，没有外部文件上传。此界面不修改 agentctl 控制状态或 Gate。

保存采用版本乐观锁。同一份草稿的旧版本写入返回冲突并暂停自动保存，不能强行覆盖。可先备份，再明确另存副本。失败时内容留在当前页面，不显示假成功。

命名版本存在 `editor_versions`。快照使用单条条件插入，绑定草稿 owner、已保存修订号与 20 个上限。相同请求 ID 的相同重试不重复创建，换名称或修订号不可复用该 ID；旧版本内容不会因后续自动保存而改变。没有删除或原地恢复接口。

## 本机启动与验证

在 `apps/evi-x-platform` 中先 `npm run build`，再 `npm run dev:editor`。

该入口只应用本地迁移，固定监听 `127.0.0.1:3001`，沿用 `.wrangler/editor-state` 持久库，不删除既有记录。`EVI_X_D1_PERSIST_PATH` 可覆盖路径，用于隔离验收。普通 `npm run dev` 保留原行为和原有默认库，不与编辑器演示库混用。

检查：`npm run typecheck`、`npm run test:editor`、`npm test`。完整测试使用隔离临时库，验证原功能、草稿越权/冲突、生成文件内容与跨服务重启持久化。运行整套测试前停止当前 dev 服务，结束后用 `npm run dev:editor` 恢复。

## 实现依据

浏览器文件生成分别使用 [docx Packer](https://docx.js.org/api/classes/Packer.html) 与 [PptxGenJS](https://gitbrent.github.io/PptxGenJS/docs/usage-saving/)。草稿迁移为 `0002_happy_nemesis.sql`，命名版本增量迁移为 `0003_striped_thunderball.sql`，不重写已应用的迁移。

本次为本机集成，未发布到远端、未改变站点访问权限。生产升级前仍需独立处理开发工具链的依赖安全告警，并对目标环境及 Office 渲染做验收。
