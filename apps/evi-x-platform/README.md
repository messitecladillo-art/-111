# 证见 EVI-X｜正大杯冠军 Agent

面向“正大杯”市场调查与分析项目的循证工具 MVP。它把获奖案例证据检索、五维赛事规则解析、项目准备度诊断、12 阶段权威合约、9 道质量 Gate 和本机只读生命周期作战室放在同一个门户里。

> 证见 EVI-X 为独立研究辅助工具，非“正大杯”赛事官方产品，与赛事主办方、承办方及冠名单位无隶属、授权或合作关系；系统不预测或承诺奖项结果。

## 当前运行入口（2026-10-07）

首页 `/` 为公开的像素寻证之旅；原研究工具保留在 `/workspace`，团队项目为 `/projects`，模型服务为 `/services`。旧 `/#editor` 等书签兼容跳转。标准 Next.js + FastAPI + PostgreSQL 的安装、身份、保存范围以 [P0 运行说明](../../docs/p0-running.md) 为准，首页设计与验证见 [首页说明](../../docs/landing-page.md)。

以下原工程功能记录保留为迁移基准，其中 D1、匿名会话、3001 编辑服务属于旧实现；请勿把旧持久化描述用于当前托管站点。

## 原工程能力与迁移基准

- **报告与 PPT 实时编辑器**：同一工作区按章节编辑报告、按页面编排幻灯片，支持实时预览、撤销重做、D1 自动保存、冲突保护、DOCX/PPTX 导出和 JSON 备份恢复。它是结构化单人编辑器，不是 Office 文件导入器或多人同步编辑。详见 [编辑器说明](docs/live-editors.md)。
- **获奖案例证据库**：32 条精选记录；29 条仅核验公开公告中的题名、学校、组别、奖项与届次，3 条为用户陈述奖项且已做材料深读的案例。它不是历届全量榜单，不支持据此推断获奖概率；支持关键词、届次、组别、奖项与来源状态筛选，以及分层证据卡片。
- **Agent 快速诊断与行动**：基于自报信息的启发式缺口提示，按严重度排列行动，列明准备材料、预期产物和复核条件；可将本轮输入转为问卷简介提案，预览差异、选择字段、显式应用后检查与撤销。修改来源或目标会使旧提案失效。分数未核验真实证据，不代表质量认证或 Gate；详见 [诊断行动说明](docs/diagnosis-actions.md)。
- **拼装式问卷与组合分析**：7 类自编问卷模块、量表题批量配置，6 种可重复组合的分析卡片，以及专门的 Cronbach α 检查。原始答卷只在浏览器内存处理，方法适用条件与未实现功能明确标示；详见 [组合研究说明](docs/composable-research.md)。
- **问卷项目与版本**：明确同意后保存独立问卷项目与不可变快照；支持版本预览、确认载入、一次撤销、并发冲突保护和原请求重试。不自动上传、不保存答卷，不代表问卷验证或赛事 Gate；详见 [问卷库说明与验收边界](docs/questionnaire-library.md)。
- **问卷—数据联动**：逐题选择 CSV 数据列、明确确认编码/文字格式，计算前检查测量水平、构念、计分与取值范围。问卷或对应关系改变后旧结果失效；可下载/恢复不含答卷行的对应备份，恢复后必须重新确认。关联报告提案保存版本指纹与所选题目 ID，不能据此证明实际施测或数据真实性。
- **统计证据到报告**：频数或原始 α 汇总经隐私确认后生成可恢复提案，核对报告与版本后显式确认追加。服务端复算汇总，保留前后版本并防止冲突覆盖；不自动修改 PPT，不把摘要校验当成田野真实性认证。
- **五维赛事规则解析器**：按届次、组别、赛区、赛道和阶段同时匹配已核验规则快照；当前收录第十六届本科组 1 个来源、10 条规则。范围不匹配时返回未知并阻断，不回退套用旧规则。
- **项目控制门户**：创建和读取项目登记项，显示 canonical 12 阶段、9 道 Gate、状态修订号与合约指纹。浏览器端不评估 Gate、不推进控制状态，也不执行最终 handoff；这些动作必须由受信任的 `agentctl` 控制面完成。
- **生命周期作战室**：本地页面可通过独立的回环地址桥接器，读取真实项目的 `status`、`next` 与 `doctor` 安全摘要。门户登记态和本机权威态始终分栏显示；读取失败保留并标记旧快照，契约哈希不一致时停止解释下一转换。桥接器不接收路径或命令，不提供 Gate 修改、阶段推进、审计、初始化或 handoff。
- **持久化与隔离**：生产环境使用 Cloudflare D1；项目登记按账户或匿名能力密钥隔离，最多 20 个项目，本地登记演示默认是内存存储。编辑器始终使用 D1，最多 40 个作品，匿名草稿按 HttpOnly Cookie 会话隔离，不回退为内存保存；快速诊断不持久化。
- **证据与安全边界**：官方案例只保留来源能够证明的题名、学校、组别、奖项和届次，不推断未公开的方法、样本、结论或评委意见；不托管获奖报告全文。

## 本地运行

2026-10-07 新增用户自带密钥的服务接入框架：受邀邮箱验证码、账号隔离的加密配置、能力绑定、固定目的地模型适配器，以及“研究需求 → 问卷草案 → 预览确认 → 可撤销应用”。当前已有问卷执行入口，研究/报告/答辩仅保存绑定。参见 [框架与部署配置](docs/byok-framework.md)。运行专项测试使用 `npm run test:agent`；真实邮件、供应商和整站身份迁移尚待验收。

要求 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

需要报告/PPT 持久化编辑时，先 `npm run build`，再 `npm run dev:editor`；该入口自动应用本地草稿迁移并在 `127.0.0.1:3001/#editor` 提供页面。普通 `dev` 的默认数据库行为保持不变。

常用校验：

```bash
npm run build
npm test
npm run lint
npm run typecheck
npm run test:bridge
npm run rules:check
npm run db:generate
```

Windows 集成测试独立于已有 3001 预览，关闭测试服务时通过只读进程元数据确认子进程退出。若运行环境不允许读取这些元数据，测试会保留临时数据并中止，不冒险清理；不得因此关闭用户预览或绕过身份校验。

合成集成测试为迁移、测试服务和 HTTP 测试子进程使用独立用户目录、配置、缓存与临时目录，不继承云端凭证、代理或 Node 预加载。启动前仅检查文件名，发现项目 `.env*`、`.dev.vars*` 或隐式祖先 Wrangler 配置即拒绝，不读取内容。迁移使用固定本地测试绑定和复制后的 SQL；完成后复查迁移清单、表存在性、外键与 `quick_check`，不把日志绿勾或强制终止当成功。它不修改正常开发启动方式，也不保证依赖工具完全不访问网络。

`npm run test:harness` 检查隔离与失败处理契约。Windows 的真实自造子进程场景需显式设置 `EVI_X_BOUNDED_OS_TESTS=1` 后运行同一命令；默认跳过这些 OS 场景，不可把跳过报告当作已执行。当前默认进程身份适配器仅支持 Windows，其他平台必须提供并验收对应适配器。完整集成测试失败时保留本次合成临时状态；如需在成功时也保留证据，可设置 `EVI_X_TEST_KEEP_STATE=1`。进程清理声明仅覆盖观测到的 PID/出生时间身份，不是系统级进程容器证明。

打包版另运行 `npm run build` 后的 `npm run test:built-runtime`：它用独立、临时的本地 Worker 和静态资源服务，连续核对拒绝请求的状态码、JSON 错误、响应头及后续健康请求，并确认端口关闭。任何连接中断均返回失败，不能拿开发模式的 `npm test` 通过替代。当前 Windows 工具链仍能复现静态资源 HTTP 转发的请求体错误，故这一上线前检查尚未通过；详见 [运行稳定性记录](docs/runtime-validation.md)。这不是云端部署或真实 ONLYOFFICE 联调验收。

本地项目控制门户默认使用进程内演示存储；重启开发服务器后会清空。要测试已迁移的本地 D1，请先应用迁移，并在请求中显式提供 `x-evi-local-storage: d1`。

### 读取真实 Agent 状态（本机可选）

生命周期作战室只在由 `localhost` 或 `127.0.0.1` 打开的页面中启用。托管站点不会访问本机文件，也不会启动 Python。

1. 按 [`local-bridge/README.md`](local-bridge/README.md) 复制本机私有配置，并用别名登记已经初始化的真实项目。
2. 启动 `local-bridge/agentctl_read_bridge.py`；它固定监听 `127.0.0.1:8765`，并在终端显示本次启动临时口令。
3. 在网页“生命周期作战室”粘贴口令、读取项目清单，再读取权威状态。

口令仅保存在当前页面内存；本机绝对路径、运行/事件标识、可执行命令、阻塞详情、材料路径和哈希不会下发到浏览器。配置文件 `local-bridge/bridge.config.json` 已被 Git 忽略。

## API

- `GET /api/cases?q=&edition=&group=&award=&verification=`：检索案例与 facets。
- `GET /api/cases/:id`：读取单个案例证据卡片。
- `POST /api/diagnose`：返回确定性的项目准备度诊断；输入和诊断结果均不持久化。
- `GET /api/rules`：读取规则语料元信息、五维覆盖、来源哈希与单独标示的届次通知更新。
- `POST /api/rules`：以 `edition/group/region/track/stage` 五维解析规则；无精确范围证据时返回 `match=none`、`blocking=true`。
- `GET /api/control-contract`：读取当前 canonical 工作流、Gate、相邻转换与 fail-closed 能力声明。
- `GET|POST /api/projects`：读取或创建当前所有者的项目。
- `GET /api/projects/:id`：读取项目登记态与事件。
- `PATCH /api/projects/:id`：固定返回 `control_plane_unavailable`；浏览器不能推进阶段或更新 Gate。

项目接口只保存项目名称、控制状态、赛事阶段、Gate、合约指纹与必要事件元数据。不要上传原始问卷、受访者个人信息、敏感数据或未授权商业资料。匿名访问密钥只允许通过 `x-client-key` 请求头传递，不接受 URL 查询参数或请求体中的 `clientKey`；仅接受本页生成的新格式密钥或兼容旧版的 48 位十六进制密钥。

## 答辩训练与练习备份

答辩训练提供 13 类问题、五槽笔记、依据状态声明、人工核查提示和可调节的路演计时。另有分段实测彩排、暂停/继续和单独 JSON 导出，详见 [彩排说明](docs/defense-rehearsal.md)。题库来自 3 份用户提供的非官方经验资料，只吸收抽象方法，保留来源页码；不构成官方规则或获奖身份认证。

练习可导出为 JSON 后重新导入。导入先预览新增/替换题数，可取消、选择是否恢复计时；题库版本不一致时必须额外确认。导入保留未涉及题目，编辑会取消过期预览。损坏、超限或不符合格式的文件会被拒绝；导入内容始终未核验，不接受文件自带的“已验证”声明。仅修改依据状态的笔记也会保留。

这些笔记只在当前页面内存中保存，切换模块保留，刷新或关闭页面会丢失未导出的修改。导入过程不上传文件；尚无账户绑定、云端持久化或与真实项目证据的自动核验。请在导出前去标识，并妥善保管备份。

## 当前明确未实现

问卷设计、基础统计与上述有限的统计证据到报告链路已实现；它们不等于完整的研究自治。田野质控、完整证据台账、AI 全文生成、证据绑定的答辩审查、浏览器内 Gate 判定、阶段推进与最终交接仍未形成闭环。KMO/Bartlett、EFA/CFA、t/ANOVA、回归、聚类和 SEM 等目前仅有路线说明，没有计算实现。

真实 ONLYOFFICE 引擎与云部署需独立验收；模拟接口测试不能替代。Windows 打包 Worker 的错误请求路径仍有请求流运行异常，开发环境通过不能作为生产稳定性证明。当前只读桥接也不抵御同一 Windows 账户下持续进行目录替换的恶意进程。因此系统仍是可验证的垂直领域 MVP，不应称为已经完成全生命周期执行闭环。
