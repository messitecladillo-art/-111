# 证见 EVI-X 宣传片（代码生成）

80 秒、1920×1080、30 fps 的产品宣传片。画面、动效与配乐全部由本目录中的代码生成，可随时重新渲染。

| 文件 | 作用 |
| --- | --- |
| `cues.json` | 时间线：每句文案、每次转场与每个重音的时间（秒）。画面与配乐都从这里读取，保证卡点一致 |
| `film.html` | 画面。`window.renderFrame(t)` 只依赖 `t` 绘制该时刻的一帧，不依赖真实时钟，因此可以任意顺序、多进程并行截取 |
| `score.py` | 配乐。用 numpy 从零合成（无采样素材）：持续低音、弦乐垫音、钢琴动机、钟声、太鼓、印章声、上升音效与混响 |
| `render.mjs` | 渲染。并行启动无头 Chromium 截取每一帧，直接送入 ffmpeg 编码 H.264 分段，再拼接并与配乐合成；音频做两遍响度归一化（-14 LUFS，-1.5 dBTP） |

## 渲染

```bash
# 需要：Playwright（全局安装时设 PW_ROOT 为包含 node_modules/playwright 的目录）、ffmpeg、python3 + numpy
node media/promo-film/render.mjs --workers 4
# 输出：media/promo-film/out/evi-x-promo-1080p.mp4（out/ 不入库）
# 只渲染一段：--from 29 --to 32
```

浏览器使用软件渲染（`--disable-gpu`），在 4 核机器上全片约数分钟。

## 合规与素材

- **模式**：`public_promo`。片尾完整显示非官方声明：“证见 EVI-X 为独立研究辅助工具，非“正大杯”赛事官方产品，与赛事主办方、承办方及冠名单位无隶属、授权或合作关系。”不使用赛事或任何第三方标识。
- **内容分类**：
  - 界面画面为 `simulated`，即证见工作台的真实截图（`apps/evi-x-platform/public/landing/app-*.webp`），使用教学示例问卷与模拟数据，画面中标注「真实界面 · 示例数据」。
  - 粒子、光环、轨道与印章为 `conceptual`（概念性视觉），不代表任何样本量、比例或趋势。
- **品牌素材**：标志使用 `skill/zhengda-cup-champion/assets/brand/logo/mark.svg`。獬见使用生产锚点 `evi-x-character-anchor-v2`（`usage_modes` 含 `public_promo`），片尾注明「AI 辅助生成、经人工验收的原创概念角色」。
- **不使用的素材**：用户提供的第十六届报告页面未获作者授权确认，不进入本片。
- **证据链**：顺序固定为 Q 问题 → D 数据 → I 洞察 → A 行动；Q 用开放圆环与问号，D 用点阵，I 用棱镜分光，A 用金色单向箭头。
- **字体**：Noto Sans CJK SC / Noto Serif CJK SC。
- **配乐**：由 `score.py` 原创合成。
- **人工验收**：公开发布前须由负责人观看全片并确认文案与画面，再登记发布版本的文件哈希。
