# 研究资料库

问卷设计、数据分析、报告/PPT、路演答辩各有一个可展开的“研究资料库”。默认按当前任务筛选；可按关键词、分类检索，或勾选“浏览全部资料”。已有编辑器、10 张研究方法卡和项目版本机制继续使用。

## 本批内容

- 87 张卡片：30 张理论与方法、30 张问卷设计模式、12 张可追加题组、9 张报告/答辩、6 张原创知识练习。
- 12 组候选问卷，共 38 题。包括资格筛查、知晓与信息渠道、使用/未使用分支、实际行为、流程体验、问题处理、满意与意愿、业务采用状态、改善优先项、分层画像、行为机会、感受与亲历事件。
- 每张卡包含开始条件、操作、人工核对清单、预期输出、解释范围和来源定位；共引用 47 份本地资料。题组可预览题干、选项和显示条件，再明确追加到当前问卷末尾。
- 追加不覆盖现有题目；为所有新增题目分配新 ID 和变量编码，重映射内部条件，整批形成一次可撤销修订。读取、未应用数值、确认窗口等未完成时不追加。
- 卡片可导出为 UTF-8 文本，保留当前勾选、来源 SHA-256、精确定位和资料库版本；练习导出包含选项、答案与解释。勾选是个人核对记录，不推进项目 Gate。

## 方法校正

从教材、历史问卷和作品中提炼可迁移的设计，而非把每条旧资料视为正确答案。已补齐单元无应答与项目缺失的区别、预试中的拒答/难度/实测时间/调查员工作量、插补不确定性、多选频数的现有输入边界。对历史样本量示例重新计算；来源中的不一致不成为本项目结果。

统计执行器未扩展：现有频数、描述、分组描述、交叉表、Pearson、Spearman、信度继续独立计算。资料卡中的抽样、因果、插补、回归等是设计与复核指导，不注册尚未实现的计算能力。报告章节由用户自由组织；三线表使用现有产品设置 1.5/0.75/1.5 磅、逐列居中。

## 来源处理与覆盖

用户提供的六个目录共 283 个顶层文件，SHA-256 去重后 264 份，19 个重复件。254 份独立文件已取得机器文本（107 份现代格式、147 份旧格式），累计 177,171 条定位记录；5 份 DOC 超时、2 份独立旧 PPT 阻塞、1 份扫描 PDF 无文字层、2 份 ZIP 已盘点。283 份原件前后哈希一致。现代 Office 使用 XML/ZIP 解析，PDF 提取文字；旧 DOC/XLS 使用安装的 Office 创建独立只读实例，禁用宏和外链更新，前后核对源哈希。4 个旧 PPT 对应 2 个独立文件；未验证安全读取路径时保留阻塞状态。扫描教材不声称完成 OCR；两份 Word 转换文本来自同一 2018 版教材，不能算两套独立理论证据。

索引、机械文字提取、定向语义审阅是不同层次。理论 PPT 去重后 13 份/539 页完成结构阅读；现代问卷 39 份及旧 DOC 9 份作定向模式审阅。6 篇作品用于研究结构、证据组织、报告/答辩指导；渲染检查了抽样页，未声称逐页人工验完。其余提取文本可继续扩展卡片，不批量发布原书、完整试卷或历史调查数据。

工具：`tools/ingest-research-materials.py --source-root <资料目录> --output <源目录以外的输出目录>` 建立本地索引；旧格式补充见 `tools/ingest-legacy-materials.ps1 -Manifest <manifest.json> -Output <输出目录/legacy> -Kind doc -Limit 200`（XLS 用 `-Kind xls`）。详细选项以各工具帮助/参数为准。输出包含原文和本机路径，仅作本地证据，排除 Git。资料文件从不写入源目录，源/输出重解析链接被拒绝，故障回执区分超时、错误、空文本与未支持格式。

## 验收

`npm run lint`、`npm run typecheck`、`npm run test:unit`、`npm run build` 在 `apps/evi-x-platform` 执行。新增 `tests/research-materials.test.mjs` 验证完整卡片合同、中文组合检索、12 组严格解析、重复追加及分支隔离、一次撤销/重做、容量/ID 失败原子性和真实文本导出。

浏览器验证：保留原题并追加 4 题，5→1→5 的撤销/重做，下载备份中的新 ID 与分支正确；原创练习 A 选项判分、实际卡片文件中的三个选项/答案/解释/哈希正确。资料检索与切页不覆盖问卷编辑内容。桌面尺寸和深浅主题以本地验收记录为准。

历史评分权重、页数与展示时间未进入第十七届硬规则；届次、组别、赛区、赛道和阶段需由适用的官方文件确定。画布、资料卡和知识练习不会更新 `.agent/state.json` 或赛事阶段。
