# 问卷设计与数据分析工作区

本轮在现有 `evi-x-platform` 上优化两个工作区，同一套组件继续服务研究工具页和云端项目页。统计程序、问卷格式与业务 API 保持兼容。

## 操作结构

- **问卷设计**默认打开题目编辑。题目目录、当前题项与预览按屏幕宽度布局；文件、题目操作、查找筛选和研究简介按需展开。模块拼装和映射检查仍可随时切换。
- **数据分析**按“数据检查 → 题目对应 → 分析结果”组织。已有分析使用任务列表，只展开当前卡片，切换时保留其设置与结果。
- 问卷发送快照后自动进入“题目对应”。用户可以返回数据检查；同一快照不会反复抢走当前视图。
- CSV 支持逗号、分号及 Tab。解析失败会标明本次分隔符，并提供读取选项入口；失败或取消不替换已有数据。
- 页面使用现有浅色/深色语义色、紧凑工具栏和窄屏布局。账户、文件来源和保存状态继续明确显示。
- 云端项目将生成建议、版本历史和近期模型调用收为按需展开的工具，已有问卷优先进入编辑。提案持续保留；在其他步骤收到提案或待核对状态时，提供返回查看入口。

## 研究路线与自由组合

“分析方案”提供两种起步方式，进入后共用一份模块列表：

- **选择研究路线**：活动体验与运营改进、人群分层与服务支持、消费体验与增长机会。先预览研究问题和分支，再追加到当前方案；节点均使用已实现的统计方法。
- **自由搭建**：选择六类基础分析或信度与题项诊断，独立定义变量、构念、反向项和样本范围。可重排、移除和撤销，界面只展开当前模块。

样本筛选支持一个分类列和多个类别；缺少变量或类别时阻止计算。问卷关联模式在原始数据上分别核验分析题目和筛选题目的资格，再计算两者与筛选值的交集。原表级跳题问题不会被筛选悄悄隐藏。结果显示原始、分支、共同应答和有效计算人数。

**下载方案配置**保存 `analysis-plan/v1` 文件，**下载计算汇总**保存结果，两者职责明确。方案包含变量名、研究问题和筛选类别，不含答卷或结果；导入时严格核对原始文件、解析指纹、缺失设置和已确认的题目对应/跳题策略。预览期间出现新编辑时必须重新读取，保护现有工作。刷新后重读原数据、恢复同版对应及口径，再打开方案并计算。

自定义分支结果目前保留在工作区与结果文件中；现有报告候选仅接受未额外筛选的频数及 α，避免遗漏新增筛选口径。完整依赖图、共享得分变量、云端方案和拖拽画布按 [双入口设计](analysis-workflows.md) 后续推进。

## 状态与计算

研究工具页的问卷编辑和原始 CSV 在当前页面内存中使用；需要保留时主动下载备份或分析记录。云端项目问卷的保存状态依服务器保存版本判断。切换工作区或分析步骤保留已挂载组件；刷新页面仍遵守各模块原有持久化边界。

修改变量、研究问题、缺失口径或问卷映射后，旧结果需重新计算。数值字段未完成输入时，问卷转交和导出继续受保护；异步导入仍核对操作版本。

当前组合分析覆盖频数与比例（附 Wilson 95% 区间）、数值分布（附均值 t 区间）、分组比较、交叉表与关联强度、Pearson 和 Spearman 相关；另有量表 Cronbach α。分组比较两组用 Welch t 检验、多组用 Welch 方差分析，附秩检验对照、效应量和 Holm 两两比较；交叉表给出 χ² 检验，2×2 稀疏表改用 Fisher 精确检验；相关给出双侧 p，Pearson 另给 Fisher z 区间。每张结果卡有可复制的报告句、措辞克制的读法、前提与提醒；检验以随机抽样为前提，便利样本只作参考。EFA、回归和聚类尚未交付。

## 公开真实数据验收

使用 [UCI Bank Marketing](https://archive.ics.uci.edu/dataset/222/bank+marketing) 的原始 `bank.csv`：4,521 行、17 列、分号分隔，461,474 字节。它是官方发布的小样本文件，不是 45,211 行全量文件，也不是本项目自行开展的调查。

来源：Moro, S., Rita, P., & Cortez, P. (2014). *Bank Marketing* [Dataset]. UCI Machine Learning Repository. DOI: [10.24432/C5K306](https://doi.org/10.24432/C5K306)。许可：CC BY 4.0。原始文件只用于本地验收，未加入仓库。

独立 Python `csv` / `statistics` / `Counter` 参考实现与 TypeScript 计算引擎对照 14 个场景、462 个标量/标签检查项，均通过，最大绝对误差 `1.819e-12`。复跑说明见 [公开数据验收](../evals/public-data/README.md)。

| 核验项 | 参考结果 |
|---|---:|
| 订阅 `y=yes` | 521 / 4,521，11.524% |
| `balance` 均值 | 1,422.657819 欧元 |
| `balance` 中位数 | 444 欧元 |
| `education × y` Pearson χ² | 15.236580 |
| `education × y` Cramér V | 0.058053 |
| `age × balance` Pearson r | 0.083820 |
| `age × balance` Spearman ρ | 0.075998 |

对照分别保留 `unknown` 类别及显式设为缺失，核对两种口径的分母变化。`pdays=-1` 表示此前未联系，3,705 条对应记录始终保留，不能将 `-1` 自动设为全局缺失代码。该数据没有经过验证的多题量表，因此不拿它验证真实量表信度，也不由此宣称问卷效度成立。

实际数据促成了分隔符错误提示与恢复入口的改进；界面实测促成了分析卡片前方控件的进一步压缩。统计引擎对照未发现需要修改的数值错误。

## 验收与后续边界

- 最终单元回归：489 项，482 通过、7 项原有跳过、0 失败；`npm run test:analysis` 已纳入新计划契约，共 94 项通过。
- 新增 16 项计划领域测试与 16 项独立组件行为检查，覆盖严格来源恢复、重复 JSON 字段、导入取消/竞态、原有结果保留、条件筛选资格和连续多选。
- 分支计算另用独立 Python 参考验证 4 个公开数据分支、1 个高类别筛选阻断、2 个合成 α 场景，共 41 个检查项通过。合成量表的完整案例 α 为 0.9625668449，参与者分支为 0.9642857143；这些只用于数值验收。
- 问卷专项回归及独立组件状态检查覆盖编辑保留、撤销重做、数值草稿、晚到导入、快照对应和结果失效。
- TypeScript 与生产构建验收；分析模块 ESLint 通过。问卷组件已有的 Hook lint 诊断与基线一致，不将它记为全仓 lint 通过。
- 生产浏览器通过公开 CSV 导入、题项编辑、撤销重做、快照转交、对应确认、频数计算与 JSON 下载；导出来源哈希、样本分母和统计值与输入一致。修改上游问卷后，原对应和结果进入待重新核对状态。
- 本批生产浏览器通过路线追加、公开数据筛选、重排保留结果、下载配置和汇总、新页面重新读取数据并恢复方案、重算和连续多选。中等教育分支为 2,306 人、订阅 245 人；小学/高等教育合并分支为 2,028 人、订阅 257 人，与独立参考一致。信度模块的合成样本 6 人中 5 个完整案例，界面显示 α=0.9626。
- 390 px 与 320 px 页面宽度检查无横向溢出。生产构建和 101 项标准 Next 产物检查通过。大数据输入优化减少隐藏模块的重复计算；性能脚本只测同步组件计算，不作为浏览器帧率承诺。
- 浏览器验收使用公开数据和明确标注的测试问卷。公开数据适合检查计算与交互；手机实际填答、真实云端回收、统计推断与任务恢复仍须按对应阶段继续验收。
