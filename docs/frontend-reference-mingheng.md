# 明珩前端参考与证见应用位置

研究日期：2026-10-11。来源：[Modex Agent 官网](https://www.mingheng.xin/)。范围为桌面首屏、产品页签、场景卡、流程、技能线路和产品细节。

## 可迁移的设计

网站先用大标题说明成果，再展示产品窗口；功能解释依靠卡片中的界面、输出和流程，而不是不断补充说明段。证见采用相同的信息顺序：问题 → 具体操作 → 当前结果 → 下一步。

| 参考方法 | 实际观察 | 证见板块 | 应用方式 |
| --- | --- | --- | --- |
| 大标题与留白 | 黑底、蓝紫微光、居中两行标题；主按钮显著，次按钮较轻 | 首页、`/explore` | 延续现有金色与青绿，以一句主标题和明确入口承接产品体验；历史叙事保留 |
| 同一窗口切换产品页签 | 编辑器、任务详情、新工作流和工作流列表切换预览；暂停按钮可停轮播 | 产品演示 | 问卷、样本和报告共用展示窗口。用户手动切换，编辑内容保留；文字输入区不自动轮播 |
| 错落的功能卡 | 宽主卡、较高侧卡和小卡组合，内部展示具体输出 | 功能介绍 | 问卷与分析承担主卡；报告/PPT、硅基样本承担辅助卡。工作台数据表保留稳定布局 |
| 横向阶段线路 | 文献、实验、写作、复核以节点与连接展示 | 项目概览 | 问卷 → 回收 → 分析 → 成果，选中阶段显示当前对象与下一步；进度由实际项目状态驱动 |
| 主路线与支线 | 技能生态采用中央连接与分支节点 | 分析方案 | 推荐路线作为主线，自选模块作为可插入支线，保留已有自由排序和模块独立计算 |
| 轻量装饰动效 | 已加载 CSS 含局部边框光点、按钮掠光、卡片悬浮位移和细连接光束 | 公共页、案例入口 | 只装饰可点击卡片和按钮；输入、图表数值、正文和计算结果保持稳定 |

以上是参考迁移方案。卡片重新布局、阶段线路和新增追光尚未实现，不计为本轮交付。已有产品演示的视图切换保持原机制；本轮实际落地的是文案删减与空壳样式清理。

## 核对范围

产品页签和暂停轮播经过实际点击。边框追光、按钮悬停、连接光束和减少动态规则通过页面加载后的 CSS 核对；实际悬停与操作系统减少动态设置未单独验收。官网上的用户数、耗时、获奖率和评价只作为网站内容，不用作证见的效果证据。
