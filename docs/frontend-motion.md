# 证见桌面动效实施记录

本轮范围：桌面浏览器。沿用现有 CSS、Web Animations API 和 Three.js；不新增动效框架，不修改业务 API、数据库、统计公式或成果版本契约。

## 统一规则

| 行为 | 时长与实现 | 作用范围 |
| --- | --- | --- |
| 选择标记 | 180ms，量测当前按钮位置 | 目录与模式选择 |
| 目录重排 | 240ms，稳定 ID 的 FLIP 位移 | 问题、分析模块、成果目录与文件列表 |
| 新项目强调 | 一次背景强调 | 新增、复制与实际返回的记录 |
| 内容显现 | 220ms，轻微位移与透明度 | 只读提案、图表、结果、预览与服务器回执 |
| 首页转场 | 直接由滚动位置计算 | 同一粒子场景的六段连续变形 |

编辑器、表单、光标和中文输入区域保持挂载。数值显示计算终值；读取、保存、执行和完成状态来自现有业务状态。连续重排取消先前动画；窗口变化重新量测。减少动态偏好和页面隐藏时取消动画并呈现终态。

## 板块映射

| 板块 | 已接入的反馈 | 保留的业务依据 |
| --- | --- | --- |
| 问卷 | 目录标记、添加/复制强调、重排、提案显现、保存反馈 | 新增到末尾、复制到原题之后、服务器保存回执、晚到提案保护 |
| 分析 | 双入口选择、模块目录、当前模块、真实结果显现、实际文件读取状态 | 原表与筛选分支、共同应答范围、模块独立计算、方案恢复 |
| 寻证体验 `/chronicle` | 序章→甲骨→徵→灋→證→考据链→现代证据环 | 保留完整粒子与文案转场；可反向滚动、直接跳转；产品首页保留已合并的新版设计 |
| 登录与项目 | 登录阶段标记、实际等待反馈、回执显现、列表新增强调、键盘焦点 | 原邮箱验证、会话、项目权限与密钥隔离 |
| 硅基样本 | 画像选择、平滑聚焦与光环、流程标记、名册重排、答案与图表显现 | 同意、调用、停止、导出；个人状态只来自该画像实际响应 |
| 报告/PPT | 对象目录、编辑/预览模式、版本目录、页预览、保存状态 | 草稿、撤销、导出、精确版本与未保存编辑保护 |
| 分镜 | 卡片重排、来源依据、只读预览 | 预览签名、确认应用与冲突判断 |
| 原生 Office | 文件与版本目录、实际会话状态回执 | 保存文件版本、来源/会话校验与恢复机制；iframe 不参与动画 |
| 答辩 | 题库与行动卡目录、只读证据与导入预览 | 原导入、编辑、取消和文件版本逻辑 |
| 排练 | 当前讲述段标记、实际已用时间条、结束后复盘显现 | 原计时、暂停、阶段切换、快照与导出 |

硅基样本不通过聚合完成数猜测某个画像的完成顺序。示例结果立即可看，不播放虚构的逐个答题过程。

## 验证边界

独立复核比较旧业务处理函数、事件、编辑值、禁用条件和生命周期；定向测试覆盖动效取消、快速重排、内容 token、统计口径、版本、导出与排练。完整 lint、类型检查、测试和生产构建与桌面浏览器验收作为本轮交付依据。

浏览器使用本地合成环境，不输入真实密钥，不产生付费模型调用。未配置独立 ONLYOFFICE 服务时，不能由状态样式和源码检查推断 Word/PPT 在线编辑、协作及重开已验收。本轮不验收手机，也不将源码层减少动态检查表述为实际系统偏好切换测试。

2026-10-11 用户已授权完成后创建并合并 PR。先将本地成果提交至独立分支，再整合已合并的新首页；旧验收记录保持原版本范围，整合后的首页及寻证路线重新验证。

- 完整单元测试：524 项，517 通过、7 跳过、0 失败；lint、类型检查与生产构建通过。标准 Next 构建隔离检查 111 项通过。构建仍有未配置生产域名的 `metadataBase` 提示，未据此声明线上社交预览已验收。

- 桌面浏览器验证：人物选择与聚焦；24 位 × 2 情境的 48 份离线回答；修改画像后的旧结果标记；移除属性并重跑后的分组与关系选择恢复；新增预期与重复变量保护；模拟数据交接到分析页；十张方法卡选择和内容呈现。
- 报告/PPT 验证：中文正文编辑、复制、排序、撤销、预览切换和 JSON 备份下载。答辩验证：切换依据状态保留输入、主题筛选、实际计时、暂停、提前结束及记录导出。项目列表收到服务器的三条合成项目记录，键盘可进入原项目。
- 首页验证包括章节跳转、键盘进入甲骨、正反向滚动的进度变化、暂停/继续及单画布呈现。平滑跳转的验收读取目标章节顶部约 88px 的终点；`data-stage` 跨过页面中线时就变化，不能单独用它断言滚动已结束。
