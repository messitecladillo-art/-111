# 研究画布 A1：共享编辑宿主

本批验证两种视图共享现有问卷和报告编辑器。工作台继续完成详细编辑；画布只放用户添加的成果引用，点击引用打开同一编辑器实例。节点执行、连线、拖动和布局持久化进入 A2/B 批，A1 不显示运行或保存成功状态。

## 开启与回退

实验入口默认关闭。构建时设置 `NEXT_PUBLIC_EVIX_RESEARCH_CANVAS=true` 才启用；运行时改变该变量不会改变已构建的浏览器代码。关闭变量后重新构建，返回原项目工作台。

```powershell
$env:NEXT_PUBLIC_EVIX_RESEARCH_CANVAS = 'true'
$env:EVIX_API_ORIGIN = 'http://127.0.0.1:8182'
npm run build:web
$env:PORT = '3182'
npm run start --workspace evi-x-zhengda-champion-platform
```

本批没有数据库迁移、API 调整、新依赖或首页修改。成果引用只保存在当前界面的内存中；问卷与报告继续使用原版本及保存机制。

## 实现边界

- 保留唯一编辑宿主，通过隐藏/显示切换视图。问卷、报告和首次打开后的报告编辑器持续挂载。
- 按编辑区记录最后可编辑字段、UTF-16 选区、方向及滚动位置。恢复前核验连接、可见布局、原生禁用状态及实际焦点。
- 中文 composition 期间延后整个切换动作，最终输入结算后应用最新意图。组件销毁取消帧、观察器和晚到回调。
- 首次异步载入最多观察 5 秒；用户操作、再次切换或账户/项目变化会取消焦点恢复，避免晚到字段抢夺焦点。
- 账户与项目变更重新建立宿主。默认关闭时直接返回原子内容，不挂载宿主及控制器。
- 报告只读权限覆盖本地编辑、撤销、导入、格式和旧回调；降权使已开始的备份读取失效。已有下载能力保留。
