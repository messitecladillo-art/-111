## 文件与复核

- `apps/frontend/content/topic-advisor/county-pack-01.json`：供后续严格解析与审校流程读取的草稿包。
- `corpus-source/topic-advisor/county-pack-01/captures.json`：HTTP状态、原始响应SHA-256、大小、日期元信息和不超过40字符的核验片段；未归档页面全文。
- `recovery.json`：六次web读取结果。乌审记录的是可读范围、原创摘要与极短定位；**没有原始HTTP响应SHA**，不冒充有原始字节快照。
- `editorial-evidence.json`：包指纹、每条来源原创摘要指纹、各地区资料覆盖与待复核状态。
- `build-pack.py`：离线重建；只使用成功读取的来源，始终输出草稿。
- `validate-pack.py`：离线合同、代码归属、日期、来源、方向和指纹检查；不是内容审批。

```powershell
python -X utf8 corpus-source/topic-advisor/county-pack-01/build-pack.py
python -X utf8 corpus-source/topic-advisor/county-pack-01/validate-pack.py
```

`capture-sources.py` 为有界手工采集器，不加入测试或自动任务。重新联网采集须另行分配请求预算；离线构建与验证不会联网。

审核应逐条判断：来源是否支持该地域和事实、计划是否被误读为结果、候选问题是否预设痛点、所需渠道是否可核实、三方向是否具有不同决策用途。通过后由运营发布新内容版本，不能直接把本文件的20个 `draft` 批量替换为 `published`。
