# 高级方法：从计算到报告章节

数据分析的结果区新增“高级方法”标签（`components/analysis/AdvancedMethods.tsx`），补上正大杯报告常用、而分析模块此前没有的方法。每种方法都按同一条链走：完整案例 → 计算 → 按报告排版的预览 → 写进蓝图章节。

| 方法 | 计算（`lib/`） | 写进的蓝图章节 | 图 |
|---|---|---|---|
| 效度：KMO、Bartlett、主轴因子 + varimax | `psychometrics.ts`、`factor-analysis.ts` | 正式调查数据检验 | 碎石图 |
| 多元线性回归（VIF、Breusch–Pagan） | `regression.ts` | 回归模型分析 | 系数森林图 |
| 二元 Logistic 回归（OR、似然比、平均边际效应） | `logistic.ts` | 回归模型分析 | OR 森林图（对数轴） |
| 重要性—表现分析（自评或隐性重要性） | `ipa.ts` | 满意度与绩效评价 | IPA 四象限图 |
| K-means 聚类（k-means++、轮廓系数） | `kmeans.ts` | 聚类与人群画像 | 标准化中心剖面图 |
| 层次分析法（权重、CR） | `ahp.ts` | 方案优先级与成本评估 | — |

## 数字从哪来

- 只用所选变量都有有效数值的案例；缺失代码与空白不计入，不插补。教学模拟数据写进报告时，所在章节会加上“【教学模拟数据，不能作为实际调查结果】”。
- 每个计算模块都与独立实现对照过（NumPy / SciPy / scikit-learn / statsmodels，同一份种子数据），一致到 1e-12 左右；对照值写在 `tests/*.test.mjs` 里。
- 不能可靠估计时直接拒绝并说明原因：题项或案例太少、变量无变化、完全共线、Logistic 完全分离、Heywood 情形、主轴因子不收敛、判断矩阵不互反等。

## 写法（`lib/method-writing.ts`）

每种方法给出：方法说明（为什么用、以公式收尾）、KaTeX 公式、“式中”段（每个符号与适用条件）、结果表（名词短语表题、表头、表注）与读数段。读数只写关联、不写因果，条件不满足时直说（KMO < 0.6 或 Bartlett 不显著、交叉载荷、VIF > 5、异方差、CR ≥ 0.1、轮廓系数偏低）。图在 `lib/method-figures.ts`，与报告其他图同一配色与字体，经 `planSVG` 做矢量安全检查。

## 写进报告

“写进报告”经 `onReportInsert` 交给报告与 PPT（与抽样设计相同的通道），作为一步可撤销的写入：方法说明、公式、式中段、结果表（登记为该方法的结果，暂无计算凭据）、表注（统计量均为行内公式）、图、读数段。读数段用 `[[表:@N]]`、`[[图:@N]]` 引用同一次写入的第 N 项，写入时换成真实的块编号，因此导出 Word 时是“由表 x-y 和图 x-y 可知”。

图画的数字存在登记结果的 `metrics` 里（标签为“名称｜量”，至多 40 个，放不下时只写表不写图），`report-figures.ts#figurePlan` 遇到这些方法的结果时交给 `method-figures.ts#methodFigure` 重绘，所以编辑器预览与 Word 导出画的是同一张图。
