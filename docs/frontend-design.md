# 证见 EVI-X 前端设计约定

本轮按 `frontend-design-production` 技能执行，在原有研究工作台上完善托管项目页面和报告格式面板。保留证见品牌、侧栏工作台、项目路由、业务接口、编辑器、撤销和原生导出；不新增视觉组件依赖。

## 主任务与信息顺序

用户先确认登录身份和所在项目，再判断保存版本，随后生成提案或编辑。问卷提案、已保存版本、未保存编辑分别显示；成功以服务器回执为准。报告区先显示作品与导出操作，格式来源和参数收进可展开面板，保持写作空间。

## 视觉与行为

- 沿用青绿色主操作、纸白表面、深色正文和细边界。报告面板复用工作台 `--wb-*` 变量；托管页沿用现有配色，不再引入新色系。
- 标题、任务说明、操作、内容按层次排列。长标题与服务名可换行；网格子项可收缩，窄屏单列。版本列表独立滚动，不挤压编辑器。
- 当前导航同时提供文字下划线和 `aria-current`；键盘焦点明确可见，并提供跳到正文入口。保存、加载、失败和冲突使用文字反馈，避免仅靠颜色表达。
- 卡片位移仅用于悬停反馈；系统开启“减少动态效果”时取消。现有复杂工作台动效继续遵循已有 reduced-motion 规则。
- 报告格式来源和说明使用正常文档流；折叠后保持主操作可见，展开后按可用宽度显示规则列表。首行缩进和页码选项保持原生表单控件。

## 验收条件

使用本机 Codex 内置 Chromium 浏览器验证正式构建：桌面正常视口、390 px 与 320 px 窄屏，检查布局、导航、键盘入口、展开/收起及导出。合成邮件与合成模型用于流程测试；真实服务、原生手机 Safari、WPS 和 ONLYOFFICE 不计入本轮浏览器覆盖。

构建、独立代码复核、截图和实际操作记录分别保存于 `.collab/runs/20261007-p0`，汇总见 [P0 验收](p0-acceptance.md)。图片只能证明所展示的画面，运行证据与服务验证单独记录。
