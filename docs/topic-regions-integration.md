## 地理判断与独立发现

- v2 使用真实行政父链；直辖市和省直辖县不增加虚构的地级节点。
- 同省同名县不能仅凭县名获得精确匹配。例如江苏“鼓楼区”不能同时证明南京与徐州的地方来源。外部来源的旧县名标签须在来源声明的省份中唯一；没有省份时要求全局唯一。真实地级 OR 标签继续可匹配。
- 明确版本化县代码的辅助判断允许真实祖先显示名，拒绝其他省份、兄弟县区和错误代码。
- 当前公开事件包仍是原有 national/province/city 类型。县级事件的辅助函数与共同反例已验证，但正常内容包解析接入留在 P3；本批不宣称已发布县级热点。
- 目录是 2025 年末历史快照，社区整理来源尚未完成2026现势全量官方复核；港澳台在该来源中仅有省级节点。地方深入资料和功能区清单仍按内容批次建设。

## 模型回执与原请求恢复

POST 请求顶层字段保持兼容。v2 回执额外绑定 `sourceVersions`：原有四资产 manifest 的摘要，以及地区目录版本、截止日期和原始字节 SHA-256。客户端在规范化新请求时保存这些版本；校验回执时使用原请求捕获的版本，材料指纹也包含它们。

已派发的旧请求保留原始 JSON 值与幂等标识，目录升级后仍可核对原回执。后端首先检查认证用户拥有的精确幂等请求；只有新请求才应用当前目录、候选与服务校验。重复标识搭配不同内容被拒绝，新的失效地区请求不会调用供应商，也不会留下操作或费率记录。结果未知不自动换标识重发。

公共版本文件只包含哈希和目录元信息，不含教学偏好原文。离线检查复核前后端四资产、两份目录及版本文件；不联网、不自动升级内容，也不重写原冻结排序器。
