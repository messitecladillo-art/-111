# 研究成果质量与报告/PPT联动

## 本阶段能力

数据分析结果可登记为研究证据，整理并确认研究发现，再进入自由组合的报告和 PPT。结果保留源指纹、计算值、口径和内容哈希；发现保存问题、解释、其他解释、范围和行动意义。

报告正文可插入真实结果图表、原生三线表等内容块。图文对应面板列出每个章节和图表在 PPT 中的位置，区分已编排、未使用和版本变化。选择原文讲述重点后预览图文页，确认时追加页面，保留已编辑的原稿。

PPT 支持八种可修改起始版式，以及文字、原生统计图、原生表格和三份原创矢量素材的独立移动、复制、删除、锁定、层级、编组与撤销。没有固定章节、页数和分析方法顺序。工作台继续使用原有编辑器和保存机制。

## 内容与版本

- v1 文档和旧文字版分镜继续按原语义读取；富内容保存为 v2。
- 已确认发现的精确措辞单独绑定到章节。修改或重新确认发现后，旧章节仍需明确核对。
- 图文链接 v2 绑定正文、内容块、发现和结果快照，以及页面对象。报告修改、错误证据替换或隐藏图表不能被误判为当前版本。
- 异步预览冻结输入；报告或讲述重点更新后，旧提案不能应用。
- 大小、对象数量、Unicode、引用和来源限制由前后端共同校验；超过容量时保留原内容并显示原因。
- 账户/项目变化重建项目宿主，旧分析回执不能进入新项目。

## 矢量输出

正式 PPT 的统计图使用原生图表和内嵌数据工作簿，表格使用原生单元格，装饰与流程使用原生形状。文字、图注和数字可编辑。Word 图表保留自包含 SVG，同时提供实际渲染的 PNG 兼容预览。SVG 拒绝位图、外链、脚本和栅格滤镜。

三线表顶线/表头线/底线分别为 1.5/0.75/1.5 磅，各列居中。短表和表题尽量同页；长表可分页。统计底层保留完整精度，页面按明确显示精度排版，不把未知值当作零。

LaTeX 输出复用现有工作台，图表以有限 PGF 数据坐标表达，表格使用 booktabs。源文件与服务端校验通过不等于实际 TeX 引擎编译通过；生产环境仍需部署字体、编译沙箱并验收原生 PDF。

## 公开数据样板

启动现有 Next.js 应用后访问 `/examples/bank-marketing`。页面内可以修改、撤销并下载报告、PPT 和 JSON 备份。

数据来自 [UCI Bank Marketing](https://archive.ics.uci.edu/dataset/222/bank%2Bmarketing)，使用 CC BY 4.0 的公开历史记录。主样板采用 `bank.csv` 的 4,521 条记录、17 列；第二组使用 `bank-additional.csv` 的 4,119 条记录、21 列。不同文件的未联络标记和历史状态分别解释，不互换编码。`duration` 是联络后信息，不用于联络前资源配置。

主样板由产品相同的解析、频数、交叉表和分组描述程序生成。六个正文板块和三个图表全部绑定到六页 PPT，另有数据处理记录、AI 使用记录和主张证据对照三类附录。四类代表页也独立导出。报告与 PPT 的数值相同，行动内容是依据历史观察提出的试点建议。

复算与生成（CSV 和输出目录自行提供，不自动下载）：

```text
cd apps/evi-x-platform
node --experimental-strip-types scripts/build-quality-benchmark.mjs <source.csv> <private-output-directory>
npm run test:unit
npm run typecheck
npm run lint
npm run build
```

生成目录包含内容 JSON、完整 PPT、四类代表页、报告、附录、TeX 源码、来源摘要和图文覆盖回执。原始 CSV、参考作品、渲染截图和 Office QA 副本留在私有验收目录，不进入前端公共资源。
