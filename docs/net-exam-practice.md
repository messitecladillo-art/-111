# 网赛刷题

工作台侧栏新增独立“网赛刷题”，入口为 `/workspace#exam`。它使用用户提供的网赛资料，独立于问卷编辑、调查数据与赛事控制面。

## 首批题库

冻结版本 `historical-411597014a55b723` 包含 973 题：786 单选、118 多选、69 判断，实际题目引用 22 个来源。10 个知识分类包括市场调查基础、调查方案设计、调查与数据采集、问卷与量表、抽样与估计、描述统计、统计分析与推断、数据处理与报告、专项调研和综合练习。

网赛目录盘点 49 个文件，43 个可读、3 个同哈希重复、2 个 DOC 超时、1 个 ZIP；ZIP 中另有 2 个 XLSX 取得文字。解析器的 13,207 条候选是机械块，不是真实独立题总数；9,825 个隔离记录和 2,409 个冗余记录不加入可判分池，原因计数可能重叠。

独立审阅核对 36 题的题干、选项及源答案，覆盖三类题和 DOC/DOCX/XLSX/ZIP，原样本在最终版全部保留。独立核验 16,719 个题面/选项来源定位，并额外重查 3,382 个答案定位，20,101 次核验均可解析。此前扫描 236 道数学相关题面，发现的 32 项残缺、疑错或歧义均已隔离。另一次展示审查关闭了截断题干、选项粘连、题干条件缺失与解释混入后续题目等问题；尚未单题审阅的解释候选留在本地，首版只显示源答案与来源。未逐题独立重解所有历史知识答案，`semanticReviewed` 保持 false；题库内容版本随规范化题目内容变化。

最后一轮清理差异逐题回看，新增发现 4 项源键疑错或缺单位。已核隔离保留具体题目 ID，并对非 PDF 来源绑定来源 ID、原文件 SHA-256 和段落/单元格，避免清理题干导致题目 ID 改变后重新入库。PDF 全部保持布局待核，但不把整页的疑错标记传播到其他来源中的干净题。隔离不一概表示知识答案有错，后续可在单题来源复核后恢复。

## 使用

- 顺序练习、随机练习、章节练习、错题重练、收藏和模拟测试六个入口。
- 单选、判断选择一个选项；多选可反复勾选，提交后按完整答案集合判分。练习明确点击“提交答案”，模拟测试交卷后统一显示答案。
- 数字键选择选项，左右方向键切题，普通练习可按 Enter 提交。输入框、按钮与中文输入期间不会接管快捷键。
- 错题池以最近一次判分为准，重做正确后移出；收藏独立于正确与否。未作答题单独统计，不生成答错记录。
- 模拟测试可以选择题数与时长。题目 ID、随机顺序和截止时间在开始时冻结，刷新可继续；到期或主动交卷只计分一次。切换板块和隐藏页面停止视觉计时，回到题面依据真实截止时间恢复。
- 未完成的模拟测试开始新一轮需要页面内确认；取消后返回当前测试，不替换已有作答。

## 记录与来源

记录按登录账号 ID 和题库内容版本保存在当前设备，包括累计作答、错题、收藏和当前轮次。写入失败显示“未保存”，不称为云端保存。损坏、错账号、错版本或未知题目 ID 的记录整体拒绝读取。不同设备、同时打开的同账号标签页目前不合并练习记录。

题库对重复题按题干及选项文本去重，答案按选项文本核对；同题答案冲突及同一题块内不同显式答案进入本地复核清单。答案保留用户资料的明确答案，不由模型推测。提交后可展开文件名、SHA-256 与题干/答案定位。分类是练习知识标签，保留可识别的来源章节，不作为官方考试目录。

源资料缺答案、缺图片/公式、版面损坏、答案越界、编号作用域不明、重复答案冲突或发现明确错误时，题目不进入自动判分池。原始资料、提取原文及完整复核清单留在本地，不随产品源码上传。历史答案的结构检查、定向内容抽验与逐题知识复算是不同验收层次。

第十七届考试题数、时间、评分与合格线未硬编码；模拟数量和时间由用户设置。练习判分不会更新 `.agent/state.json`、赛事阶段或 Gate。

## 题库不随公开源码分发

历史题库来自第三方备赛资料，公开传播授权尚未确认，因此题库 JSON 不进入 Git 仓库，`apps/frontend/data/net-exam-bank.json` 已列入 `.gitignore`。题目原文、答案与来源文件名只保存在运营方服务器的私有路径：

- API 进程设置 `EVIX_NET_EXAM_BANK_PATH` 指向题库文件（建议放在源码目录外，例如 `/srv/evix/private/net-exam-bank.json`；本机开发可用仓库根目录下已忽略的 `.local/net-exam-bank.json`）。
- `GET /api/net-exam/bank` 只对已登录的受邀成员返回题库，响应沿用全局 `Cache-Control: no-store`；文件按修改时间与大小重新读取，结构不合格时返回 503，不提供旧内容。
- 未配置时接口返回 404 `net_exam_bank_unavailable`，练习页显示“此服务器尚未配置网赛题库”，其他功能不受影响。
- 前端 `parseExamBank` 与后端 `validate_bank` 使用同一结构契约：版本、来源编号、题型、选项、答案数量、`answerStatus=valid` 与来源定位。

若日后取得资料的公开传播授权，可撤销以上限制；在此之前不要把题库文件提交到仓库或公开站点。已推送到 GitHub 的历史 PR 分支仍含旧题库文件，彻底清除需另行处理。

## 重建与验收

先运行研究资料提取工具生成本地 `manifest.json`、定位文本与 ZIP 成员回执，再运行：

```text
python tools/build-net-exam-bank.py --extraction <本地提取目录> --output .local/net-exam-bank.json --review-output <本地复核清单.json>
```

生成器读原件时前后核对 SHA-256，校验提取文本哈希；输出须位于原始资料目录外。Office/PDF 文本提取属于上一批工具，本生成器不启动 Office、不调用模型。题库内容回归测试读取 `EVIX_NET_EXAM_BANK`（默认 `.local/net-exam-bank.json`），文件不存在时跳过，解析器合成夹具测试照常运行。

在 `apps/frontend` 执行 `npm run test:unit`、`npm run lint`、`npm run typecheck`、`npm run build`。Windows 可设置 `EVIX_PYTHON` 指向已有 Python；构建前设置 `EVIX_API_ORIGIN` 为本地 FastAPI 地址，Next.js 会在构建时冻结代理目的地址。解析器测试覆盖多套卷题号错配、答案表作用域、真假标签、无后缀 Word 图/公式、冲突去重、缺失公式、ZIP/成员/文本哈希篡改、跨段选项粘连、合法两/三选项与普通“答案”语句；进度测试覆盖重复提交、账户隔离、损坏存储、错题纠正、空白题、过期答题及 1000 题压力样本。

题卡每页最多渲染 50 个按钮，题面与结果复用现有显现/选择动效；准确数值直接显示终值，减少动态模式显示终态。浏览器验收覆盖 1280×720、1440×900、1920 宽屏，记录真实选择、提交、错题重练、收藏、模拟交卷、刷新恢复及键盘交互。

本批完整回归 659 项通过、7 项跳过、0 失败；lint、类型检查、Next.js 构建及 128 项托管构建检查通过。题库解析独立隔离复现 10/10 通过；从原源重复重建的公共 JSON 字节一致。最终 973 题页面实测翻至 20/20 页，最后一页只渲染 951–973 共 23 个题卡按钮；1000 题合成压力样本覆盖判分与恢复。未测得 FPS 或交互 P95，不将这些结构与功能验证称为帧率指标验收。
