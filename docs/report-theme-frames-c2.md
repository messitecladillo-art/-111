# C2：报告主题页框与可复用 Skill

本批基于 C1 `e0296d66833731d13c8bb9806eca1517bb613283`，增加可选的主题页框。已有问卷、分析凭据、共享图形、项目配色及单章报告分镜继续使用原有对象。

## 包含的能力

- `skill/research-report-frame/` 提供主题提炼、生图概念、矢量重建、版心保护、真实文稿校验与交付流程。四幅原创生图仅为概念参考，附完整提示词及来源回执；概念 PNG 不进入正式报告背景。
- 受控矢量主题包括“几何连接”和“运动轨迹”，可选择正文、章节或封面变体，调整边角、开放框、闭合框、线宽、密度与颜色强度。保留无框选项。
- 报告编辑器内并列展示无框、当前作品与候选方案。用户主动应用后才保存批准定义；页框修改、项目配色改变或版本漂移后，正式输出需重新应用。
- `ReportFrameStyle/v1` 保存主题、版心几何、保护区域、项目配色版本、图元参数及绑定定义哈希的复核记录。首次应用页框升级为文稿 v3；移除页框保持可撤销。旧文稿默认不增加装饰。
- 当前报告格式为 A4、左右 31.8 mm、上下 25.4 mm，正文版心 146.4 × 246.2 mm。页框额外避让正文外 3 mm 和登记的页码等区域。这是当前产品排版设置，不是通用赛事规则。
- Word 使用固定页面坐标的原生 VML 形状；未应用的分节使用明确空页眉，避免前一节装饰继承。LaTeX 使用可信模板的 TikZ 页面背景层。装饰不参加正文流，也不改变页边距、字号、正文行距和表格。
- 后台沿用严格契约和项目配色白名单，拒绝未知字段、非法几何、原始答卷、任意 SVG/TeX 与过期批准哈希。Skill 几何实现与后台文件按字节保持一致。

一份当前文稿保存一套页框定义及其应用范围；并未实现同一文稿同时指定三套不同变体，也没有将概念稿直接自动描摹为正式页框。

## 兼容与分批范围

报告与 PPT 的单章分镜继续使用 link v1/v2。页框不改变分析结果或既有章节、页面内容哈希；共享图形变化仍由 C1 的引用指纹识别。

本批不包含 D 的多来源 `sources`、link v3、分镜界面、样板生成器和十二页作品扩展。C1 的分镜实现及界面保持原样，服务端拒绝尚未支持的多来源字段。

应用时记录的批准代表用户对当前候选的选择；自动测试中的 `automated-test-actor` 只代表软件 QA，不代表用户视觉审核、素材权利审核或任何赛事规则认可。

## 验收

前端全量单元测试、类型检查、lint、生产构建与后端报告/图形/页框/LaTeX 测试分别执行。专项覆盖：

- 两种主题、三个变体、项目配色、三色短调色板、跨语言规范哈希及图元一致性。
- 版心和页码保护、越界与碰撞拒绝；应用、撤销、批准后篡改及配色版本漂移。
- 旧 link v2 加框前后保存恢复不变；未使用的稠密图形不阻塞 LaTeX 工作区。
- Word 原生页眉图元、封面单独应用后的空页眉隔离；无栅格背景，正文 XML 和页边距保持一致。
- 正式 TeX 源码的草稿/篡改拒绝；真实 XeLaTeX 编译后比较有框/无框 PDF 的页数、文字及位置矩阵，并确认新增的是矢量路径。
- Skill 的 26 项标准库测试与官方技能包校验。

原始日志、投影文件清单和独立验收记录保存在本次运行证据目录。原生 Word/PowerPoint、浏览器与实际 PDF 全页视觉审阅另有主任务证据；包检查不能代替这些检查，WPS 等未运行项目应继续标记为待验证。
