# 证见：循证三千年首页

## 产品与叙事

公开首页位于 `/`，放在受邀邮箱登录之前，主题为「无征不信 · 循证三千年」。页面把证见的证据链放进一条真实的中国证据史：每一章一句经典引文、一段解读，再接一张「今天，证见这样做」的对照卡。

| 章节 | 时代 | 引文与出处 | 粒子成形 | 对应的证见做法 |
| --- | --- | --- | --- | --- |
| 序 | — | 「无征不信」，《礼记·中庸》 | 谷纹圆环（日冕式光晕） | 品牌主张 |
| 壹 | 商 · 约前13—前11世纪 | 「貞，卜問也」，《说文解字》；卜辞叙辞、命辞、占辞、验辞四段 | 龟甲、钻凿与卜形裂纹 | 先锁定届次等五维与决策问题，结论回到原问题核对 |
| 贰 | 春秋 · 约前6—前5世纪 | 「文獻不足故也」，《论语·八佾》；朱熹注「徵，證也」 | 「徵」 | 缺失即未知，不补写数据、受访者或引用 |
| 叁 | 东汉 · 约公元100年 | 「廌……令觸不直」与「灋」的字形解释，《说文解字》；獬豸冠，《后汉书·舆服志》 | 「灋」 | 合成材料冒充真实证据判为致命问题 |
| 肆 | 清 · 乾嘉年间 | 梁启超《清代学术概论》归纳的四条考据学风 | 「證」 | 证据台账、制作与复核分离、不虚构、来源绑定 SHA-256 |
| 伍 | 今 · 2026 | — | Q → D → I → A 证据链（左下到右上） | 证据链四步与九道质量关 |
| 终 | — | 「问有据，见有策」 | 圆环回归 | 登录、了解证见、研究工具 |

滚动带中的「实事求是」出自《汉书·河间献王传》，已列入页脚出处。

第叁章的展柜卡片使用已批准的獬见全身生产锚点，说明獬豸在两千年后成为证见的守证灵兽，并标注「AI 辅助生成、经人工验收的原创概念角色」。页面不出现赛事、主办方、冠名方或高校标识，不出现奖杯、桂冠或红色官方印章。所有引文出处列在页脚。

## 视觉系统

- 色彩取自 EVI-X 令牌：近黑墨蓝底、墨证蓝光晕、证据金为主、洞见青为点缀；行动珊瑚未使用。
- 经典引文、章节标题与大字用宋体系（Noto Serif SC / 思源宋体 / 宋体回退），界面与说明用黑体系；不加载外部字体。
- 金箔渐变用于主标题与关键字；细金线展签、角标、双线印章（九道质量关）和竹简（贰章引文按原文竖排、自右向左、两道编绳）构成「馆藏」质感。
- 全页叠加极淡的纸纹噪点与十二列细线，模拟碑拓与研究网格。

## 版式与指针交互（2026-10-10 第二轮）

为避免每章都是「左文右图」，五章交替三种构图，粒子成形随之换位，章节之间的散聚因此也是横向迁移：

| 章 | 构图 | 粒子位置 | 章内交互 |
| --- | --- | --- | --- |
| 壹 商 | 图左文右 | 左侧龟甲 | 卜辞四段悬停抬升、金线划过 |
| 贰 春秋 | 居中 | 「徵」作暗背景 | 竹简逐片落下，悬停的那一片抬起，其余变暗 |
| 叁 东汉 | 文左图右 | 右侧「灋」 | 灋字部件与獬见展柜随指针 3D 倾斜并带随动高光 |
| 肆 清 | 居中 | 「證」作暗背景 | 四块考据碑：正面竖排古训，悬停或键盘聚焦翻面显示证见的做法 |
| 伍 今 | 文左图右 | 右侧证据链 | 证据链卡片倾斜与高光，九道关印章悬停盖印 |

另加两条古训滚动带（悬停暂停）、每章一个描边巨型年代数字（随滚动横移）。参考 Kimi 招聘页「多场景同台、按滚动切帧」的公开描述：横屏下文字块随滚动由模糊、缩小、下沉过渡到清晰，离开时再淡出；不支持 `animation-timeline` 的浏览器退回 IntersectionObserver 淡入。Kimi 官网在本环境网络策略下不可访问，未复制其任何素材或代码。

指针交互仅对精确指针（鼠标、触控板）启用，触屏与「减少动态效果」下全部关闭：

- 金色光环光标滞后跟随；悬停可交互元素时放大，按下时收缩。原生光标保留。
- 「探灯」：指针周围出现暖光，并显露隐藏的研究网格。
- 粒子在指针周围被拨开并提亮；点击泛起一圈向外扩散的涟漪。由着色器 uniform 完成，不逐帧更新 React。
- 主按钮与登录按钮有磁吸位移和扫光；倾斜卡片用 CSS 变量驱动 `perspective` 旋转与高光位置。
- 首屏提示「移动鼠标拨开金尘 · 点击泛起涟漪」只在精确指针且 WebGL 就绪时显示。

## 交互与运动

- 保留原生滚动。一张固定 WebGL 画布承载约 2 万个粒子（窄屏约 9 千），随滚动在七种成形间变形；变形中段粒子旋涡式散开再重聚，章节之间留出呼吸区，使散聚发生在两章空白处。
- 序章与终章的圆环缓慢自转；鼠标在桌面端带来轻微视差。
- 右侧时代索引（序 / 商 / 春秋 / 东汉 / 清 / 今）可点击跳转，金色进度线由 DOM ref 直接更新；章节变化时才触发 React 更新。
- 「暂停动效」停止自转、闪烁、漂移、滚动带与粒子的指针反应，滚动仍控制成形。系统减少动态效果时，粒子在章节间离散切换，入场、倾斜与翻转动画关闭，按钮显示为已按系统设置。
- 文案入场动画只在脚本运行且允许动效时启用；无脚本时内容默认可见。
- 页面切到后台时停止渲染；无 WebGL 或上下文丢失时，序章显示 SVG 圆环，各章显示与章节对应的描金空心大字（卜、徵、灋、證、证），居中构图的大字降为背景亮度。

## 实现与边界

| 文件 | 作用 |
| --- | --- |
| `components/landing/LandingPage.tsx` | 叙事内容、滚动进度、时代索引、旧书签重定向 |
| `components/landing/ChronicleScene.tsx` | Three.js `Points` 着色器、字形栅格化、可见性与上下文恢复 |
| `lib/landing-chronicle.ts` | 纯函数：成形生成、字形采样、滚动进度、各章布局 |
| `tests/landing-chronicle.test.mjs` | 成形边界、确定性、Q→D→I→A 方向、进度单调与布局连续 |

「徵」「灋」「證」由访客本机宋体在离屏画布上栅格化后采样；字体缺失时退化为柔和粒子云，不抛错。其余成形由固定种子生成，同一设备每次一致。像素密度上限 1.75；卸载时释放几何、材质、渲染器与监听器。没有新增依赖、后端接口、视频或外部字体。

## 验证与运行

沿用 [P0 运行说明](p0-running.md)。生产构建与开发服务器共用 `.next`，应先停开发服务器再运行构建。

```powershell
npm run test:unit --workspace evi-x-zhengda-champion-platform
npm run typecheck:web
npm run build:web
npm run start --workspace evi-x-zhengda-champion-platform
node apps/evi-x-platform/scripts/check-landing-routes.mjs
```

浏览器渲染在无 GPU 的 SwiftShader 环境中检查过 1440×900 与 390×844 两种视口的全部章节、减少动态效果、禁用 WebGL 回退、时代索引跳转与暂停按钮；帧率表现取决于访客设备，未在实体手机上测量。
