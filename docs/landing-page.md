# 证见：产品首页

## 定位与结构

公开首页位于 `/`，放在受邀邮箱登录之前，属于 `public_promo` 物料。版式参考常见的 AI 产品落地页：深色底、玻璃导航、渐变主标题、标签切换的产品窗口、功能便当格、证据链卡片、评价式滚动卡片和地平线光晕收尾。内容全部来自证见本身：

| 区块 | 锚点 | 内容来源 |
| --- | --- | --- |
| 首屏 | — | 主张「让每个问题，都循证抵达行动」；四个数字取自代码常量：12 个阶段、9 道门禁、`SILICON_LIMITS.personas`、`awardCaseLibraryStats.total` |
| 产品窗口 | — | 五个标签（问卷设计、硅基样本、数据分析、报告与 PPT、路演答辩），每张图都是工作台截图 |
| 方法滚动带 | — | 工作台已实现的方法与功能名 |
| 功能 | `#features` | 七个模块的便当格，配图为对应模块的截图裁切 |
| 证据链 | `#chain` | Q → D → I → A 四步与九道质量门禁 |
| 硅基样本 | `#silicon` | `SILICON_LIMITS` 中的画像、属性、情境、模型上限；四项保真度检验；模拟 ≠ 调查 |
| 赛程 | `#calendar` | `data/edition17-calendar.ts`（中商统〔2026〕33号），按组别列出并按访客本机日期计算状态与倒计时 |
| 获奖案例 | `#awards` | `data/award-cases.ts` 中 `official_verified` 的案例，只显示题名、学校、届次、组别、奖项 |
| 案例深读 | `#deep-read` | 用户提供的第十六届报告《脱下“长衫”之后》中的五页，按 Q → D → I → A 标注，可点开放大 |
| 分析模块 | `#modules` | `ANALYSIS_BLOCKS` 的用途与边界 |
| 无征不信 | `#origins` | 四段证据史（商·甲骨、春秋·《论语》、东汉·《说文》、清·考据学）与獬见角色 |
| 立场 | `#principles` | 独立非官方、不编造证据、模拟不等于调查、规则有出处 |
| 开始 | `#start` | 免登录工作台、团队项目、了解证见 |

锚点避开旧书签名（`cases`、`rules`、`design` 等）：这些旧片段仍由 `lib/landing-navigation.ts` 重定向到 `/workspace#…`、`/explore` 或 `/projects`。

## 配图

- 截图来自本地工作台的深色主题：教学示例问卷「校园服务体验」、离线演示引擎的 24 位虚构画像、12 行模拟数据和报告模板。截图前隐藏了开发指示器与本地验收横幅。
- 文件位于 `apps/evi-x-platform/public/landing/`：`app-*-960.webp` / `app-*-1600.webp` 供产品窗口按宽度选择，`crop-*.webp` 供功能格与硅基样本区使用。工作台截图合计约 1 MB，除首张外延迟加载。
- 产品窗口下方标注「真实界面 · 示例数据」和该图的具体内容；页脚说明截图使用教学示例与模拟数据。
- 硅基样本区的轨道动画由 CSS 3D 生成：三条轨道各代表一个模型，小人沿轨道公转并始终直立；它是示意，不对应任何运行结果。
- 案例深读的五页取自用户提供的报告 PDF（语料 `CASE-NEW-BLUE-COLLAR`，哈希与 `user-case-intake-2026-08-04.json` 一致）：摘要、表 2 递进式证据链、抽样方案、LPA 画像、分类支持路径。封面含赛事标志与队名，不使用；所选页面没有受访者身份信息。页面写明奖项为用户陈述、尚未与官方公告核对。公开发布前须取得报告作者同意。
- 獬见使用已批准的生产锚点 `evi-x-character-anchor-v2`，并标注「AI 辅助生成、经人工验收的原创概念角色」。

## 动效

- 首屏：三团缓慢漂移的光晕、带径向遮罩的研究网格、闪烁星点；徽标的呼吸点；主标题渐变缓慢流动。
- 产品窗口：随滚动从倾斜展平（支持 `animation-timeline: view()` 的浏览器）；标签每 7 秒自动切换，进度条显示在当前标签底部，悬停或聚焦时暂停，用户点选后停止自动切换；三张浮动说明卡上下浮动。
- 首屏数字进入视口时计数；各区块进入视口时淡入上移一次；卡片有随指针移动的聚光。
- 证据链上一个光点从 Q 走到 A；滚动带与案例卡片无缝循环，悬停暂停。
- 右下角「暂停动效」暂停全部循环动画与自动切换。系统开启「减少动态效果」时不显示该按钮，所有动画与过渡关闭，内容直接可见。无脚本时内容同样可见。

## 无障碍

- 产品窗口是 `tablist` / `tabpanel`，支持左右方向键、Home、End；未选中的截图对辅助技术隐藏。
- 赛程组别按钮使用 `aria-pressed`；「下一项」卡片在切换组别时以 `aria-live="polite"` 播报。
- 循环滚动的第二份副本设为 `aria-hidden` 与 `inert`。
- 案例页用按钮打开原生 `<dialog>`，Esc 或点背景关闭，焦点回到原按钮。
- axe（WCAG 2.2 AA 与最佳实践）在 1366 px 动效开启和 390 px 减少动态效果两种条件下均无违规。

## 实现

| 文件 | 作用 |
| --- | --- |
| `components/landing/LandingPage.tsx` | 全部区块、产品窗口标签、赛程、轨道动画、旧书签重定向 |
| `components/landing/LandingPage.module.css` | 令牌、版式、动效、响应式与减少动态效果 |
| `public/landing/*.webp` | 工作台截图（`app-*`、`crop-*`）与案例页面（`case-*`），来源登记在 `data/asset-provenance.json` |

没有新增依赖、后端接口、视频或外部字体。原「循证三千年」WebGL 粒子叙事（`ChronicleScene.tsx`、`lib/landing-chronicle.ts` 及其测试）已移除，其中的四段证据史保留为「无征不信」一节。
