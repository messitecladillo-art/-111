# 证见：寻证之旅首页

## 产品与叙事

公开首页位于 `/`，放在受邀邮箱登录之前。四幕分别呈现古代市集的记录、19 世纪末的侦探桌、现代调查的样本视野和证见观察框。2026-10-10 的精简版每幕只保留一句主文案、一件像素主体和必要导航；页头仅有「了解证见」与登录入口，底部用四个小标记呈现进度。

视觉采用接近黑色的背景、低饱和石色像素和少量薄荷绿。主角是记录板、放大镜、样本网络和开放观察框；没有人物肖像、侦探服装或影视角色。场景是概念叙事，古代交易记录与侦探时代的参考链接位于 `/explore` 页脚。

首幕与末幕以短副标题说明产品是「市场调查与分析 AI 工作台」。可以编辑和撤销的问卷、合成样本核验、报告依据预览及常见问题移至独立的 `/explore` 页面，通过「了解证见」进入。登录后入口自动转向托管项目。

## 交互与运动

- 保留原生滚动，不拦截滚轮，也不设置强制播放、声音或自动翻页。
- 一套像素几何连续变形。拱门与记录转为放大镜和纸片，镜头推进后展开为样本网络，最终收束到证见观察框。
- 四个章节标记可点击跳转；中间箭头进入下一幕。旧的细节按钮、小票面板、展开视野和大时间线从公开首页移除。
- 文案在几何变形中段淡出，再显现下一幕。文本透明度通过 DOM ref 更新，避免逐帧触发 React 更新。
- 「暂停自动动效」停止环境漂移和鼠标视差，滚动仍直接控制时代进度。系统启用减少动态效果时，切换为离散静帧，关闭穿越镜头。
- 下一幕按钮跳转后把焦点交给标题，章节标记保持自身焦点，自然滚动不抢焦点。手机使用纵向构图，横屏使用左右构图。舞台使用 `overflow: clip`，避免旋转视口后焦点引发内部滚动与画面错位。
- 页面离开可见区或切到后台时停掉渲染循环。无 WebGL 或上下文故障时保留 SVG 画面、文字和导航；独立产品演示无需 WebGL。

## 实现与边界

仍使用 `apps/evi-x-platform` 的 Next.js 工程。首页 scoped CSS 与原工作台样式隔离。Three.js 为客户端动态加载；没有引入视频、外部字体、图片 CDN、GSAP 或新的后端接口。

GPU 使用一个实例化网格，桌面 4608 个方块、窄屏初始加载 3072 个，像素密度上限 1.5。场景由固定种子生成。滚动值保存在 ref 中，React 仅在章节变化时更新；逐帧没有 React 状态更新。卸载释放 GPU 资源、监听器和观察器。

产品演示仅使用本页内存。问卷连续输入按一次撤销记录，选项最多 6 项；两种采样方式均为 24 条合成记录，报告从当前采样方式计算覆盖数字。页面不会创建项目、上传答卷或调用收费模型。刷新重置示例。

## 路由与保留

| 地址 | 用途 |
| --- | --- |
| `/` | 四幕寻证叙事首页 |
| `/explore` | 交互产品演示、常见问题及概念参考 |
| `/workspace` | 原研究工作台，问卷、统计、报告/PPT、案例与答辩继续保留 |
| `/projects` | 托管团队项目与问卷版本 |
| `/services` | 个人模型服务 |
| `/login` | 受邀邮箱登录 |

原 11 个首页 hash 书签有明确白名单：`#services` 到 `/services`，`#workspace` 到 `/projects`，其余研究工具锚点到 `/workspace#...`。旧首页 `#product` 转到 `/explore`，`#questions` 转到 `/explore#questions`。`#journey` 和未知 hash 不参与重定向，任意查询字符串不被当作跳转目标。

原首页改造前的 542 份源文件保存在 `.collab/runs/20261007-landing`；本次精简前的 554 份源文件清单与 ZIP 快照保存在 `.collab/runs/20261010-landing-minimal`。研究工作台、后台接口和项目数据继续沿用。

```powershell
npm run build:web
npm run start --workspace evi-x-zhengda-champion-platform
node apps/evi-x-platform/scripts/check-landing-routes.mjs
```
