# 知识镜账户、引用与联网批次

## 已实现

收藏、最近阅读与浮窗偏好按账户保存在 PostgreSQL。客户端按 800ms 防抖，以预期修订和幂等标识提交；成功显示依据服务端回执。并发冲突保留本地修改；未知保存用同一标识核对。账户切换立即更新会话代次，旧读、写、删除和晚到回执均不能作用于重新登录的同名账户。

项目术语表复用团队权限，引用精确词条版本。公开知识通过冻结来源清单发布；发布器携带既有历史，拒绝改写同一 ID／版本。旧版可由 `/knowledge-data/entries/{entryId}/{version}` 读取，刷新后的引用不自行转成新版。

联网查证仅在确认短查询后执行 Tavily basic；固定最多五项来源，不发送页面、答卷或 OCR 文件。后台先提交额度预留与请求标识，再调用供应商；超时、缺少用量或结果未知保留待核对状态。运营 Key 在服务器环境配置，界面和公共目录不包含 Key。补词申请与个人记录受账户权限限制。

## 实际验收

2026-10-15，在本机 Next＋FastAPI＋PostgreSQL 的合成团队中：

- 邮箱验证码登录、收藏 Cronbach α、建立 v1 项目术语引用及服务器同步成功。
- 新标签页从服务器恢复同一账户的收藏、最近阅读与项目术语；切换另一账户后，前一账户的收藏与阅读记录未出现，项目列表亦按团队隔离。
- 私有运营配置的真实 Tavily 直连和界面联通各执行一次公开术语 basic 查询；两份回执均为 ready，各 1 credit。没有重复发送收费请求。
- 35 项知识接口在真实 PostgreSQL 和受限应用角色上通过；完整后端 410 项通过、14 项原有可选检查跳过。
- 独立复核关闭历史发布覆盖、精确路由范围及 A→B→A 缓存代次问题；23 项针对性回归、类型、lint、发布检查通过。
- 前端完整回归与生产构建保留原有问卷、分析、图表、报告/PPT、画布和首页。

本机邮箱为测试适配器；此结果不代替生产邮件送达或云端部署验收。原生 IME、冷启动完全离线 OCR 及知识解决率事件测量保留为后续项目，不在本批已通过指标中。词库数量以独立审校并实际发布的概念计数，草稿与别名不计入。
