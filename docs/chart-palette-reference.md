## 核对方式

在浏览器打开原文，读取正文的 `image 1` 至 `image 35` 图片编号及实际图片地址；随后在独立浏览器标签查看其中八张图片，直接核对图片中打印的 HEX 和 RGB 标注。没有执行原文 MATLAB 代码，没有利用图片像素反推未知色码，也没有复制原图到产品资产。

仅录入已看清的 HEX 标注。色卡名称、分类方式和适用用途由证见自行拟定，属于使用建议。文章中的原论文身份与出版信息未逐项追溯，因此这些名称不标记为某期刊官方配色。

## 接入规则

- 项目主题存储稳定色卡 ID；类别颜色另以稳定类别键绑定，筛选、排序后沿用原颜色。
- 白底浅色图形使用深色轮廓、文字或分隔线；密集系列配合点形、线型和直接标签。
- 深紫与黑、浅紫与浅灰等近似颜色需要在实际图形中检查可区分性。当前完成来源核对，尚未宣称通过色觉模拟、灰度打印或所有背景的对比度测试。
- 顺序色阶表示单向大小；正负偏离使用另行设计并检查的发散主题。多类别颜色不直接插值成为强度色阶。
- 统一主题已作用于图表预览和下载图片；报告/PPT 的版本化引用按 P3 接续。改变样式不改变统计口径与计算结果。
