2026-10-11。直接扩展现有证见数据分析和图表工作室，电脑端，本批成果留在本地。验收使用确定性合成数据，不产生真实受访者记录。

## 发现及修复

马赛克图从每个单元格一个自定义系列改为每列一个系列：400→20 个系列，400 格数据保留。预计算交叉索引，窄格只在空间足够时显示文字；完整分类与频数仍可通过提示和表格查看。

模块化 ECharts 引擎原先缺少旧 `containLabel` 布局实现；改用当前已注册的 `outerBoundsMode/outerBoundsContain`。重复绘制时不再出现该布局警告，坐标标签采用重叠隐藏，表格和交互提示保留完整名称。

实际默认 1200×720、字号20的雨云图暴露短组名被截成相同“人群…”的问题。分类轴改为换行并按密集程度旋转，20 个组名均保留可辨后缀；多组分布与交叉图例完整分行展示并预留高度，静态导出不只留下分页图例的第一页。额外回归解析实际 SVG，逐组核对完整轴名与图例；新增配色储备同时检验所有稳定 ID 的格式恢复和短色卡的热力色阶。

热力图静态导出的连续色条补上零值和当前最大频数，保留真实 0–最大值范围；配色变化不人为拉大相近频数的对比。图例仍标明交叉频数。

三线表以共享常量固定顶线/表头下线/底线为 **1.5 pt / 0.75 pt / 1.5 pt**，与普通图形线宽解耦，不带竖线和内部横线。预览直接使用 pt；SVG 原始画布按 96/72 转换为 2/1/2 单位，PNG 对同一 SVG 编码。每列表头及内容独立居中，多行内容按行高居中；题名和注释保持原有对齐。导出图片在报告中再次缩放时，线宽也会同比缩放；原生 Word/PPT 数据表属于后续成果工程。

## 验收链

Node 使用实际模块化绘图引擎，对现有 30 种图形和结果表的 90 个适用组合绘制（含不同结果与双字体）；严格解析 SVG，检查绘图数据索引与有效样本，不能仅凭 `n` 标题判定完整。随后执行 120 次绘制/销毁循环，并在预热和显式 GC 后记录堆内存。

浏览器测试页面复用真实 `ChartStudio/ChartPreview`，不是另一套演示图。覆盖 60 次连续确认绘制、36 次快速状态提交、最终图型/标题/样本绑定、复杂雨云和热力的 SVG/PNG 编码。精确 A→B→A 测试先截住 PNG 编码回调，确认切换到 B、回到原 A 并完成绘制，再释放旧回调；旧下载被取消。卸载期间的晚到编码同样取消，恢复后可再次导出，测试创建的对象 URL 最终归零。

浏览器自动记录共 68 次确认绘制。36 次快速提交逐次确认状态已进入 DOM，只要求最终帧正确，不将中间请求全部计作完成绘制。自动运行内的四份 Blob 检查编码内容和 PNG 尺寸；实际文件下载另行通过工作室按钮验证，记录分开保留。

真实工作台采用 `localhost:3180` 的独立源本地存储，保留原 `127.0.0.1:3180` 页面的研究状态。读取合成 CSV、设置 NA、恢复八模块方案、逐项计算得到 8/8 当前结果，下载汇总与独立程序对照一致，然后选择复杂图型、修改色系并实际下载 SVG/PNG。400 行长表 PNG 超出画布保护时提示转用 SVG，SVG 保留全部行。

## 复现与记录

在 `apps/evi-x-platform` 运行：

```powershell
npm run test:charts:stress
npm run test:charts:browser
```

证据目录：`.collab/runs/20261011-chart-stress/`。保留旧 `baseline`、`final`、`final-three-line`、`before-range-*` 及因新增要求触发源码漂移而失效的独立记录，最终批准绑定最后的源码清单。`browser-release.json` 是最终浏览器记录，`browser-site/build-binding.json` 记录实际打包输入和 JS/CSS 哈希；更早的 `browser-baseline.json` 的 A→B→A′ 不能作为精确 A→B→A 证据。

最后生产工作台的实际按钮下载保存在 `workbench-final-*`；配色格式下载/恢复及逐列居中的 UI 回执另外保存在 `workbench-release-ui-receipts.json`。最后的雨云图预览截图为 `desktop-palette-and-chart-final.png`，当前配色库可见九组，原统计样本 n=4,884 不变。原始缺陷截图和导出保留，不当作当前结果。

## 本机最终结果

- 单元检查：580 项，573 通过、7 个条件跳过、0 失败；lint、类型检查、生产构建通过，114 项托管构建隔离检查通过。
- Node：90 个适用绘图组合及 120 次循环通过。循环中位数 36.6 ms，P95 115.4 ms，最大 143.2 ms；预热和显式 GC 后堆变化 +88,072 字节。
- 浏览器：68 次确认绘制、36 次快速状态提交、4 份复杂 SVG/PNG 编码及精确 A→B→A/卸载晚到取消通过；P95 118.4 ms、最大 183.2 ms，记录 25 个长任务，测试对象 URL 最后为零。
- 生产工作台：八模块重新计算、格式文件恢复、二十组完整名称、400 格热力图真实色条范围、400 行居中三线表 SVG，以及复杂图实际 PNG 下载通过。

以上数值来自 Windows、Node 24.15、ECharts 6.1 和 Chromium 155 的本次运行。浏览器仍有长任务，单次复杂绘制不等于持续 60 FPS；后台并发负载未在此轮测量。图注英文词元的跨行排版可继续润色，保留在后续视觉优化清单。

计时为本机观测：Node 循环包括绘图、严格 XML 和数据索引检查；浏览器包括 React 调度到实际 SVG/表格就绪，不包括数据准备。浏览器堆没有强制 GC，不能与 Node GC 后堆读数直接比较，也不能据此判断泄漏。本轮证明已支持边界内的复杂图、切换和导出行为；后端队列、云端并发和 P1–P4 仍按总任务表接续。
