## 采用方式

当前赛事官方要求决定报告格式；国奖案例提供组织与表达参考；本来源用于加强论证、压缩冗余和图表质量。按中文市场调查报告的研究对象、样本口径和决策目标使用，不套用 Nature 的篇幅、图数、字体或投稿尺寸。

六份实质材料：`nature-writing/SKILL.md`、`nature-polishing/SKILL.md`、`nature-figure/SKILL.md`、`nature-writing/references/paragraph-flow.md`、`nature-figure/references/figure-contract.md`、`nature-shared/core/main-text-discipline.md`。另核对共享路由与 LICENSE。逐文件内容、哈希及定位保存在 `.collab/runs/20261011-chart-studio/evidence/nature-reference.json`。

## 方法卡与产品位置

| 卡片 | 用在何处 | 执行方式 | 验收依据 |
| --- | --- | --- | --- |
| NAT-01 段落单一任务 | 报告章节编辑 | 先写该段主题句，再列支撑证据，最后说明其对章节目标的贡献 | 段落可概括成一个论点，名词和指代清楚 |
| NAT-02 反向提纲 | 报告结构复核 | 从已有正文抽取“研究问题→主题句→结果引用”，按决策逻辑组织段落 | 每条主题句有对应依据，能回到章节问题 |
| NAT-03 保真润色 | Agent 修改提案 | 起草与语言润色分开；改写前锁定数值、变量、样本和范围，形成可审阅差异 | 润色不改变数字、正负方向、因果强度或对象范围 |
| NAT-04 结果分工 | 正文、图注、方法、附录 | 核心发现和会改变建议的结果留在正文；完整诊断和过程台账按用途安排 | 没有遗漏反例，计算与结论仍可复核 |
| NAT-05 压缩重复 | 章节和全文审阅 | 新句加入时先检查能否替换旧句；标记重复论点的引入、证明、解释、建议功能 | 每次重复都有新增内容，保留修订记录与撤销 |
| NAT-06 一图一问 | 图表树与后续图组 | 先确定研究目的和当前结果，再选择图型；多面板只容纳必要的互补信息 | 图型与数据相配，图表能回答绑定的研究问题 |
| NAT-07 稳定色系 | 项目图表格式 | 同一变量类别按稳定身份分配颜色，整篇报告沿用色系；强调色有限使用 | 排序、筛选和图型切换不按显示位置重派颜色 |
| NAT-08 数字与图注 | 图表预览、导出 | n、单位和误差定义由计算结果提供；SD、CI、检验结果分别表述 | 不能由样式选项产生未计算的显著性或区间 |
| NAT-09 渲染复核 | Word/PPT 与图片输出 | 在目标输出尺寸查看成品，检查标题、图注、表格、裁切和间距 | 实际下载文件通过打开和视觉检查 |
| NAT-10 适配渲染器 | 图表工程 | 保留 ECharts 网页预览，将其图件质量原则用于导出验收 | 网页交互与导出都验证，不替换现有渲染架构 |
| NAT-11 规则优先级 | 报告格式配置 | 将通用表达建议与届次、组别、赛区、赛道、阶段的硬规则分别存放 | 外部写作指导不冒充赛事规定 |

## 当前落实与后续工程

图表工作室已有按用途选图、稳定类别色系、准确 n 与误差定义、尺寸设置、SVG/PNG 和真实导出检查。这些行为对应 NAT-06–10，验收继续以本轮实际计算、源文件和浏览器记录为准。

NAT-01–05 是下一批报告编辑的质量流程：需要与 `ClaimRecord`、结果版本和修改提案绑定，输出可编辑反向提纲与差异。当前没有新增自动段落评分、自动改写或“已符合期刊/赛事”的判定。官方报告版式、原生 Office 持久化以及跨成果数字引用仍沿用总任务表中的 P3。

段落检查的最小记录建议：段落 ID、章节目标、主题句、论点引用、证据版本、修订提案、人工决定。数字保真检查先使用固定程序比较改写前后的数字与单位，再由模型检查语义变化；语言修改以提案方式应用，保留原文版本。

图组的后续记录建议：研究问题、结果版本列表、面板目的、共同色系、轴单位和范围、图注、导出尺寸。需要共同尺度时显式对齐；不能为了统一视觉而改变统计结果或隐去有效的负值。
