# 知识镜：本地文档识别与搜索验收

本批在已完成的知识镜中增加按需打开的本地 PDF／图片识别。文字 PDF 先提取文字；扫描 PDF、PNG、JPEG、WebP、BMP 使用锁定的 Tesseract.js 7.0.0 同源 Worker。识别文字可修改，再用同一套本地词库提取候选概念。

## 资源与边界

- 文件不超过 20MiB；图片解码前读取头部尺寸，最多 800 万像素／8192 边长。
- PDF 渲染按同样像素上限缩放；关闭 XFA、自动获取、流式读取和外部 WASM。
- 单个 OCR Worker、60 秒超时、12,000 字符文本上限。取消、换文件、换页、收拢及隐藏页面终止运行，晚到结果不进入新页面。
- Worker、嵌入 WASM、中文／英文语言包全部同源，SHA-256、来源与许可在资源 manifest 登记，构建检查字节与锁定 npm 包。
- Worker 实际响应采用限定 CSP：脚本与连接仅同源，允许 WASM 编译；未放宽研究页面的脚本策略。

## 已观察到的验收

2026-10-15，Windows／Chrome 155，实际 Next 开发服务：

- 两页合成 PDF 文字页返回 Cronbach alpha、confidence interval、SEM、GIS、PCA 等概念候选。
- 同文件的扫描页完成中英混合 OCR，读出反向题、置信区间、结构方程模型、抽样框与选择偏差。
- 倾斜 3° 的中英混合 PNG 完成识别并返回同组候选。
- 运行中取消显示取消状态；换文件后保留新文件身份，先前结果被清空。
- 9 个独立识别回归覆盖图片签名、截断／超限、PDF 尺寸、初始化取消、协议、晚到结果和像素编码期间取消。
- 5,000 条索引实际浏览器压力结果见 knowledge-browser-performance.md；100 次查询正确，端到端 P95 23.965ms，无主线程降级。

完整离线冷启动、复杂数学公式和任意扫描质量不在本批通过范围。语言包使用本地缓存；浏览器支持完整离线识别仍需在明确断网条件下单独验收。识别提供文字和术语候选，不生成图表结论。
