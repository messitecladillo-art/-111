# 图表工作室：首批实现

2026-10-11，原位接入 `apps/frontend` 数据分析板块。电脑端；本批不推送 GitHub。图表建立在已有的固定统计结果和精确样本投影上，绘制本身不修改分析结果。

## 使用路径

进入数据分析，读取 CSV/TSV 或试用教学数据，核对缺失代码与题目对应，配置并计算分析模块，再打开「图表工作室」。左侧按用途选择图型，中间预览，右侧修改格式。模块设置、题目应答范围、缺失代码或数据变化后，旧图停止预览和导出；重新计算恢复。

## 已接通的图型

| 结果类型 | 可用图形 |
| --- | --- |
| 频数与比例 | 柱状、条形、棒棒糖、饼、环形、矩形面积、样本格 |
| 数值分布 | 直方、箱线、密度曲线、累积分布、点带、小提琴、雨云 |
| 分组描述 | 组均值、均值±样本标准差、分组箱线、分组小提琴、分组密度、分组雨云 |
| 交叉分析 | 分组柱、堆叠柱、百分比堆叠、交叉热力、马赛克 |
| Pearson/Spearman | 原数值散点、有效配对平均秩散点 |
| 信度与题项诊断 | 校正题总相关、删除后 α、反向计分后的题项均值 |

共 30 种图形配方；各类结果都可切换到结果表。表格支持三线表、网格线和简洁留白。选择树只提供对应结果的图型；无有效样本保留表格，常量/单例停用密度图，饼/环形限少量类别，未定义诊断保持空值。

三线表统一顶线 1.5 pt、表头下线 0.75 pt、底线 1.5 pt，无竖线及内部横线；不随普通图形线宽变化。表头与每列内容分别居中。预览与原始 SVG/PNG 画布使用同一单位换算；原生 Word/PPT 数据表与图片插入后的物理缩放另行验收。

## 统一与单图格式

项目级研究蓝、洞见青、山林绿、墨紫、石墨五套同色系。类别标识决定色值，排序与过滤不会按当前位置重新分配颜色；有限色板可能复用色值，构成图始终保留类别名称。单图可配置强调色、图表标题、副标题、横纵轴名称、图下注释、字体、字号、小数位数、图例、数值标签、网格、边框、线宽、点径、背景/文字颜色和导出宽高。Unicode 下标可直接写入标题或轴名称。

「配色组合库」另提供九组科研配色，展开查看色块、HEX 和适用类型，点击应用到项目，其他图表同步使用。八组来自已视觉核对的原文色卡，一组为其中暖色子集的顺序组合；名称与适用用途由证见设计，详见 `chart-palette-reference.md`。分类颜色保留原值，热力强度另使用单调连续色阶：原五主题端点保持不变，新增分类方案从最深色向白色派生，顺序方案使用原有三色。格式文件可保存并严格恢复这些稳定 ID，继续绑定同一计算版本。

空轴名按实际图型派生：密度使用概率密度，ECDF 使用累计比例，秩散点注明平均秩，误差线明确为 ±1 个样本 SD。项目格式统一操作保留每张图自己的题名、轴名和注释。

## 下载与恢复

SVG/PNG 从独立的 SVG 绘制实例生成，绑定当前结果和格式。SVG 严格解析；PNG 由浏览器对同一 SVG 编码。切换或修改格式期间，旧请求不能在 A→B→A 后恢复下载。SVG 中没有系统品牌。

「下载当前格式」包含当前已计算模块的图型和格式（包括未编辑的默认图），不含答卷、数值结果或样本点。数据哈希与计算设置签名绑定恢复条件。「载入格式」逐字段校验 JSON、重复字段、尺寸、颜色、图型及版本；未出现在文件中的待算/撤销偏好继续保留在内存。恢复方案需先读取同一数据、恢复分析方案并重算，再载入格式。

表格 SVG 随完整行数展开；PNG 高度超过 8192 或超过 1600 万像素时，明确选择 SVG，不截断行。数据、计算、图表格式目前都沿用分析板块的本地流程，格式单独下载；托管图表版本和报告/PPT 的引用闭环属于后续工程。

## 计算口径

图表输入来自模块计算使用的同一有效表：原表 → 筛选分支 → 已确认的共同应答范围 → 有效数值/配对。数值、组均值和信度指标与既有计算结果核对。箱线采用 Type 7 四分位数及 Tukey 1.5 IQR 范围内的观测须，离群点保留；直方采用 Sturges 等宽箱（末箱右闭），常量单箱。KDE 为 Gaussian/Silverman robust，并记录带宽；小提琴峰宽独立归一。ECDF 合并并列值。散点没有随机抖动，样本格每格对应一条有效记录。

## 实现与验证

ECharts 6.1.0 固定版本，使用按需加载的静态命名导入，只注册本批八种绘图引擎和 SVG 渲染器。预览以整个绘图层等比缩放，ResizeObserver 随窗宽量测，保持绘图坐标一致；切换时销毁实例和观察器。字体使用 XML 安全的 CSS 引号。

桌面「专注图表」让同一工作室占满窗口，目录、预览与格式各自滚动，图表和编辑状态保留。Escape 退出，Tab 限于工作室内，背景元素临时 inert；关闭或卸载时恢复背景、页面滚动与焦点。结果表的标题按实际字号换行，并预留字体上缘空间。

关键实现：`lib/chart-{types,data,registry,theme,options,engine}.ts`、`components/analysis/ChartStudio.*`、`ChartPreview.*`。独立测试：`tests/chart-data.test.mjs`、`tests/chart-boundary.test.mjs`。验收原始记录位于 `.collab/runs/20261011-chart-studio/`；完整回归、类型、lint、构建及实际浏览器下载以该目录最终记录为准。

ECharts/LICENSE、NOTICE 和第三方声明以及 zrender/LICENSE 已保存到 `docs/third-party/`；sax 1.6.1 仅用于严格 XML 测试。

复杂图与 5,000 行支持边界压力测试见 `chart-stress-validation.md`，追加证据在 `.collab/runs/20261011-chart-stress/`，不替换此前的基础验收记录。
