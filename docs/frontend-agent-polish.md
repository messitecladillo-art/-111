# Agent 工作区界面整理（2026-11-12）

基线：`d06be8805367ebe8cbc8e1be328da7ff87732fd9`。范围为 Agent 工作区和模型服务接入页。

## 设计与边界

参考 [Recent / Web](https://recent.design/?category=web) 及其中的 [Krea Agent Onboarding](https://recent.design/i/t865vsj-krea-agent-onboarding)，提取内容分层、留白和逐步展开的组织方式。没有复制第三方素材，也没有增加图片或依赖。沿用现有字体、青色操作色、金色强调色与深浅主题；首页没有改动。

- 研究入口强化题目输入，提供三个可修改的方向示例。点击示例只填写方向，不发起任务。
- 团队条件、自动推进设置和步骤模型按需展开。每种模型任务保留自己的名称，失效选择仍明确显示。
- 有对话时研究路线可以收拢；使用原生 `details` 保持原研究组件与编辑状态，不另建数据副本。
- 顶栏保留视图、素材架和模型配置；代码、模型信息和对话导出移入“更多”。菜单支持 Esc、失焦关闭。
- 侧栏研究进度与分析产出可收拢，保留项目、最近对话、搜索和管理操作。
- 小于 960px 时素材架使用覆盖面板，不再隐藏。打开移交焦点，Esc 或关闭按钮收起后返回原控件。
- 模型服务页区分“服务接入 / 任务分工”，整理表单、服务列表和空态。页签支持方向键、Home/End。修改配置后聚焦对应表单。

## 后续整理：模型继承与独立素材

模型分工继续采用已有优先级，界面分为默认模型、任务分配、具体步骤覆盖。普通步骤配置默认收拢；失效配置始终可见，修复后接续键盘焦点。顶部按实际调用步骤统计模型分配数，不把配置保存或能力匹配写成供应商连通成功。

预览与主要操作前置，来源、中文材料分类和完整指纹收入可展开详情。图片仍以下载原图为主操作；未增加图片自动应用到报告的能力。账号或项目尚未确认时禁用素材写操作并说明原因，沿用原来的 scope/lease 校验。

## 文献研究阅读顺序（2026-11-13）

文献面板改为资料优先：文献与已确认摘录数量、导入与显式运行置前；五个角色及其本地规则回执放入可展开的协作区。候选选题区分别呈现研究问题和验证思路，适用条件与原文引用按需展开，全部文本、来源和物理页码保留。没有改变文献解析、分析算法、原件指纹、范围确认或采纳规则。

三个页签使用键盘可达的 tablist，支持方向键和 Home/End；对应编辑区始终挂载，隐藏时不进入键盘顺序。原文引用与角色成果操作会移交焦点到实际页原文或结果区。确认范围仍绑定精确资料对象和研究方向；方向或资料变化后旧候选不能采纳。

最终源码回归 2,349 项通过、17 条件跳过、0 失败；类型检查、目标 ESLint 和生产构建通过，生产资源检查 235 项通过。完整 lint 在首版候选通过（保留原有一项警告），最后仅候选卡展示的小修重新运行目标 lint、完整单测与构建。独立审阅接受。构建首次受本任务生产预览的 Windows 目录锁阻挡，停止该预览后重建通过，未删除用户文件或干扰其他开发进程。

实际生产页面使用两份自行构造的文字层 PDF 验收：读取、刷新后恢复已提取文字、错误原件拒绝重新关联、相同指纹原件重新关联、逐项确认摘录、文献对照及候选选题。组件验收另用长中英文标题覆盖二十次键盘切换的草稿保留、引用跳页与焦点、修改方向后范围确认失效、折叠引用不触发采纳。当前窗口宽度实际为 1082px；本轮尺寸覆写未生效，不能把它记作新的 390px 或 900px 浏览器验收。未连接账号后端或模型服务，不将上述本地规则流程计作 LangGraph 或真实研究全流程验收。

## 与 LangGraph 的边界

本 PR 是前端整理。核对当前源码后，`create_app` 仍以 `workflow_handlers or {}` 构建 LangGraph；未显式注入处理器的部署没有默认真实角色执行器。HTTP 的 `advance` 以单角色准备、事务外执行和结果提交为边界。前端整篇报告入口则调用 `/api/agent/full-report` 与 TypeScript 报告生成链；这一入口没有因界面改版而成为 LangGraph 全流程。真实角色适配、统一调度、模型绑定与跨页面持续执行须另批实施和验收。
