# 浏览器本地 XLSX（PR-B）

选择 XLSX → 选择工作表、表头行和区域 → 载入 → 核对题目候选 → 人工确认。SheetJS CE 0.20.3 使用官方分发 tgz 的精确 URL 和依赖锁，严格 ZIP/XML 预检先于解析；工作放入可终止 Worker，不上传文件或执行公式、宏、外链。

原表、空白与有效 0 不改写。稳定列 ID、原标签、题号、单元格坐标、公式缓存及解析问题分别保存。缺少公式缓存定位后由用户处理。姓名／学号等原标签继续触发标识列保护，分支、模块与数值导出使用同一保护。解析身份绑定读取配置和列字典；恢复不恢复批准。候选按变量、题号或已核验的问卷星往返清单提出，重复候选待人工决定，多选拆列不由 v1 猜测。

## 边界

输入最多 2 MB；ZIP 最多 512 项、32 MB 解压总量、16 MB 单项；解析最多 400,000 个单元格；选择最多 5,000 条记录、80 列和 200,000 个单元格。超限拒绝，不截断。严查重复单元格、工作表关系、异常数值/布尔缓存、嵌套缓存与畸形 XML。20 秒资源超时、主动取消、重选、卸载和晚到回执均保留现有数据。取消确认替换后可继续调整区域。
