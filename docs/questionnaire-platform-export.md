# 问卷星文本导出（PR-A）

## 使用

在问卷设计工具栏选择「导出到问卷星」，检查题目预览与平台待设置清单，下载 ZIP。包内含 UTF-8 / LF 文本、源问卷版本及 SHA-256 绑定的往返清单、平台设置清单。原有草稿 TXT、JSON 与编辑器实例保留。

问卷星按其文本导入入口处理题目；标题、说明、必答、跳题和数值验证在平台自行设置。证见的数值题按填空导入，量表按单选导入；量表 A.–O. 前缀用于避免平台把裸数字选项误拆成题目。原编码、分值、锚点与反向计分配置存于清单，不由平台序号代替。

文字中可能被识别为题号、题型指令、换行、连续下划线或数值开头选项的内容，定位到题目与字段后由用户修改，未自动重写草稿。下载清单只证明内容完整性，不是身份签名、平台认证或分析批准。

## 2026-10-12 验证

- 16 个导出及完整性测试通过：五种现有题型、负数/零计分、Unicode、80 题/30 选项、异步版本捕获、重复 JSON 字段与篡改拒绝。
- 在用户授权的测试账号创建明确标记的合成问卷：单选、多选、开放题、数值填空、负数起点量表各一题。发布后提交一条 T01 合成答卷并取得平台 XLSX。
- 平台保持五道题及选项次序；多选拆成两列 1/1，数值 0 完整保留；量表原分值 0 回收为选项序号 3。这要求后续人工重编码，不可直接分析序号。
- 平台将中文问号规范为 ASCII 问号，文本不宣称字节相等。测试未核验跳题、完整范围校验及所有选项数量；必答默认需人工核对。每份新导出包仍是 proposed / runtimeVerified:false，用户自己的问卷未被测试自动认证。
- 桌面导出对话框、ZIP 下载、Esc 关闭与焦点恢复已验证。真实账号信息、原始回收文件、截图与运行缓存不进入仓库。

参考：[问卷星文本导入说明](https://www.wjx.cn/help/help.aspx?h=1&helpid=138)。后续 PR-B 实现本地 XLSX，PR-C 处理 SAV 与一题多列；本 PR 不修改业务 API 或数据库，不推进赛事阶段或 Gate。
