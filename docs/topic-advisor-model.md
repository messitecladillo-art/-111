# 选题顾问：可复现的排序训练与证据边界

本模块把用户声明的地区、学校背景、样本入口、团队资源、时间预算与关注领域，与作者整理的研究问题框架及已登记事件进行匹配。它训练的是一个小型透明线性排序器，不是大语言模型微调，也不预测获奖概率。

## 数据、来源与训练

固定输入位于 `apps/frontend/content/topic-advisor/`：

| 文件 | 作用 |
| --- | --- |
| `catalog.json` | 原创研究问题框架、必要渠道/资源、最低规划估算和来源 ID |
| `sources.json` | 来源标题、链接/路径、覆盖类型、可支持的主张与限制 |
| `hotspot-events.json` | 全国/地方事件、发布日期、发生日期、有限复核窗口及拟议研究假设 |
| `train.json` | 明确标为 `authored_synthetic`、`split: train` 的人工成对偏好 |
| `ranker.json` | 可复现的非负权重、超参数、输入 SHA-256、训练拟合指标及限制 |

来源中的 `fulltext`、`listing_only`、`reference` 是不同证据边界。获奖名单只能证明名单所载信息，不能证明获奖项目的研究方法、样本质量或获奖原因。框架和偏好标签为作者设计；它们不是真实调研数据、真实评委打分或奖项结果。

在应用目录运行：

```text
node --experimental-strip-types scripts/train-topic-advisor.mjs
node --experimental-strip-types scripts/train-topic-advisor.mjs --check
node --experimental-strip-types --test tests/topic-advisor.test.mjs
```

训练脚本只接受上述固定训练输入。它不接受任意数据路径，也不读取留出评测。`--check` 重新训练并比较完整产物字节；训练没有随机种子、当前时间或网络依赖。输入指纹按原始文件字节计算。

每一偏好对提供同一用户背景下的优选模式与对比模式。程序计算两者特征差，通过批量梯度下降最小化成对逻辑损失，并加入 L2 正则；每一步把负权重投影为零。超参数固定为 2400 轮、学习率 0.12、L2 0.015。排序器没有截距，因为成对差会消除公共截距。输出保留 12 位小数。

训练一致率仅统计训练偏好是否得到正向差值，不把平局算正确。该指标和训练损失都是训练拟合信息，不能称为真实选题质量、外部准确率或获奖率。独立测试由协调者在冻结模型后另行编写和执行；不能针对留出答案调参后仍宣称盲测。

## 特征与硬检查

十四个特征均处于 0—1 范围：已确认渠道、可能渠道、资源匹配、精确地域匹配、用户声明场景、兴趣/领域匹配、时间余量、预算余量、决策结构、证据计划、实质差异、行动用途、当前事件匹配、一般研究敏感度。学校名称、院校层次、隐含人脉和推测地方产业都不进入特征。

现有24个框架中，四个按字段/条目完整性计算的特征在训练比较项中均为1，对应权重为0。当前训练主要区分条件匹配，不能据此声称已经学会比较研究本身的价值。后续先冻结独立评测与可复核的质量评价，再扩展偏好材料；完整框架继续保留，不通过削弱内容人为制造特征差异。

`confirmed` 仅表示用户声明已确认；`possible` 仍需核验；缺失键表示未知；`unavailable` 是明确不可得。未知时间/预算在排序特征中取中性值，但在用户可见诊断中保持未知，不作为零或已满足。

硬检查在模型之外进行：必要渠道/资源不可得、固定地域冲突、明确时间/预算不足、敏感研究被用户设置为避开时，模式从推荐项移至阻断列表。模型系数无论多高都不能覆盖阻断。规划天数与预算为作者估算，不是报价或竞赛硬规则。仅可能获得的渠道和未知输入标为待验证。

排序先按条件初步齐备、尚待验证分类，再按模型分值排序，ID 用于稳定打破平局。模型分值仅内部比较；自由输入的候选题不赋予可比较的模型质量分数。

八维诊断对应：问题强度与时效、决策者、样本与证据、实质差异、伦理与执行、分析设计、行动影响、答辩潜力。分值是设计成熟度的拟议刻度；缺证据时使用 `null` 与“未知”，不是把缺证据包装成精确评分。每一维保留理由、待验证事项与框架来源。第一周计划为拟议工作，未执行的访谈、调查或观察不会写成已完成。

## 事件的时间与地域

v1事件按明确填写的省份、城市进行规范化精确匹配，保留旧版语义。v2使用显式地区代码及目录版本匹配真实上级路径；同名县区和历史名称须经用户选择确认，清除地区后不沿用残留文字加分。当前发布事件目录仍按全国、省和城市登记，县域草稿未自动进入这一目录。全国事件仅提供全国背景；地方影响必须另行验证。

事件认定为当前线索需要：状态为已核验、来源全部达到全文覆盖、发布日期及核验日期不晚于参考日、在有限有效/复核窗口内，且与比赛时间范围相交。已发布且落在比赛窗口内的未来安排可作为当前计划线索，同时明确标注尚未发生。历史、参考性材料、过期材料、超过一年未更新材料、仅名单来源不会增加当前事件特征。未填写参考日期时无法认定当前有效。复核窗口可能是作者制定的信息新鲜度策略，必须展示其依据，不能冒充政策有效期。

## 导入、保存与模型深化

草稿支持旧版v1与显式地区引用的v2，保留各自语义；不包含原始问卷、受访者数据或缓存结论。导入拒绝未知字段、重复 JSON 成员、无效日期、重复 ID、控制字符和动态对象属性。保存键必须同时绑定有效账户与项目，不能回退到全局匿名键。任何背景变更都改变规范化指纹，旧结果由页面标记为过期；旧地区引用可历史读取，新的推荐、确认及简报应用要求先完成明确迁移。

可选的大模型深化使用最接近的合成训练示例，学校名称不参与检索，示例中的学校/专业名称不发送。输入始终标为不可信资料，来源 ID 与模式 ID 采用白名单；仅允许提出拟议题目、问题与核验计划，不允许新增统计事实、学校资源、执行动作或获奖判断。结构化校验只验证格式与引用范围，无法证明自然语言无幻觉；模型建议仍需人工核验。外部调用、成本和幂等性由主应用接口管理。

## 验证边界

核心回归覆盖训练确定性、正向单调性、不可达阻断、未知/零区别、学校改名不变性、地域精确匹配、日期/来源时效、领域过滤、草稿版本与账户项目隔离、重复 ID 与引用拒绝、内容指令不能覆盖逻辑、候选题缺证据诊断和来源白名单。制品复现检查必须在完整内容生成后执行，缺少内容时的开发跳过不能作为交付通过依据。

当前能力不替代当届竞赛规则核验、真实决策方确认、伦理审批、招募可行性检查、原始数据质量审核或专家评审。任何外部质量提升主张都需要独立、预先固定的评价设计。
