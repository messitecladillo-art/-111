# 县域资料展示与受控发布投影

本批接入全局及项目选题页的只读县域资料面板，按当前目录、精确县级代码选择。历史事实、拟议研究、地域、时间、来源阅读范围和发布状态分别展示；同名地区、旧目录和多包冲突不会自动猜测。面板不采用题目、不调用模型、不写项目或推进赛事 Gate。

## 当前内容状态

维护者登记 `corpus-source/topic-advisor/county-publications.json` 当前为空，公共投影也为空。原始二十县及审核后的三县仍为草稿；内容复核通过没有自动产生发布决定。当前页面可以显示精确的空覆盖状态，准备好的完整布局由合成发布夹具验收。

## 发布与撤回

全局发布权限沿用维护者 Git PR 审核。项目 owner/editor、项目选题确认、前端传入的作者姓名或自报复核回执均不是全局发布权限。

维护者需要在 PR 内核对实际来源阅读、逐项内容复核、实际页面六项披露，及目标包/内容版本/原始字节指纹。每个包只有一条不可变历史，事件由现有 `applyTopicPublication` 创建；批准需绑定精确事实或拟议方向。收录历史文件不是直接将草稿状态改为 published。撤回追加绑定当前有效内容的事件，历史和原稿保持不变。

登记修改之后显式生成公共投影：

```powershell
cd apps/evi-x-platform
node --experimental-strip-types scripts/publish-topic-counties.mjs --write
node --experimental-strip-types scripts/publish-topic-counties.mjs
```

默认命令仅核对，生产构建的 `topic:check` 也只核对。没有来源登记、完整逐项复核、精确发布决定或一致公共投影时构建失败。维护者审核和用户最终批准仍在 PR 中完成；本批没有增加管理员接口或网页发布按钮。

生成器验证每条历史的哈希链及发布/撤回合同，排除未发布、撤回和旧目录内容，拒绝同包拆成多段历史以及多个有效包覆盖同一县的歧义。登记上限为 8 MiB / 64 个包历史，每包继续受领域合同的 1,000 事件限制。

## 浏览器边界

浏览器只导入 `content/topic-advisor/published-counties.json`。完整维护者历史、作者/复核者声明、原始包文本和未选县域草稿不进入面板的依赖树。公共投影保留选中县的内容版本、包/发布指纹，以及该县实际引用的来源；共享来源的其他县事实与阅读 ID 会被裁掉。这里的裁剪只减少可见字段，不扩大任何来源支持范围。

来源发布日期、资料检索日、实际阅读时间和事实对应日期具有不同含义。空日期继续显示“尚未确认”；阅读全文或打开链接不会自动变成对某条事实的支持。拟议研究方向保持 proposed，渠道仍由用户另行核实。

静态发布使已部署版本的内容固定。追加撤回事件后仍需生成、审核并部署新公共投影；本批没有声称旧离线缓存能被远程抹除。后续采集队列、实际运营审阅、定期时效更新与训练评测继续单独交付。

## 验收范围

- 合成发布/撤回/破坏历史、同名县、目录变化、竞争资料包、未读及仅题录来源。
- 实际 React 输出的六项披露与链接；变更 profile 时不残留前一个县的事实。
- 维护者登记到公共投影的离线重建、字节漂移阻断、不同工作目录和生产构建。
- 桌面布局、键盘折叠/链接、浅深主题和减少动态；真实来源是否支持事实仍由独立内容审校确认。
