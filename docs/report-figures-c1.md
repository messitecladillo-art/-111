# C1：共享图形、项目配色与跨格式导出

本批基于 `091c6dd16b01d0cae56930a3ddaad1e1873925cc`，独立承接分析凭据。页框、报告主题 Skill 和多来源分镜保留在后续批次，不需要这些能力即可构建与使用 C1。

## 包含的能力

- 将已登记的分析结果保存为共享图形；问卷与数据分析传入报告时，同步携带分箱、箱须等必要的汇总摘要。
- 图形目录提供柱形、条形、分组柱形、百分比堆叠、热力、直方、箱线与三线表。只展示现有结果足以支持的图形，不从汇总表反推原始分布。
- `EditorContent/v3` 保存项目配色版本与图形定义，报告内容块和 PPT 对象通过 `figureId` 复用同一图形。旧文稿继续按原版本读取，首次主动采用图形后才升级。
- Word 保留 SVG 图形与原生表格，PPT 采用原生图表或真实 SVG，LaTeX 通过受控图形注册表生成 TikZ。数字、行内分母和配色来自同一份定义。
- 三线表采用 1.5／0.75／1.5 pt，每列分别居中。格式设置只改变表现，不触发统计重算。
- FastAPI 严格检查图形字段、有限值、上限、结果版本、样本数和对象引用；拒绝原始答卷数组、逐条离群点与任意 SVG。
- 单源报告分镜继续使用 link v2。实际引用共享图形的章节指纹包含相关图形与配色；未引用图形的旧章节升级到文稿 v3 后保留旧指纹语义。

记录、图形和版本检查确认结构与来源一致，不能替代统计解释及人工审阅。

## 验收范围

需要完成前端全量单元测试、类型检查、lint、生产构建，以及后端报告、图形契约和 LaTeX 测试。整合回归还覆盖：

- 结果传递后，汇总图形和已有配色保留；身份冲突与过期结果不能覆盖现有内容。
- 旧 v2 链接在 v3 文稿中保持稳定；已引用图形、配色或页面改变后待复核。
- 相同结果的不同 `figureId` 不能冒充同一张报告图；从报告生成 PPT 时保留选中的图形。
- 小样本、常量、缺失、百分比分母和非有限值边界。
- 未使用的超密图形不阻塞当前 LaTeX 工作区；真正导出该图形时明确提示拆分。

自动检查与包检查不代替原生 PowerPoint/WPS/Word 的渲染、修改、保存重开，以及 PDF 矢量保留验收。具体结果以本次交接的原始日志与投影文件清单为准。
