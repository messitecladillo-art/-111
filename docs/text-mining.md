# 文本挖掘：开放题的词频、提及率与群体差异

`apps/frontend/lib/text-mining.ts` 处理用户导入的开放题答案，只做计算，尚未接入界面。

- **分词**：用运行环境自带的 `Intl.Segmenter('zh')`（浏览器与 Node 的 ICU 词典），不打包第三方词表，因此无需另核词典许可。运行环境不支持时直接拒绝并提示更新浏览器，不退回到二字切分（那会把“放时”这类碎片计为提及）。去掉虚词（`FUNCTION_WORDS`，刻意保守：“希望”“增加”等常是诉求本身，保留）、纯数字与单字。
- **提及率**（`termTable`）：每个词在多少条有效回答中出现，按提及条数、再按出现次数排序；“无”“不知道”等不作答（含全角写法，先做 NFKC 规范化）不计入分母。少于 5 条有效回答时拒绝计算。
- **群体特征词**（`distinctiveTerms`）：以每组回答为一篇文档做 TF-IDF，各组都说的词得分为零，留下的是这一组独有的说法。
- **共现**（`cooccurrence`）：两词同时出现在多少条回答中，默认至少 2 条。

不做情感分析（情感词典需先核许可），不内置爬虫：只分析用户合规采集并导入的文本。
