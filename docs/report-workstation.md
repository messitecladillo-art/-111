# 报告生成工作装置

这批将 Anatomy 的等距图解方法用于报告生成界面。装置只承担屏幕上的过程反馈，不进入报告数据、统计结果、Word、LaTeX 或 PDF 内容。

## 已接入的位置

Agent 的全报告请求通过 `LiveWritingStatus` 记录实际响应：请求准备、正文起草、结论组织、修订、完成与中断。`reportWorkState` 将其转换为装置状态；请求尚未收到计划时不显示预设章节数。计数表示已返回章节，不表示总体完成百分比。只有有效 `done` 回执后才完成，装置随正文接替退出。

`ReportPaper` 向 `PaperPages` 传递可选屏幕状态。`PaperPages` 依据真实测量结果，在当前章节所在页的最后内容下方寻找空白；装置与正文、页码均留有间距。它不进入 `buildFlow`、分页测量 portal 或 `EditorContent`。空间不足、当前页不明确或纸面缩放过小时，使用页外的紧凑区域；封面不叠加装置。打印媒体隐藏装置。

同一装置按上下文提供报告、数据和资料三种视觉细节。它直接嵌入现有工作区，不要求用户切到演示页面或手动切换运行状态。

- 全报告 NDJSON：按真实章节回执显示在纸面空白；完成后让位给正文。
- 对话与章节拟稿：只有本次挂载实际派发、且身份仍匹配的请求显示内嵌反馈。尚未返回时写“等待模型返回”；恢复的历史进行中记录静态显示“待核对”。
- 知识镜：本地索引加载在现有对话占位中显示；联网查询沿用账户和查询回执边界。
- 数据分析：使用现有文件读取阶段，不把同步分析或已存在的结果伪装成后台任务。

报告纸面正在反馈同一全报告任务时，对话不重复展示第二台装置。当前对话只突出最后一条待处理消息，旧步骤保持记录形式。

## 交互与任务隔离

- 准备、撰写、修订时有轻量活动；错误、等待、完成状态静止。没有计时器推进业务阶段。
- 生产界面不提供“展开结构”和演示状态按钮。组件保留受控测试选项，正常调用默认为关闭。
- 离屏、页面隐藏、系统减少动态时停止视觉循环；卸载清理观察器、事件与本组件的资源。
- 每次请求绑定账户、身份轮次、对话和项目。重复启动被阻止，过期响应不能写入新上下文。
- 身份有效性使用会话的同步校验，不能仅等待 React effect 更新。离开任务时停止接收，并将对应界面记录沉降为中断；原身份仍可访问的调用消息标记为结果未知。
- 中断接收不保证外部服务停止执行或收费；本批不增加自动重试。
- NDJSON 流接受末尾无换行的有效回执，缺少有效完成包时保留未完成状态。

## 源码职责

| 位置 | 职责 |
|---|---|
| `lib/agent/report-work.ts` | 状态转换、空白定位、请求作用域与中断控制 |
| `components/figures/report-workstation/` | 装置几何、SVG、局部样式、活动生命周期 |
| `components/agent/AgentShell.tsx` | 真实请求与响应的生产者，身份与任务隔离 |
| `components/agent/Transcript.tsx` | 在当前消息内部显示等待；历史记录不持续动画 |
| `components/analysis/AnalysisJourney.tsx` | 文件读取和检查过程，复用既有导航 |
| `components/knowledge/KnowledgeLookupPanel.tsx` | 当前账户的联网查询与真实回执 |
| `components/editors/ReportPaper.tsx`、`PaperPages.tsx` | 页内或页外的屏幕展示，不改变正文模型 |

`/examples/report-workstation` 已移除；测试夹具保留在内部验收目录，不成为产品模块。

这是 `agent_ui` 概念视觉。上游的几何制作工具和检查能力不证明研究数据真实、统计有效，或当前图形已通过全部机械碰撞审计。

## 验证入口与边界

`report-work.test.mjs` 覆盖状态、计数、作用域和空白保护；`report-work-dispatch.test.mjs` 独立执行实际派发分支，覆盖同步身份变化、首次对话创建、重复请求、换项目、断流及末尾回执。既有分页、报告格式和模型同意测试继续运行。

浏览器验收使用生产组件与合成传输，覆盖主工作区等待、错误静止、完成接替、减少动态、离屏暂停、浅深色、窄屏回退和打印排除。先前内部样板的检查记录不能代替本轮主工作区的复核；它们均不能替代真实供应商调用、收费对账或生产部署验收。
