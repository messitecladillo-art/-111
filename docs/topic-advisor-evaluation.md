# 选题顾问：公开校准与独立评测建设

## 本批交付与证据范围

本批落实 P5 的第一份校准包：12 个明确标为合成的团队情境、两位独立 AI 评审的原始意见、20 条共同认可的断言、冻结指纹和离线对照程序。生产排序器、60 对训练材料、24 个问题框架及产品页面均未修改，没有追加训练或调用外部模型。

这 12 例是**公开校准案例**。评审在读取排序实现或排序输出前分别完成标注，协调者只纳入双方共同确认的断言；评审意见完整保留。AI 同行复核不是人类专家金标，公开校准也不是封闭盲测，不能用检查通过比例表示真实选题质量或获奖概率。

| 文件 | 用途 |
| --- | --- |
| `evals/topic-advisor/scenarios-v1.json` | 12 例输入、任务、主分层、地区/来源/事件家族及合成分类 |
| `evals/topic-advisor/reviews-v1.json` | 两份独立 AI 评审、来源、理由、范围与身份说明 |
| `evals/topic-advisor/labels-v1.json` | 协调者冻结的共同断言，绑定精确场景指纹和两位评审 |
| `evals/topic-advisor/manifest-v1.json` | 场景、标签、评审、全部运行依赖、排序器与训练输入的 SHA-256 |
| `apps/frontend/scripts/topic-evaluation.mjs` | 输入验证、隔离检查、两基线、统计口径和特征审计 |
| `apps/frontend/scripts/evaluate-topic-advisor.mjs` | 固定输入的离线命令，不接受任意数据路径 |

外部原文在本批不重新抓取。有关事件的断言只检查冻结目录的地域、日期、阅读覆盖和状态语义，不据此确认真实市场需求、实际活动执行或新的地方事实。既有县域公共投影继续为空，本批不批准内容发布，不推进赛事 CLI 阶段或 Gate。

## 校准案例

| 案例 | 覆盖内容 |
| --- | --- |
| cal01 | 武汉校园入口已声明、餐食/赛事条件比较、校名替换不影响排序 |
| cal02 | 只有地点，其余条件未知；允许条件式探索，不能认定齐备 |
| cal03 | 必要管理方渠道明确不可得 |
| cal04 | 零天与未知时间分开；无法启动目录调查时不给可启动方向 |
| cal05 | 预算未知时保持待验证 |
| cal06 | 南京与苏州的地方条件分开 |
| cal07 | 天津河东区的明确地区引用优先于残留武汉文字 |
| cal08 | 旧地区目录须先明确迁移再执行新推荐 |
| cal09 | 不将晚发布信息带回较早参考日 |
| cal10 | 已有渠道也不能覆盖“避开敏感研究”的选择 |
| cal11 | 自拟题目、零预算与未完成估算；没有可比较的训练质量分 |
| cal12 | 过期活动与历史计划保持历史状态 |

案例标题不是验收范围。cal12 的标题提到了未核验草案，但其任务实际只列两项历史事件；匹配本地地域的待核验来源、已发布但尚未发生的计划、长期有效政策与新鲜度复核窗口等，仍需后续场景单独覆盖。cal07 中的草案先因地域不适用被排除，不能冒充“已验证了本地未核验来源”的案例。

另有 5 条只被一位评审提出的断言保留在原始意见中，没有计入本次共同标注。这里的“共同认可”是对具体断言的共识，不代表案例中所有可能问题都已审阅。

## 评价口径

当前排序器与 `resource-only-v1` 使用同一目录、硬约束、领域过滤和条件齐备顺序。简易基线仅令 `possibleAccess` 与 `resourceFit` 权重为 1，其余为 0：已确认为 1、可能为 0.35、不可得或未知为 0，分别按所需渠道和资源数量归一化。它只对排名权重构成对照，不是另写一套权限、地域或伦理逻辑。

分别报告以下内容，不能互相替代：

- **边界断言**：每条已共同标注断言的通过与失败，按主分层列出。失败不能从分母移除。
- **两项均可进入推荐的偏好比较**：胜、平、负及明确分母。分值平局不能靠 ID 排序算作胜。被硬约束排除的方向不计入“两项均可推荐”的质量比较。
- **Top3 可接受情况**：只统计已有独立可接受题目标签的推荐场景，报告分子、分母、覆盖率及 Wilson 95% 区间。没有标签时比率和区间均为 `null`。
- **空列表**：只统计推荐任务；事件检查、自拟题目诊断、单框架检查和旧引用拒绝不是推荐空列表场景。已标注必须空列表的案例另列是否得到执行。
- **特征差审计**：在全部可执行场景与目录框架中检查各特征的最小/最大值、权重及共同偏好中的非零差。
- **训练暴露**：列出与训练资料的精确背景重合；共享目录和已知家族仍明确标为已暴露。没有精确重复不等于没有语义泄漏。

两位评审均未给本包指定可接受 Top3 题目，因此 Top3 分母是 0，质量命中率未测。唯一成对比较的一方有明确硬约束，故“两项均可推荐”的偏好分母同样是 0。不得把 20 条边界断言全部通过包装成推荐准确率 100%。

`decisionClarity`、`evidenceDesign`、`differentiation`、`actionability` 在现有 24 个完整框架中均为 1，权重均为 0。本包保留这些框架的完整性，没有删减内容来制造可学习的差异。要学习实质研究价值，下一批须引入经过独立标注的决策备选、可得证据、比较基准和行动指标。

自拟题目返回的 `rankScore: 0` 是既有代码的“未评分”内部哨兵值。报告明确输出 `trainedQualityScore: null`，不会拿它和目录题目比较，也不会把零解释为研究价值最低。

## 冻结与失败处理

执行前校验所有必需文件、内容哈希、评审身份、场景绑定、两份意见中的实际断言支持及全部案例覆盖。待审标签、单人自审、断言缺少任一评审支持、相反偏好、矛盾状态、重复场景、未知字段、错误哈希或链接文件都会拒绝。修改文件后不能自动重算指纹并继续报成功；应先完成相应审阅，再显式建立新冻结记录。

冻结记录包含 `core.ts`、类型、输入解析、地理执行、地区目录、问卷重复字段检查、训练实现和训练脚本，以及模型和固定输入。只改特征实现而沿用同一个评测身份会被拒绝。哈希证明内容一致性，身份授权仍来自代码审阅流程，不把自报姓名或哈希当成认证。

`frozenAt` 保留历史标签冻结时刻，供核对评审是否在有效授权期内完成；`sealedAt` 记录本次整包封存时刻，两者分别核验。发布修正不重写原始评审时间、情境或评审内容。源代码及其他冻结文件使用 LF；`scenarios-v1.json` 以 Git `-text -eol` 保存两位评审实际读取的原始字节。回归测试对每个冻结文件执行 Git clean-filter 比对，避免本地通过而 Linux 检出后指纹失效。

每个场景登记情境、地区、来源和事件家族。隔离检查拒绝跨 calibration/development/final 集的同家族和近重复；校名、专业或标题变化不能产生新的独立情境。Jaccard 近重复阈值为 0.9，标记的是字段级相似，不替代语义审阅。现有包只有 calibration 集，不宣称已经有封闭测试集。

当前包不以“训练资料零精确重合”证明独立性；共享框架、源事件及等价情境必须在后续切分时人工核对。训练脚本继续只读取固定 `train.json`，评测文件不进入训练或产品浏览器包。

## 本地复算

在 `apps/frontend` 中运行，使用仓库已有 Node 版本，不需要模型 Key、数据库或网络：

```powershell
node --experimental-strip-types scripts/evaluate-topic-advisor.mjs --verify
node --experimental-strip-types scripts/evaluate-topic-advisor.mjs --pretty
node --experimental-strip-types --test tests/topic-evaluation.test.mjs
```

命令以脚本位置解析固定路径，可从其他工作目录调用。结果写到标准输出；需要留档时由调用方重定向。相同冻结版本产生相同输出。退出码：0 为本包声明的检查通过，1 为检查完成但存在失败，2 为输入、指纹、评审或命令参数被拒绝。通过仅指当前声明范围。

## 后续批次保留

下一步先补足约 90 个独立情境及真正可区分的价值标注，再考虑约 300 组审校偏好：30 常规、20 资源反例、20 地域/时间/来源边界、10 敏感、10 自拟题/未知为覆盖目标，不为凑数复制情境。开发与最终测试在调参前按情境、地区、来源和事件家族隔离，最终标签不交给调参者。公开校准案例不能改名为盲测。

对最终测试中的错误进行调参后，原测试只能作为开发证据；之后的盲测主张需要新的冻结版本。未来 Top3 ≥85% 只作为事前目标，须同时给出独立可推荐场景分母、覆盖、恰当弃答及区间，不是本批结果。

现有选题到问卷、人工发布/撤回、研究发现与报告/PPT质量链、资料和知识库、画布、教师审阅及部署验收继续保留；本批不改变这些工作的完成状态。
